# design-demo 设计与修改约束

## 适用范围

- 本文件适用于 `docs/design-demo/`，与项目级 `AGENTS.md` 一并遵守；用户当前明确要求优先。
- 本目录用于产品界面与核心交互设计，不接入真实采集、认证或后端能力；不要因修改设计稿顺带扩展业务实现。
- 本文件记录后续修改应遵守的原则；启动方式、页面细节和现有实现见 [README.md](README.md)。README 中的历史兼容描述不自动成为新需求，与本文件冲突时以后者为准。

## 文案与操作入口

- 手机业务界面按实际产品体验设计，不加入仅用于解释演示或测试的多余文本，例如“仅为演示”“模拟数据”“尚未接入”“不会生成或保存结果”。实现限制写入 README，不反复放进页面、状态提示或 Toast。
- 保留核心操作指引、必要的错误反馈和已确认的健康参考声明；不要把它们当作多余文本删除，也不要在标题、内容和页底重复堆叠。
- 测试、模拟触发和重置入口与业务界面分离，沿用现有预览外部操作区，不把开发控制塞进手机业务流程。外部操作区位于手机下方并与手机同宽，按钮自动换行，不超出手机左右边界。
- 数据接入相关状态先在本目录设计，不同步修改原生。状态预览挂在侧栏对应页面的右侧衍生层级，父节点点击直接展示成功态，子节点展示各衍生态，不向下展开；不另建集中“状态设计”分组，不在手机外部增加状态按钮。首页指标直接进入对应历史日区间，不再弹出指标详情或设计其异步状态。
- 侧栏页面和状态入口的宽度随文字内容自适应，不拉长按钮以对齐；右侧衍生列从各自父节点的实际边界连接。
- 首页首次加载用骨架，刷新在各数据位置显示旋转加载，加载圈随被替换读数或文字的实际尺寸变化，保留原占位及单位，不统一固定为 18px；获取或刷新失败使用 Toast，最终回到空数据。手机下方现有演示操作区提供“刷新首页”按钮，仅已登录首页可用，加载期间禁用；按钮演示刷新过程，不是衍生态切换入口。历史首次获取与刷新共用日期筛选下方的大旋转加载，获取失败与刷新失败共用“历史数据获取失败／重新获取”页面状态，不保留旧内容展示、不使用 Toast，也不保留独立刷新预览入口。加载、空态与失败区填满筛选下方至底栏前的剩余空间；空态无图标，检测与重新获取使用主题色文字箭头，加载及失败不显示声明。
- 区分检测失败、结果获取失败和任务创建失败；检测失败仅可重测，没有失败详细报告。部分成功仍显示“检测完成”及原提示，只在失败指标卡底部说明未生成或信号质量过低；质量拒绝有分数才显示质量分，血氧失败保留空仪表。检测结果弹窗的状态图标与标题同一行整体居中，说明另行居中。
- 报告首次加载保留“详细结果”标题栏及返回入口，仅在下方内容区显示居中旋转图形；声明只随成功及部分成功报告展示。波形加载和读取失败仅影响有效报告的局部画布，无可用波形合并为读取失败，不再设计结果不可用报告或失败详情。保持成功态原布局，不展示算法版本或后端技术阶段。
- 控件只表达当前可执行的动作；次要入口优先使用合适的图标与浮层，不为解释控件额外增加一排文字。图标保留准确的可访问名称。
- 糖尿病风险只把既有 0／1／2 档位映射为“较低风险／中风险／较高风险”，不按概率重新划档，不补造无记录的等级。使用20px字号、26px行高及与其他读数一致的主文字色 `--ink`；详细结果的看板和指标解读完整显示单行等级，首页、历史与简要结果仍为第一行“较低／中／较高”、第二行“风险”的两行居中。风险排版不连带改变加载圈尺寸或转速。原始概率不在页面展示，缺失或失败仍为空态，并保留非诊断声明。
- 无扰心率开关与隐私偏好共用启用说明及等待流程：明确确认后才等待并提交开启，取消或只去设置不启用；启停等待期间保留上次确认外观、显示局部加载并禁用重复操作，离页或重置取消未完成动作。Demo 不申请真实权限或启动服务。

## 布局与视觉

- 复用项目主题、品牌资源和现有组件风格，不维护第二套色表或复制资源；图标优先使用 SVG，不用表情替代。
- 独立加载圈统一采用品牌青绿渐变圆弧及18%透明度浅色底轨，使用与原生相同的24×24画布、半径9、线宽2比例，900ms匀速旋转；不再用CSS边框叠加圈径或线宽。首页按原生内容占位计算加载圈尺寸，不推移读数、单位和卡片；渐变底按钮内的加载圈保留白色前景。
- 区分页面区域、图表坐标绘图区和数据范围。调整数据留白不等于缩小绘图区，更不等于改变整个区域的高度；未明确要求时，不连带调整预览、读数、按钮或分页布局。
- 历史趋势图直接展示在页面背景上，不包裹卡片；区间平均数据卡片参考结果弹窗指标卡，使用白底、浅色细边框和圆角，不加阴影。趋势曲线使用主题青绿、平滑连线及向下淡出的渐变面积；图例放在图表内，与坐标绘图区留出间距，不放在图表底部。数据圆点仅在交互时显示，圆心为白色，外圈使用对应曲线颜色。
- 指尖检测与血压检测的详细结果页中，指标总览、血压主卡、处理后波形卡和解读卡统一使用白底、浅色细边框及圆角，不使用卡片阴影；波形绘图区的既有内阴影保持不变。
- 指尖与血压简要结果弹窗的声明居中，与下方主按钮保留 12px 间距，不叠加声明底部外边距；详细结果页的声明布局不变。
- 历史趋势图按当前筛选区间，以对应曲线同色上三角图标＋数值标注最高、下三角图标＋数值标注最低，不再显示“最高／最低”文字；血压两条曲线各自计算。极值不引入常驻圆点，最高与最低相同时合并显示双三角图标和一个数值。下方平均卡片仍保留同色上／下三角、“最高／最低”文字及数值。
- 历史页周期分段为“日、7天、30天、自定义”；日显示基准日当天，7天和30天均包含基准日，不按自然周或自然月取整。前后切换按所选天数移动完整区间，日视图逐日切换。点击“自定义”打开日历，确认合法日期后才应用区间并保持该分段选中；日历入口确认后同样选中“自定义”，自定义区间不显示平移箭头。
- 历史自定义日期使用页内日历，不调用浏览器日期输入框；七列与点击区域不变，仅内缩选中和区间背景。年份、月份可分别进入选择面板，选中使用主题色；标题加粗居中、无关闭图标，减少标题下方间距。底部横向等宽排列，左为描边“取消”、右为“确认”。仅浏览年月或未点选日期就确认时原样返回，取消及其他关闭方式不保存草稿；只有显式点选日期并确认有效范围才提交。
- 历史日期面板固定预留六行日期，星期标题另计；不足六行保留空白，避免切换月份时弹窗高度跳变。年月选择面板不强制六行，可用高度不足时保留弹层内部滚动。
- 历史页顶部当前指标居中，名称与下拉图标使用深青主题色；保留较大字号与下拉选择，相邻指标名称以小字号分列左右并可点击切换，首尾留空、不循环，不再使用圆形箭头按钮。
- 历史指标入口使用从底部弹出的单选菜单，高度为手机屏幕的 60%；顶部固定“取消／标题／确认”，下方独立滚动。选项仅修改草稿，主题色与勾选标记表示选中，确认后才应用；取消、遮罩或 `Esc` 不提交，不调用浏览器原生下拉框。
- 历史页“最近测量记录”显示当前筛选区间内倒序排列的最近10条，不足10条时展示全部；“查看全部”保留同一区间的完整列表。
- 历史趋势图的 Y 轴刻度置于右侧；绘图区左侧不为 Y 轴预留空白，X 轴显示区间起点刻度，首个标签左对齐以避免裁切。
- 历史背景与原生历史页共用健康页渐变配方，不改变账户背景；底部声明仅置于测量记录下方，文案为“检测仅供健康管理参考，非医学诊断依据。”。
- 浮层相对其所属内容定位。“回到最新”位于波形右侧，垂直中心对齐实际波形绘图区，不把标题栏算入居中范围，也不占标题栏空间。
- Toast 统一为手机屏幕中央、宽高比 1:1 的圆角正方形，上方放大状态图标、下方居中展示说明文字，出现时显示灰色蒙版并隔离手机背景交互；不显示右上角关闭按钮。所有非加载提示均可点击外部蒙版关闭，加载不可点外部关闭，点击卡片本身不关闭。成功提示默认1.5秒，错误与信息默认3.5秒；替换后重新计时，加载持续到处理结束或被替换。
- 内容和控件尺寸保持稳定，避免计时、读数、选中标识或显隐变化推移相邻内容；不通过裁掉正常内容来凑一屏。
- 血压贴胸指引只显示颈部及以下，不出现头部；两幅图直接沿用户提供的 GIF 原始轮廓与逐帧姿势制作，保留双肩透视、手型、手腕与前臂的自然连接，不自行拼画人体结构或强行旋转手机。第一幅沿用斜侧视角，露出另一侧肩膀；第二幅沿用正面贴胸动作。只简化纹理和配色，不强调肘关节，不描绘指甲、指节及衣褶等细节；衣物与皮肤用不同填色及清晰柔和的轮廓线区分，保留袖窿线与袖口内侧轮廓，食指覆盖后置摄像头的位置必须清楚。深色只用于真实镜头区域，手部不保留误提取的黑色碎片；人物底部裁切处不画横向封口描边。贴靠帧在手机上方显示青绿高亮短线，移近帧不显示，高亮仅提示动作，不表示系统识别成功。
- 贴胸插画的皮肤阴影沿原 GIF 各帧明暗轻量变化，集中在袖口下方、前臂下缘及握持处；只用低透明度肤色，限制在皮肤轮廓内，不增加黑色杂色或关节线，不改变衣物、底边与贴靠高亮。
- 指尖与血压的镜头中央操作提示使用半透明毛玻璃背景和加粗文字，不改变提示框的居中、尺寸上限及非阻断操作语义。
- 指尖与血压等待覆盖、部分覆盖的镜头中央提示统一为“手指未完全覆盖镜头，请调整位置”；只合并文案，不合并覆盖状态、百分比或准入规则。
- 指尖与血压镜头中央提示按阶段着色：操作调整及血压等待贴胸提示使用心率红 `--accent-rose` 与正文黑色 `--ink` 按 70%／30% 混色，完整覆盖待开始与检测中使用薄荷绿 `--mint` 与 `--ink` 按相同比例混色，完成后的提示使用 `--ink`；不改变提示背景和布局。
- 血压每轮首次进入等待贴胸时自动展示贴胸操作指导，不另设等待计时；沿用指尖指导的居中标题、双图解及仅确认关闭语义。提供默认未勾选的“下次不再提示”，确认时才保存标签页内独立偏好，刷新或重置演示后恢复；确认不代表贴胸识别成功或开始检测，同轮覆盖丢失再恢复不重复弹出。

## 动态效果与手势

- 只按正常动态效果设计、实现和验证，不考虑“减少动态效果”场景；不为 `prefers-reduced-motion` 增加适配分支、静态替代或专项验证，不因通用规范或 Skill 建议扩展该范围。
- 动效服务于状态和空间关系，不用形状插值掩盖数据更新；波形刷新不能让已有波峰变形。
- 嵌套滑动区域明确手势归属：波形内水平拖动用于回看历史，不触发外层说明／波形分页；分页保留独立的切换入口。
- 历史趋势在指标、日期及图例变化时使用约 350ms 过渡，不改写记录和统计；点击或按下查看后可横向拖动连续选点，松手保留最后一条。拖动只选择读数，不平移或缩放坐标，触摸保留页面纵向滚动；该动画不用于实时脉搏波。

## 脉搏波

- 面部与指尖复用 `pulse-wave.js` 的展示逻辑；仅追加新采样，历史时间和幅度不再改写。保留本轮完整历史，重测或离页时清空。
- 开始时从右侧出现并向左累积，未满六秒时左侧留空；每屏固定六秒，只能水平平移，不能滚轮或双指缩放。
- 数据高度保持在整个坐标高度的 10%–85% 内，以坐标底边为 0%。通过固定纵轴数值范围给数据留白，不改写采样值、不随窗口自动缩放、不增加百分比布局内边距，也不改变脉搏波区域高度。
- 检测中默认跟随最新数据，回看时保持所选时间段并继续采样；结束后仍可回看全部历史。
- 回看时显示右侧圆形“回到最新”浮层图标，点击后回到最新窗口并恢复跟随，随后隐藏；不用标题栏文字按钮替代。
- 关闭 ECharts 曲线入场和更新插值动画；窗口随刷新平移，不对历史曲线做形状过渡。保留已有的页面隐藏暂停和离页资源释放机制。

## 修改与验证

- 只修改当前目标相关内容，沿用职责划分，不把两个检测页的共用逻辑各维护一份，也不顺带重构其他页面或原生 App。
- UI 修改使用常规竖屏、默认字号和正常显示设置，实际打开对应页面验证核心交互；除非用户明确要求，不增加极端尺寸、横屏、大字号、多设备矩阵或专项无障碍检查。
- 图表修改验证实际数据和坐标关系；不能只看配置就宣称视觉正确。涉及“不改变高度”时检查区域高度，涉及居中时以实际绘图区为准。
- 文档或文案修改只检查内容与引用，不额外跑行为测试；验证结论在回复中说明，不写入项目文档。
- 新的明确约束沉淀到本文件；具体页面行为变化同步 README，避免把一次性讨论或验收流水写成长期规则。
