# 心沐交互设计 Demo

独立的移动端交互演示，不连接真实业务。品牌与操作照片直接读取 `apps/native/assets/`，不维护副本；历史趋势和脉搏波使用根目录开发依赖 ECharts 6.0.0，经本地资源映射提供，不依赖 CDN。Demo 的模拟行为不代表原生 App 的采集或认证能力。

## 启动

在项目根目录执行：

```sh
pnpm install --frozen-lockfile
node docs/design-demo/server.mjs
```

浏览器访问 <http://127.0.0.1:4173/>；安装依赖后可直接启动，按 `Ctrl+C` 停止。端口占用时可指定其他端口：

```sh
node docs/design-demo/server.mjs 4174
```

服务只监听 `127.0.0.1`，同一 Wi-Fi 的其他设备不能直接访问。必须通过 HTTP 访问，不使用 `file://`。其他静态托管需映射品牌 SVG、应用图标、favicon 和 `op1.png`／`op2.png`／`op3.png`，并将 `/vendor/echarts.esm.min.js` 映射到 `node_modules/echarts/dist/echarts.esm.min.js`。服务仅支持 GET／HEAD，按精确白名单提供文件，不开放 assets 或 node_modules 目录、不代理 API；资源缺失返回错误，不以远程资源替代。

### 数据与结果状态预览

现有页面继续作为原成功态，沿用其布局和配色。状态预览分别挂在侧栏对应页面右侧的衍生层级，父节点点击直接演示成功态，右侧子节点展示加载、空数据或失败等衍生态，不向下展开；不另设集中“状态设计”分组，也不显示手机下方的外部状态按钮或“预览检测结果”按钮。原模拟采集与重置操作不变。首页各指标直接进入该指标的历史日区间，不再弹出指标详情，也不提供详情状态预览。
侧栏页面和状态入口均按内容宽度显示，不拉长对齐；右侧衍生列沿各自父节点的实际边界连接。较窄桌面窗口可在侧栏内部滚动，不压缩手机预览。

| 页面 | 衍生路由 | 展示范围 |
| --- | --- | --- |
| 首页 | `#home-{loading,empty,failed,refreshing,refresh-failed}` | 首次骨架、空数据、按原内容尺寸旋转刷新；失败入口仅演示 Toast，最终均显示空数据 |
| 历史 | `#history-{loading,empty,failed}` | 首次和刷新共用全高加载区，失败共用页面重取；纯文字空态及文字箭头操作，不使用 Toast |
| 指尖检测 | `#fingertip-measurement-{success,waiting,partial,partial-quality,failed,failed-quality,query-failed,task-failed}` | 完成、等待 Toast、部分结果、检测失败、结果获取失败和任务创建失败 |
| 血压检测 | `#blood-pressure-measurement-{success,waiting,failed,failed-quality,query-failed,task-failed}` | 同一结果语义，血压双读数不拆成部分成功 |
| 指尖详细结果 | `#fingertip-results-{loading,partial,partial-quality,query-failed,wave-loading,wave-failed}` | 页面级加载、部分成功、获取失败及局部波形状态，没有检测失败详细报告 |
| 血压详细结果 | `#blood-pressure-results-{loading,query-failed,wave-loading,wave-failed}` | 页面级加载、获取失败及有效报告的局部波形状态 |

表中花括号表示可选后缀，例如 `#history-loading`，不是地址中的字符。`partial-quality`、`failed-quality` 只展示相同结果因质量不足的样例，不是新增业务结果类别。失败状态中的“重新获取”先展示约一秒加载，再恢复成功样例；侧栏直接打开的加载预览持续到切页。历史首次获取与刷新统一保留指标及日期筛选，下方剩余区域只显示大旋转加载，不显示旧记录或声明；获取及刷新失败统一为“历史数据获取失败／重新获取”，不使用 Toast，不保留独立刷新路由。加载、空态与失败区填满筛选下方至底栏前的可用空间，成功内容仍可滚动。空态无图标，前往检测与重新获取使用主题色文字箭头，不画按钮外形，也不提供分页完成度状态。

指尖部分成功保留绿色完成图形、“检测完成”和“可以移开手指，查看本次结果”，失败项只在指标卡底部标注“未能生成结果”。质量未通过的失败项仍显示其分数，并改为“信号质量过低”；无分数的失败不补造质量分。血氧失败保留与成功相同的半圆仪表，只清空读数及亮格。简要结果与详情共用同一看板，部分成功详情不增加状态说明卡。

检测失败统一为“检测失败／本次检测未能生成有效结果，请重新检测”，仅提供重新检测，不提供查看详细结果。结果查询失败统一为“结果获取失败／结果查询失败，请稍后重新获取”，仅重新获取，不重新采集。上传未确认或失败统一为“任务创建失败／由于未知错误，任务创建失败，请重新检测”，仅重新检测。两种检测的结果弹窗中，状态图标与标题同一行整体居中，说明单独居中；成功与部分成功沿用原完成标题行。

报告加载保留“详细结果”标题栏及返回入口，下方内容区仅显示水平、垂直居中的旋转图形，不附加说明或声明；结果获取失败页同样不显示声明。声明仅在成功及部分成功报告中保留，波形加载和读取失败作为这些有效报告的局部状态，不清空成功读数；无可用波形并入读取失败，不再提供“结果不可用”或检测失败的详细页。所有分支均为本地设计样例，不接接口、不上传文件、不生成真实记录，不修改原生应用。


## 交互与状态

### 导航与首次体验

- 桌面左侧为思维导图式导航，“页面”下分主界面、账户、启动展示、首次体验。健康、历史、指尖／血压检测及其详细结果父节点直接展示成功态，各衍生态位于对应父节点下；健康另保留未登录子节点，我的保留未登录／已登录状态节点。面部、指尖和血压检测页位于对应引导下，指尖和血压详细结果又位于各自检测页下。点击切页，不支持拖拽画布。
- “组件”下提供弹窗和四种 Toast（`success`、`error`、`loading`、`information`）预览；Toast 分组始终展开，父节点不作为按钮。组件预览不切页、不修改演示数据。
- 桌面侧栏宽 344px，手机预览宽 390px；矮窗口侧栏可独立滚动。移动端全屏展示，隐藏桌面侧栏，保留“健康、功能、历史、我的”底部导航；选中 Tab 的图标和文字使用品牌主色 `--primary`，图标为实心填充，未选中使用线性图标，两态复用相同轮廓，尺寸、位置与布局保持一致；历史图标的时针在实心状态以留白呈现。
- 外部操作区位于手机预览下方，与手机同宽、右对齐；一行放不下时自动换行，不超出手机左右边界。“重置演示”与仅在指尖、血压页显示的模拟操作同组；移动端仅在这两个检测页显示这组外部操作，可滚动到达。血压额外提供「模拟贴靠胸口」和「模拟覆盖丢失」；结果状态只从侧栏预览。
- 浏览器前进／后退可切页；历史指标使用底部单选菜单，同时保留左右相邻指标名称的直接切换。
- 桌面图标进入开屏并停留；开屏只有标志、名称与 Slogan，无按钮或定时跳转。首次引导从侧栏、设置或 `#onboarding` 独立进入，按“功能引导 → 授权引导 → 首页”流转；功能引导可跳过，授权引导可返回。两步均保留明确进度和可访问按钮，不展示虚构读数、不提供权限开关。
- 手机内可从“我的 → 右上角设置”查看启动页、重看功能引导或重置演示，三个入口相互独立。

### 首页、功能与账户

未登录首页的血压和四项指标读数为 `--`，记录位置显示“暂无记录”，血氧仪表为空刻度；心率、呼吸率及风险插画保留正常颜色和透明度。主按钮及指标入口进入登录，演示登录后恢复样例读数与检测入口。首页和我的随登录／退出同步切换；侧栏状态预览只设置本地身份，不修改资料、不向手机业务界面增加状态按钮。

手机下方的演示操作区提供“刷新首页”按钮，仅在已登录首页可用；首次加载及刷新期间禁用，离开首页隐藏。点击后以局部旋转演示约一秒刷新，再恢复已登录成功样例；离页会取消未完成的演示恢复。读数、时间、辅助文案及血氧中央的加载圈沿用原生内容占位的尺寸计算，不统一固定为18px，也不推动原单位或卡片。圈形统一为24×24画布、半径9、线宽2的SVG，品牌青绿渐变圆弧配18%透明度浅色底轨，900ms旋转；不再额外叠加CSS边框。血氧仪表内固定加载视口的位置与尺寸，仅旋转内部图形，保持原读数圆心，不旋转或裁切整个嵌套视口；刷新结束恢复原读数，百分号及刻度不变。这只是 Demo 的交互演示，原生使用下拉手势和真实请求时长，不依靠聚焦或重新进入刷新。

功能页直接展示面部、指尖、指尖＋胸口三个检测入口，不再提供“按指标／按检测部位”分类切换。面部对应面部心率，指尖进入通用指尖脉搏检测准备页、不预选指标，指尖＋胸口对应血压估计；首页指标入口不变。面部入口不以历史样例冒充检测结果。首次引导使用的四幅插画保留在引导页自身，不再从功能页提取。

“无扰心率检测”卡片位于面部检测上方，表达被动心率测量的启停。卡片最小高度为 88px，内边距为上下 12px、左右 16px；文字居左，图标开关居右。胶囊轨道为 76×42px，点击区域保持 76×44px，首页同源心率图标及白色滑块均为 38px，滑块在两端与轨道边缘相距约 2px。图案沿用首页路径，交换底色与前景，以心率线条呈现在白色滑块上，不保留玫红圆底。轨道参考历史页区间选择的凹槽与高光：默认关闭时灰色轨道、灰色心率图案靠左且波纹静止；开启后整条轨道使用青绿主题渐变，白色滑块用 240ms 向右移动 34px，心率图案改为深青色并播放 4.8 秒青绿双波纹。仅右侧开关区域可点击切换，也支持键盘空格操作；标题、说明及卡片空白不触发。标题采用 16px／24px，下方显示“日常解锁使用手机时，自动测量心率”，保持与部位卡片操作辅助文字一致的 12px／18px 样式。开关与“我的 → 隐私与授权”中的被动采集偏好共用状态及启停交互：开启先显示与原生一致的后台运行设置说明，取消、关闭或遮罩不启用；明确继续后等待约 1 秒，关闭同样等待。等待时保留上次确认外观、显示滑块内加载图标并禁用重复操作，完成后才切换状态。“打开应用设置”进入 Demo 已有隐私与授权弹层，不打开系统设置、不启用，返回仍须重新确认。已确认状态切页保留，切页取消未完成动作，刷新或重置恢复关闭。Demo 不申请权限、不启动摄像头或后台服务，不生成或更新心率结果。

“我的”未登录时可点击账号区或底部登录按钮；登录后显示称呼与退出按钮。两种按钮位置一致、宽度均为内容区的 90%。登录、注册通过校验后和退出操作均进入约 1 秒加载态，按钮禁用并与加载 Toast 同步；完成后切换本地状态并提示成功。校验失败不加载，重复提交不重复执行；等待中切页会取消未完成操作，避免旧计时跳回账户页。

### 历史与趋势

历史页按“指标 → 时间区间 → 趋势 → 平均数据卡片 → 测量记录”组织，趋势图与下方统计卡片参考用户提供的体重趋势界面，周期查看与逐条详情沿用既有结构；视觉使用项目主题，不引入参考产品的配色或医学等级。

- 顶部当前指标居中，以较大字号展示并保留下拉图标。点击打开可复用的底部单选菜单，高为手机屏幕的 60%，白底与顶部圆角，从底部滑入；头部固定为“取消／选择指标／确认”，选项区域独立滚动。打开时选择当前指标，点击选项仅更新草稿，以主题色和勾选标记显示；确认后才切换指标，取消、遮罩或 `Esc` 丢弃草稿。两侧用12px次要文字显示上一个、下一个指标名称，点击名称按血压、心率、呼吸率、血氧饱和度、糖尿病风险的顺序直接切换，不显示圆形箭头按钮。首尾不存在的相邻指标留空，不循环，两种切换入口共用同一筛选状态，均保留日期区间。
- 时间区间切换提供日、7天、30天、自定义；日显示基准日当天，7天和30天为截至当前基准日、包含当天的连续日历日，不按自然周或自然月取整。使用 52px 浅灰凹槽、青绿渐变滑块与 240ms 滑动过渡。默认以固定的 2026-10-31 为基准，选择7天，对应 2026-10-25 至 2026-10-31；30天对应 2026-10-02 至 2026-10-31。左右箭头按当前所选天数移动一个完整区间，日视图逐日切换；切换指标保留区间，切换天数时保持基准日。点击“自定义”打开日期弹层，确认后才应用所选区间，并保留该分段及滑块的选中态。
- 日期旁的日历入口使用与原生相同的自定义日历，不调用浏览器日期输入框。七列布局与点击区域不变，选中及区间背景向内缩 4px；可分别点击年份与月份切换面板，年份按十二年分页，选年后进入月份、选月后回到日期，当前入口和选中年月使用深青主题色。弹层标题加粗居中、隐藏右上角关闭图标并缩短标题下方间距；底部按钮横向等宽排列，左为描边“取消”、右为“确认”。显式点选日期并确认有效范围后更新页面，反向范围在弹层内提示；未点选日期就确认、取消、遮罩或 `Esc` 均保留原周期与区间，仅浏览年月不提交。自定义区间选中“自定义”分段，不显示周期切换箭头；日历入口确认后同样选中该分段，点击日期或分段仍可重新选择。切页返回保留筛选，刷新或重置恢复默认7天。
- 日期面板固定预留六行日期，星期标题另计，不足六行以空白补齐，切换月份不改变弹层高度；年月选择面板保持原样。预览可用高度不足时弹层内部滚动，底部确认和取消仍可到达。

### 指尖检测结果

### 波形、动态效果与资源生命周期

面部和指尖共用 `pulse-wave.js` 管理模拟 PPG：ECharts SVG 折线、30Hz 采样，按采样时间只追加新点，保留本轮完整历史，重测或离页时清空。面部从获取信号后开始记录波形时间，指尖从检测开始记录；不保存或上传历史。每屏固定 **6 秒**、纵轴范围固定，仅允许水平平移，禁止滚轮及双指缩放。开始时波形从右侧出现并向左累积，未满六秒时左侧留空，不开放历史平移；标题范围从采样零秒开始，不显示负时间。检测中默认跟随最新窗口，拖动回看后保持所选时间段，采样继续；绘图区右侧垂直居中浮现 44×44px 的圆形“回到最新”图标，居中范围不包含标题栏，点击后回到最新窗口并恢复跟随，随后隐藏。结束后仍可回看全部历史并使用同一浮层返回最后窗口。绘图区聚焦后支持左右方向键逐秒平移、`Home` 回到起点、`End` 返回最新。标题仅显示当前窗口的秒数范围。

两处脉搏波统一使用 1.5px 细线与品牌主色 `--primary`，保留左侧渐隐。坐标绘图区四周使用薄荷绿 `--mint` 的浅色模糊内阴影与 12px 圆角，形成朦胧边缘，中心留白；不使用纵向渐变，不随波形填充，也不改变区域高度及坐标留白。

关闭 ECharts 入场及更新插值动画，窗口随 `requestAnimationFrame` 刷新，历史点不变形；减少动态效果时改为每秒更新，仍追加实际模拟采样。脉搏波区域高度不变，坐标绘图区保留原有上下 8px 间距，不追加百分比布局留白；仅通过固定纵轴数值范围，让波形数据落在坐标高度的 10%–85% 内（底边为 0%，底部约留 10%、顶部至少留 15%），不改写采样幅度，也不随采样自动缩放。隐藏 X 轴线、刻度文字与刻度线，不显示网格和 Y 轴，窗口左侧 14% 范围渐隐。透明端点使用主题色 RGBA 零透明度，避免 SVG 将 `transparent` 解释为无效色而产生黑色端点。图表通过 `ResizeObserver` 同步容器尺寸，不维护 Canvas 备用渲染路径。

隐藏浏览器标签页时暂停检测时钟；指尖与血压的覆盖、结果等待时钟也暂停，返回后从原进度继续。离开检测页取消动画帧、断开尺寸观察、移除监听并销毁已有图表；指尖与血压的外部模拟按钮同时隐藏。

开启系统“减少动态效果”时，波形不连续滚动，改为每秒刷新，采样历史及计时继续；状态和 Toast 的加载图标静止，指尖外部波纹隐藏但保留阴影，分页直接定位且标识无过渡，功能分类立即切换，首页装饰心率波纹静止。装饰动效不代表实时心率或设备采集状态。

### 弹窗与 Toast

弹窗、遮罩和 Toast 均限制在手机区域，不覆盖桌面侧栏。弹窗居中，长内容内部滚动；打开后手机背景与外部演示操作不可交互，`Tab`／`Shift+Tab` 在弹窗内循环。通用弹窗可通过关闭按钮、遮罩和 `Esc` 关闭，指尖未检测到手指的指导弹窗仅通过确认按钮关闭；焦点回到仍存在的触发入口。淡入 200ms、淡出 150ms，只改变透明度；淡出完成后才恢复背景交互。关闭中重新打开会取消旧动画；切页关闭弹窗。减少动态效果时立即开关。

Toast 在手机屏幕水平、垂直居中，使用宽高比 1:1、196×196px 的圆角正方形白底、中性边框和现有浮层阴影；上方为 64px 状态图标，加载图形使用24×24画布、半径9、线宽2的主题青绿渐变圆弧及18%透明度浅色底轨，外轮廓与其他状态图标对齐，下方为居中的15px／22px、600字重说明文字，图文间距16px，上下内边距8px、左右内边距24px。不显示关闭按钮，出现时以灰色蒙版覆盖手机区域，隔离背景页面及已有弹层的交互，不覆盖桌面侧栏。成功、错误、信息提示均可点击外部蒙版关闭，包括演示认证结果；加载提示不可点外部关闭，点击 Toast 卡片本身不关闭，不提供关闭规则的额外配置。默认展示中文状态名，等待检测结果时仅显示「等待检测结果，请稍候…」。错误使用 `alert` 语义，其余为 `status`；成功默认1.5秒后消失，错误和信息默认3.5秒，重复触发重置计时。加载提示持续到处理结束或被其他提示替换，检测等待结束或离页时关闭提示与蒙版；现有保存、演示认证、退出和重置完成提示使用成功状态。关闭 Toast 后恢复背景交互，若原有弹层仍在则继续隔离其下方页面。

## 模拟数据与隐私边界

- 健康数据均为固定样例，日期为 2026-10-01 至 2026-11-01，每日 08:30 一条，覆盖十月整月并保留11月1日的跨月记录；保留原 10月25日至31日的已有读数。区间内只筛选实际存在的记录，其他日期不生成数据。历史统计、趋势、最近10条、全部记录与详情共用这些样例；首页指标入口默认打开设计基准日 2026-10-31 的日区间，功能入口的固定检测时间独立保留。
- 血氧仪表展示85–100%的15格刻度，样例98%点亮13格；区间只是视觉设计，不表示医学阈值。首页和历史的糖尿病风险仍无样例记录，保持空态，不补造等级、分数或趋势；指尖结果页用演示编码0映射较低风险，三档映射与原生一致，不是临床结论。
- 功能页按浏览器当前时间与固定记录时间的实际差值显示分钟、小时或整天，记录日期不漂移。指尖联合、血压、血氧样例时间为 2026-10-31 08:30（北京时间）；面部为“尚未检测”，风险为“尚未评估”。时钟早于记录时显示“检测时间待核对”，不伪造刚刚检测。
- 面部预览是照片，指尖与血压预览是红色渐变，采集中脉搏波由本地函数生成且只用于面部与指尖页；面部平均心率来自本地样例。指尖与血压采集过程不计算指标，完成后分别展示固定四项结果与处理后 PPG、固定血压结果与处理后 PPG／SCG 及解读。三个检测页均不调用相机或算法，不请求相机、传感器、健康或通知权限，不保存或上传检测记录；血压的贴胸示意不接入姿态或接触识别，报告中的 SCG 不代表真实心震检测输出。
- 登录不是认证：任意非空用户名和密码只用于页面流转，不比对注册密码、不签发令牌。注册不创建真实账号，只返回登录并预填用户名，不模拟服务端完整密码规则。不要输入真实密码。
- 用户名、资料、偏好、反馈、注册用户名及筛选条件仅保存在当前标签页内存，刷新清除；密码不写入演示状态、日志、URL、LocalStorage 或 SessionStorage。
- 无后端请求、文件上传、真实通知或被动采集；本地服务 CSP 使用 `connect-src 'none'` 禁止页面发起连接请求。公开输入进入 HTML 模板前转义。
- 预览外框明确演示身份，固定样例与模拟边界见本节；手机业务界面不重复加入演示说明。插画不是经医学验证的操作指南，检测结果不可用于医疗诊断。真实设备、后端、原生运行、医学有效性和实体手机软键盘不属于此 Demo 的能力保证。

### 个人资料字段与草稿

“我的 → 个人资料”统一编辑基本信息与病史，字段按 `Req.Users.ProfilePatchRequest` 命名，仅模拟局部更新，不表示接入服务端：

| 字段 | 页面及提交语义 |
| --- | --- |
| `name` | 姓名／称呼选填，最多 50 字符；示例“小安”，主动清空为 null |
| `gender` | 0 未知／未填写、1 男、2 女；不能提交 null |
| `birthDate` | 保存 `YYYY-MM-DD`，不换算年龄；主动清空为 null |
| `heightCm`／`weightKg` | cm／kg，正数、最多两位小数，上限分别为 999.99／9999.99；主动清空为 null |
| `historyJson.isHypertensive` | 高血压：有／无／不清楚，默认不选中 |
| `historyJson.isDiabetic` | 糖尿病：有／无／不清楚，默认不选中；不把高血糖等同糖尿病 |
| `medicalHistory` | 其他病史选填，可补充未确诊高血糖；主动清空为 null |

只提交相对已保存状态变化的字段，缺席字段不覆盖。病史“有”为 true、“无”为 false；明确回答改为“不清楚”时生成 null 并删除本地对应键，再次打开按未填写展示，不默认“无”，保留另一病史和扩展内容。关闭或离页不保存草稿，部分填写或全部留空均可保存。刷新或重置恢复初值，不上传、不生成诊断或风险结论。

## 必要视觉约束

完整主题规则与令牌总览见 [前端开发规范](../development/frontend-development.md)。Demo 在 `styles.css` 映射 `apps/native/src/shared/theme/theme.ts`，不导入 React Native 平台模块、不维护第二套色表。卡片和弹层采用 22px 圆角与对应阴影，输入框为 8px 圆角，主按钮为胶囊形、白色文字；保留各页和窄屏的差异，不强行统一所有边距。渐变白字不构成 WCAG AA 对比度保证，界面仅提供浅色、简体中文。

- 首页心率／风险复用玫红装饰色，呼吸率复用品牌青与白色肺部；面部平均心率使用心率玫红 token，脉搏波使用主题青绿。状态同时使用文字和图形，不只依赖颜色。首页心率装饰波纹周期为 4.8 秒，仅影响透明度与缩放。
- 首页“更多健康指标”为等高四宫格，最低卡片高度 148px，图标和血氧仪表不随卡片拉伸。功能页按部位卡片文字居左、操作照片在右，用混合与透明蒙版融入背景；无扰心率检测卡片使用健康卡渐变与首页同源心率图标开关，采用白色滑块，以灰色轨道及图案、青绿主题轨道及深青图案区分关闭和开启，开启时播放青绿双波纹。首次引导保留原有四幅本地 SVG 的比例、白色贴纸边与层次，不运行时计算、不拉伸。
- 登录／注册共用居中品牌组：64px 标志，右侧 26px 名称及 12px Slogan，文字左对齐；首页使用 40px 标志和 24px 名称。账户退出按钮使用错误反馈色至心率玫红色的 105° 渐变，与登录按钮位置和尺寸一致。
- 首页及功能页在标题区域放置各自的健康参考声明，不在页面底部重复；历史声明仅放在测量记录下方。准备页图片下方保留“非医疗设备检测结果仅供参考，请勿用于医疗诊断”。糖尿病风险插画以血滴、GLU 和葡萄糖图形表达风险功能，不展示血糖检测结果。
- 优先让常用竖屏一屏展示，但不以隐藏溢出裁掉内容。页面、侧栏与弹层隐藏滚动条；矮屏、横屏、文字放大、长表单或错误信息使内容超长时仍允许滚动，底部主操作必须可到达。
