# 心沐交互设计 Demo

独立的移动端交互演示，不连接真实业务。品牌与操作照片直接读取 `apps/native/assets/`，不维护副本；历史趋势和脉搏波使用根目录开发依赖 ECharts 6.0.0，经本地资源映射提供，不依赖 CDN。Demo 的模拟行为不代表原生 App 的采集或认证能力。

## 启动

在项目根目录执行：

```sh
pnpm install --frozen-lockfile
node docs/design-demo/server.mjs
```

浏览器访问 <http://127.0.0.1:4173/>；安装依赖后可直接启动，按 `Ctrl+C` 停止。端口占用时可指定其他端口：

```sh
node docs/design-demo/server.mjs 4174
```

服务只监听 `127.0.0.1`，同一 Wi-Fi 的其他设备不能直接访问。必须通过 HTTP 访问，不使用 `file://`。其他静态托管需映射品牌 SVG、应用图标、favicon 和 `op1.png`／`op2.png`／`op3.png`，并将 `/vendor/echarts.esm.min.js` 映射到 `node_modules/echarts/dist/echarts.esm.min.js`。服务仅支持 GET／HEAD，按精确白名单提供文件，不开放 assets 或 node_modules 目录、不代理 API；资源缺失返回错误，不以远程资源替代。

## 交互与状态

### 导航与首次体验

- 桌面左侧为思维导图式导航，“页面”下分主界面、账户、启动展示、首次体验；健康与我的各有未登录／已登录状态节点。面部、指尖和血压检测页位于对应引导下，可独立预览。点击切页，不支持拖拽画布。
- “组件”下提供弹窗和四种 Toast（`success`、`error`、`loading`、`information`）预览；Toast 分组始终展开，父节点不作为按钮。组件预览不切页、不修改演示数据。
- 桌面侧栏宽 344px，手机预览宽 390px；矮窗口侧栏可独立滚动。移动端全屏展示，隐藏桌面侧栏，保留“健康、功能、历史、我的”底部导航；选中 Tab 的图标和文字使用品牌主色 `--primary`，图标为实心填充，未选中使用线性图标，两态复用相同轮廓，尺寸、位置与布局保持一致；历史图标的时针在实心状态以留白呈现。
- 外部操作区位于手机预览下方，与手机同宽、右对齐；一行放不下时自动换行，不超出手机左右边界。“重置演示”与仅在指尖、血压页显示的模拟操作同组；移动端仅在这两个检测页显示这组外部操作，可滚动到达。血压额外提供「模拟贴靠胸口」和「模拟覆盖丢失」。
- 浏览器前进／后退可切页；功能分类支持左右方向键及 `Home`／`End`。历史指标使用原生下拉选择，同时提供左右切换按钮。
- 桌面图标进入开屏并停留；开屏只有标志、名称与 Slogan，无按钮或定时跳转。首次引导从侧栏、设置或 `#onboarding` 独立进入，按“功能引导 → 授权引导 → 首页”流转；功能引导可跳过，授权引导可返回。两步均保留明确进度和可访问按钮，不展示虚构读数、不提供权限开关。
- 手机内可从“我的 → 右上角设置”查看启动页、重看功能引导或重置演示，三个入口相互独立。

### 首页、功能与账户

未登录首页的血压和四项指标读数为 `--`，记录位置显示“暂无记录”，血氧仪表为空刻度；心率、呼吸率及风险插画保留正常颜色和透明度。主按钮及指标入口进入登录，演示登录后恢复样例读数与检测入口。首页和我的随登录／退出同步切换；侧栏状态预览只设置本地身份，不修改资料、不向手机业务界面增加状态按钮。

功能页默认“按检测部位”：面部对应面部心率，指尖进入通用指尖脉搏检测准备页、不预选指标，指尖＋胸口对应血压估计。“按指标”保留五项入口，其中“心率与呼吸率”不拆分；两种分类的血压入口均进入血压准备页。返回保留分类，刷新或重置恢复默认。面部入口不以历史样例冒充检测结果。

“我的”未登录时可点击账号区或底部登录按钮；登录后显示称呼与退出按钮。两种按钮位置一致、宽度均为内容区的 90%。登录、注册通过校验后和退出操作均进入约 1 秒加载态，按钮禁用并与加载 Toast 同步；完成后切换本地状态并提示成功。校验失败不加载，重复提交不重复执行；等待中切页会取消未完成操作，避免旧计时跳回账户页。

### 历史与趋势

历史页按“指标 → 时间区间 → 趋势 → 测量记录”组织，借鉴[华为运动健康血压卡片](https://consumer.huawei.com/cn/support/content/zh-cn15923789/)的周期查看与逐条详情结构，视觉沿用项目主题，不引入参考产品的配色或医学等级。

- 顶部只显示当前指标，左右箭头按顺序切换血压、心率、呼吸率、血氧饱和度和糖尿病风险；点击指标名称展开原生下拉列表直接选择，首尾箭头按当前位置禁用，两种入口共用同一筛选状态。
- 时间区间提供日、周、月和自定义，复用功能页的 52px 浅灰凹槽、青绿渐变滑块与 240ms 滑动过渡。周按周一至周日、月按自然月计算；默认定位最近固定样例所在周，即 2026-10-26 至 2026-11-01。左右箭头切换相邻周期，切换指标保留区间，切换周期类型围绕当前日期定位。
- 自定义按钮及日期旁的日历入口打开日期弹层，确认有效范围后更新页面；反向范围在弹层内提示，关闭不提交草稿。自定义区间不显示周期切换箭头，点击日期仍可重新选择。切页返回保留筛选，刷新或重置恢复默认。
- 趋势卡背景复用健康卡渐变 token，以 ECharts SVG 渲染折线，显示当前区间均值、数值范围与记录数，血压两项分别统计。横轴按所选区间的日历日期和固定 08:30 时刻定位，单日显示时间刻度；缺失日期不补零，单条记录仅画点、不连线。点击或移动到数据点时显示日期、时间和读数，血压提示同时展示两项值；点击图例按钮可隐藏或恢复曲线，但不改变统计与记录。血压用实线／虚线区分收缩压和舒张压；心率复用玫红、血氧复用蓝色 token，读数保持中性，不表示健康等级。指标和区间切换复用同一实例并完整替换序列，尺寸变化调用 `resize()`，离页释放图表、图例监听与尺寸观察。
- 主页面按倒序显示当前区间最近三条记录，每条包含日期、时间、读数与单位；点击进入详情。“查看全部”展示同一区间完整倒序列表，并复用单条详情入口。无记录显示空态，糖尿病风险不生成分数、等级或趋势。
- 保留青绿柔和页面渐变、健康卡渐变、22px 圆角与系统字体；不显示“健康历史”页头，健康参考声明只放在测量记录下方，随内容滚动；列表通过分隔线组织，不给每条记录重复添加阴影。

### 检测准备与声音提醒

三个准备页分别使用 `op3.png`（面部完整入镜）、`op1.png`（指腹轻覆后摄）、`op2.png`（后摄覆盖并贴胸持机），保留圆形照片、水纹画框、四项准备提示、免责声明和“以后不再提示”。从功能入口进入时顶栏显示对应目标，直接地址为通用“检测准备”；不暗示一次可测出全部指标。

跳过偏好按三种方式分别保存在当前标签页，刷新或重置清除。侧栏和直接地址始终允许查看准备页并取消勾选；返回来源页，直接打开默认返回功能页。复选框保留原生语义、文字整行点击、空格切换和键盘焦点框；“开始检测”按钮宽度为内容区的 90%、高 48px。

点击开始先在手机区域内显示声音提醒，要求打开声音并调至清晰可闻，但不读取或调整系统音量、不播放音频。确认“立即检测”后，面部进入待开始页，指尖与血压进入等待指尖放置页，不生成检测结果。关闭、返回准备、遮罩或 `Esc` 只取消提醒并归还焦点；跳过准备页仍须确认提醒，取消后留在入口页。

### 面部心率演示

- 状态为 `ready → running → ended`。初始相机占位、平均心率 `--`、计时 `00:00`、空波形，不自动检测；点击开始后显示裁切照片与静态中心圆框。圆框仅提示构图，不代表人脸识别或信号质量。
- 开始后先提示“获取信号中”，第 3 秒起每 2 秒纳入一条本地样例，显示累计平均心率的四舍五入值。提示依阶段为“点击开始／获取信号中／保持稳定／检测已结束”。按钮依次为“开始检测／结束检测／重新检测”；结束冻结读数、计时与波形，重测清空并重新开始。计时为 `mm:ss`，超过一小时累计分钟，不增加小时位。
- 摄像预览保持宽 5、高 4；在页面留白外额外左右各留 4px，高度不足时宽高一起等比缩小，保留四角短线与柔和阴影。中心圆框按预览高度缩放、上限 140px。
- 底部使用左右贴边、无阴影的全宽白色面板，仅顶部两角为 22px 圆角，容纳读数、计时、状态、波形和按钮，不提供插画、原理图或分页。数据行使用 `space-between`，不设横向或竖向分隔线；心率组靠左、状态组靠右，各组内部内容居中，计时位于中间且左右各留 8px，状态区占行宽 30%。心率使用固定三位数字槽位 `3ch`，单位“次/分”为 12px、不收缩且基线对齐，避免读数变化推移单位；状态提示完整单行，不截断。按钮宽度为内容区的 90%、高 48px。
- 波形弹性填满标题与按钮之间的剩余高度，常规最小 128px、矮屏最小 100px；矮屏允许整页滚动，手势条位于按钮之后。

### 指尖演示

主流程为 `ready → covering → running → completed`：等待放置后，由手机外的「模拟放置指尖」启动覆盖；覆盖程度约 2.4 秒从 0% 增至 100%，满环保持约 0.4 秒，再开始独立的 30 秒倒计时。覆盖未满与满环待开始是 `covering` 内的两个展示状态，不新增流程阶段或模拟按钮。

| 展示状态／触发条件 | 预览中央提示 | 底部状态 | 底部辅助说明 |
| --- | --- | --- | --- |
| 等待放置：初次进入或重测复位，`ready` | 手指未完全覆盖镜头，请调整位置 | 准备检测 | 指腹轻放，不要按压 |
| 未检测到手指：`ready` 下点击外部模拟按钮 | 未检测到手指，请按示例放置手指，或切换摄像头 | 准备检测 | 请调整手指放置的镜头 |
| 未覆盖完全：`covering`，覆盖程度 1%–99% | 手指未完全覆盖镜头，请调整位置 | 调整手指 | 让指腹完整覆盖后置镜头 |
| 覆盖完成：`covering`，覆盖程度 100% | 已完全覆盖，即将开始检测 | 准备开始 | 保持轻覆，检测即将开始 |
| 检测中：满环停留结束，进入 `running` | 正在检测，请勿移动手指 | 检测中 | 自然呼吸，保持手指稳定 |
| 检测完成：30 秒结束，进入 `completed` | 检测完成，可以移开手指 | 检测完成 | 本次检测已结束 |

指尖与血压共用等待放置、未完全覆盖的中央提示“手指未完全覆盖镜头，请调整位置”；仅统一文案，不合并状态、覆盖环或流程推进规则。

未检测到手指在等待阶段更新提示并打开操作指导弹窗，不启动覆盖或检测、不增加自动超时，也不调用或切换真实摄像头。弹窗并排展示“轻覆后置镜头”和“换一颗后置镜头”：前者复用说明页的后摄持机插画，后者循环演示手指抬起、移到相邻后置镜头及对应镜头高亮，不表示切换前后摄。弹窗只有「我已知晓」按钮，不显示关闭图标，点击遮罩或按 `Esc` 不关闭；确认后仍等待放置，焦点回到外部触发按钮。

点击「模拟放置指尖」后恢复放置提示，随覆盖程度依次进入未覆盖完全、覆盖完成及检测中。准备与覆盖确认期间剩余时间保持 `00:30`；检测开始自动切到脉搏波页，切回说明不暂停计时。完成后保留 100% 覆盖环、`00:00` 和本轮波形，仍可回看；点击「模拟放置指尖」清空本轮覆盖与波形、返回等待放置及说明页，再次点击才模拟下一轮放置。

外部演示按钮固定显示「模拟放置指尖」和「模拟未检测到手指」，不随检测阶段或预览提示同步改字；覆盖确认及检测中仅改变禁用状态。

覆盖环只表示覆盖程度，检测期间维持 100%，绝不复用为计时进度。百分比使用固定 **88px** 宽圆角矩形标签，居中叠放在圆形预览底部边缘，不使用波浪底板或圆形下方的覆盖状态文字；环与底轨均为 7px。操作提示以半透明白色毛玻璃浮层居中显示在圆形预览内，背景为 72% 不透明度的主题白色、12px 背景模糊与 140% 饱和度；文字使用正文色、14px 字号和 600 字重，左右内边距 16px，最大宽度为黑色镜头区域的 80%（含内边距和边框），宽度随文字收缩，仅在空间不足时自然换行，最多显示两行，超出部分以省略号显示；随检测状态更新，不阻断操作。指尖与血压页共用此提示样式，不影响指导弹窗。预览等比例放大，占用原下方说明与间隔的空间，底部状态及波形面板保持原有布局。预览保留静态柔和阴影，覆盖确认及检测中在预览外侧播放两道错开的扩散波纹，等待及完成时停止。

状态标签和说明左对齐，倒计时位于右侧且内部居中；状态与倒计时不随分页移动。说明页并排展示“手机背面轻覆后摄／手机正面稳定持机”两幅 SVG，窄屏按可用高度缩小图解但保留文字。流程说明与脉搏波采用横向原生滚动及整页吸附，可触摸滑动、点击 44×44px 分页按钮，或使用左右方向键及 `Home`／`End`。波形绘图区内的水平手势和方向键仅用于历史回看，不触发外层切页；可在标题区域滑动或点击分页标识切回说明。当前页由实际滚动位置决定；非当前页以 `inert` 隔离交互和读屏，保留滑动中的画面。分页标识为主题色长条／中性圆点，以 200ms 伸缩和颜色过渡切换，不改变点击区域。准备阶段可查看空波形；调整尺寸保留当前页；返回按钮回到指尖准备页。检测页不另放底部免责声明，引导页保留。

### 血压演示

`#blood-pressure-measurement` 从血压准备页确认声音提醒后进入，也可从侧栏直接预览；首页血压与功能页的血压入口共用此流程。返回按钮回到血压准备页。页面沿用指尖的圆形预览、覆盖环、百分比、底部状态与倒计时位置，以及原生横向分页和点击／键盘切页，不挂载或生成实时脉搏波。

- **第一阶段：放置指尖。**两幅插画与指尖页共用，分别说明轻覆后置镜头、正面稳住手机；未检测到手指的外部模拟入口与指导弹窗也共用。等待及覆盖确认期间保持 `00:30`。
- **第二阶段：贴靠胸口。**覆盖填满并完成短暂确认后，自动切到第二页，同时提示“保持手指覆盖，将手机轻贴胸口”。两幅 SVG 分别从用户提供的《手机按压胸口六帧动画.gif》与《手机贴胸动画帧.gif》的原始色块边界提取，保留双肩透视、手部轮廓、食指覆盖镜头及自然的手臂连接，不另行拼画人体结构或旋转手机。衣物使用浅灰填充与灰青描边，皮肤使用浅肤色与柔和轮廓线，保留袖窿线、袖口内侧轮廓与轻量阴影，去除纹理与关节细节；深色仅保留真实镜头区域，不保留手部黑色碎片，人物底部裁切处不画横向封口描边。第一幅沿用斜侧移近胸口的动作，第二幅沿用正面贴靠左胸的动作，均只展示颈部以下。按原 GIF 的六帧同步循环，每帧 320 ms、总周期 1.92 秒；前 3 帧无高亮，后 3 帧贴靠时在手机上方显示青绿短线，不对手型做插值变形，切离第二页后停止。高亮仅为操作提示，不表示系统已识别贴胸状态，不直接嵌入参考 GIF。
- **皮肤阴影：**按原 GIF 各帧明暗，在袖口下方、前臂下缘与手掌握持处叠加低透明度肤色阴影，随六帧动作同步变化；阴影裁剪在皮肤内，不影响衣物、轮廓与贴靠高亮，不新增黑色或关节描线。
- 外部「模拟放置指尖」沿用约 2.4 秒覆盖递增和约 0.4 秒满环确认，稳定后进入等待贴胸状态，倒计时保持 `00:30`，镜头内提示“保持手指覆盖，将手机轻贴胸口”，并启用「模拟贴靠胸口」。点击该按钮后才开始独立的 30 秒倒计时，提示改为“正在检测，保持手指覆盖和贴胸稳定”；贴胸按钮在其他状态禁用，不接入真实贴胸识别。完成后保留满环、`00:00` 和贴胸指引，不展示血压值、不更新健康记录。
- 「模拟覆盖丢失」在血压覆盖确认、等待贴胸及检测中可用。触发后覆盖回到 0%、自动切回第一阶段并将倒计时复位为 `00:30`；再次模拟放置后须重新确认覆盖并模拟贴靠胸口，才开始完整一轮，不拼接中断前的时长。完成后点击「模拟放置指尖」先复位，下一次点击再模拟放置。


### 波形、动态效果与资源生命周期

面部和指尖共用 `pulse-wave.js` 管理模拟 PPG：ECharts SVG 折线、30Hz 采样，按采样时间只追加新点，保留本轮完整历史，重测或离页时清空。面部从获取信号后开始记录波形时间，指尖从检测开始记录；不保存或上传历史。每屏固定 **6 秒**、纵轴范围固定，仅允许水平平移，禁止滚轮及双指缩放。开始时波形从右侧出现并向左累积，未满六秒时左侧留空，不开放历史平移；标题范围从采样零秒开始，不显示负时间。检测中默认跟随最新窗口，拖动回看后保持所选时间段，采样继续；绘图区右侧垂直居中浮现 44×44px 的圆形“回到最新”图标，居中范围不包含标题栏，点击后回到最新窗口并恢复跟随，随后隐藏。结束后仍可回看全部历史并使用同一浮层返回最后窗口。绘图区聚焦后支持左右方向键逐秒平移、`Home` 回到起点、`End` 返回最新。标题仅显示当前窗口的秒数范围。

两处脉搏波统一使用 1.5px 细线与品牌主色 `--primary`，保留左侧渐隐。坐标绘图区四周使用薄荷绿 `--mint` 的浅色模糊内阴影与 12px 圆角，形成朦胧边缘，中心留白；不使用纵向渐变，不随波形填充，也不改变区域高度及坐标留白。

关闭 ECharts 入场及更新插值动画，窗口随 `requestAnimationFrame` 刷新，历史点不变形；减少动态效果时改为每秒更新，仍追加实际模拟采样。脉搏波区域高度不变，坐标绘图区保留原有上下 8px 间距，不追加百分比布局留白；仅通过固定纵轴数值范围，让波形数据落在坐标高度的 10%–85% 内（底边为 0%，底部约留 10%、顶部至少留 15%），不改写采样幅度，也不随采样自动缩放。隐藏 X 轴线、刻度文字与刻度线，不显示网格和 Y 轴，窗口左侧 14% 范围渐隐。透明端点使用主题色 RGBA 零透明度，避免 SVG 将 `transparent` 解释为无效色而产生黑色端点。图表通过 `ResizeObserver` 同步容器尺寸，不维护 Canvas 备用渲染路径。

隐藏浏览器标签页时暂停检测时钟；指尖与血压的覆盖时钟也暂停，返回后从原进度继续。离开检测页取消动画帧、断开尺寸观察、移除监听并销毁已有图表；指尖与血压的外部模拟按钮同时隐藏。

开启系统“减少动态效果”时，波形不连续滚动，改为每秒刷新，采样历史及计时继续；状态和 Toast 的加载图标静止，指尖外部波纹隐藏但保留阴影，分页直接定位且标识无过渡，功能分类立即切换，首页装饰心率波纹静止。装饰动效不代表实时心率或设备采集状态。

### 弹窗与 Toast

弹窗、遮罩和 Toast 均限制在手机区域，不覆盖桌面侧栏。弹窗居中，长内容内部滚动；打开后手机背景与外部演示操作不可交互，`Tab`／`Shift+Tab` 在弹窗内循环。通用弹窗可通过关闭按钮、遮罩和 `Esc` 关闭，指尖未检测到手指的指导弹窗仅通过确认按钮关闭；焦点回到仍存在的触发入口。淡入 200ms、淡出 150ms，只改变透明度；淡出完成后才恢复背景交互。关闭中重新打开会取消旧动画；切页关闭弹窗。减少动态效果时立即开关。

Toast 位于手机顶端下方 60px、左右各留 16px，使用白底、中性边框、状态图标与中文状态名，均可手动关闭。错误使用 `alert` 语义，其余为 `status`；成功、错误、信息在 3.5 秒后消失，重复触发重置计时。加载提示持续到被替换或关闭，不模拟真实异步结果；现有保存、演示认证、退出和重置完成提示使用成功状态。

## 模拟数据与隐私边界

- 健康数据均为固定样例，日期为 2026-10-25 至 2026-10-31；区间内只筛选实际存在的记录，其他日期不生成数据。历史统计、趋势、最近三条、全部记录与详情共用这些样例。
- 血氧仪表展示 85–100% 的 15 格刻度，样例 98% 点亮 13 格；区间只是视觉设计，不表示医学阈值。糖尿病风险无样例结果，不生成分数、等级或趋势。
- 功能页按浏览器当前时间与固定记录时间的实际差值显示分钟、小时或整天，记录日期不漂移。指尖联合、血压、血氧样例时间为 2026-10-31 08:30（北京时间）；面部为“尚未检测”，风险为“尚未评估”。时钟早于记录时显示“检测时间待核对”，不伪造刚刚检测。
- 面部预览是照片，指尖与血压预览是红色渐变，脉搏波由本地函数生成且只用于面部与指尖页；面部平均心率来自本地样例，指尖与血压不生成健康指标。三个检测页均不调用相机或算法，不请求相机、传感器、健康或通知权限，不保存或上传检测记录；血压的贴胸示意不接入姿态或接触识别。
- 登录不是认证：任意非空用户名和密码只用于页面流转，不比对注册密码、不签发令牌。注册不创建真实账号，只返回登录并预填用户名，不模拟服务端完整密码规则。不要输入真实密码。
- 用户名、资料、偏好、反馈、注册用户名及筛选条件仅保存在当前标签页内存，刷新清除；密码不写入演示状态、日志、URL、LocalStorage 或 SessionStorage。
- 无后端请求、文件上传、真实通知或被动采集；本地服务 CSP 使用 `connect-src 'none'` 禁止页面发起连接请求。公开输入进入 HTML 模板前转义。
- 预览外框明确演示身份，固定样例与模拟边界见本节；手机业务界面不重复加入演示说明。插画不是经医学验证的操作指南，检测结果不可用于医疗诊断。真实设备、后端、原生运行、医学有效性和实体手机软键盘不属于此 Demo 的能力保证。

### 个人资料字段与草稿

“我的 → 个人资料”统一编辑基本信息与病史，字段按 `Req.Users.ProfilePatchRequest` 命名，仅模拟局部更新，不表示接入服务端：

| 字段 | 页面及提交语义 |
| --- | --- |
| `name` | 姓名／称呼选填，最多 50 字符；示例“小安”，主动清空为 null |
| `gender` | 0 未知／未填写、1 男、2 女；不能提交 null |
| `birthDate` | 保存 `YYYY-MM-DD`，不换算年龄；主动清空为 null |
| `heightCm`／`weightKg` | cm／kg，正数、最多两位小数，上限分别为 999.99／9999.99；主动清空为 null |
| `historyJson.isHypertensive` | 高血压：有／无／不清楚，默认不选中 |
| `historyJson.isDiabetic` | 糖尿病：有／无／不清楚，默认不选中；不把高血糖等同糖尿病 |
| `medicalHistory` | 其他病史选填，可补充未确诊高血糖；主动清空为 null |

只提交相对已保存状态变化的字段，缺席字段不覆盖。病史“有”为 true、“无”为 false；明确回答改为“不清楚”时生成 null 并删除本地对应键，再次打开按未填写展示，不默认“无”，保留另一病史和扩展内容。关闭或离页不保存草稿，部分填写或全部留空均可保存。刷新或重置恢复初值，不上传、不生成诊断或风险结论。

## 必要视觉约束

完整主题规则与令牌总览见 [前端开发规范](../development/frontend-development.md)。Demo 在 `styles.css` 映射 `apps/native/src/shared/theme/theme.ts`，不导入 React Native 平台模块、不维护第二套色表。卡片和弹层采用 22px 圆角与对应阴影，输入框为 8px 圆角，主按钮为胶囊形、白色文字；保留各页和窄屏的差异，不强行统一所有边距。渐变白字不构成 WCAG AA 对比度保证，界面仅提供浅色、简体中文。

- 首页心率／风险复用玫红装饰色，呼吸率复用品牌青与白色肺部；面部平均心率使用心率玫红 token，脉搏波使用主题青绿。状态同时使用文字和图形，不只依赖颜色。首页心率装饰波纹周期为 4.8 秒，仅影响透明度与缩放。
- 首页“更多健康指标”为等高四宫格，最低卡片高度 148px，图标和血氧仪表不随卡片拉伸。功能页按部位卡片文字居左、操作照片在右，用混合与透明蒙版融入背景；按指标保留五幅本地 SVG 的比例、白色贴纸边与层次。五幅插画使用 96×84px 展示框，卡片图文间距为 8px；血压、血氧、风险插画在归一尺度上缩小约 10%，不运行时计算、不拉伸。
- 功能分类使用连续浅灰凹槽及主题渐变选中块，选中块横移 240ms、文字过渡 180ms，整体高 52px；不以独立未选中阴影或实线边框替代。
- 登录／注册共用居中品牌组：64px 标志，右侧 26px 名称及 12px Slogan，文字左对齐；首页使用 40px 标志和 24px 名称。账户退出按钮使用错误反馈色至心率玫红色的 105° 渐变，与登录按钮位置和尺寸一致。
- 首页、历史及功能页在标题区域放置各自的健康参考声明，不在页面底部重复；准备页图片下方保留“非医疗设备检测结果仅供参考，请勿用于医疗诊断”。糖尿病风险插画以血滴、GLU 和葡萄糖图形表达风险功能，不展示血糖检测结果。
- 优先让常用竖屏一屏展示，但不以隐藏溢出裁掉内容。页面、侧栏与弹层隐藏滚动条；矮屏、横屏、文字放大、长表单或错误信息使内容超长时仍允许滚动，底部主操作必须可到达。
