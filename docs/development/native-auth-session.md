# Native 认证会话与服务端缓存

## 显式运行配置

应用只在同时提供 `EXPO_PUBLIC_API_BASE_URL` 和 `EXPO_PUBLIC_CHANNEL` 时组装云端服务。服务地址是不含 `/api/v1` 的 HTTP(S) 根地址；渠道是普通渠道，不能为 `manager`。配置不从系统语言、时区或设备型号推断。模板位于 `apps/native/.env.template`；本机可在 `apps/native/.env` 覆盖配置，该文件已忽略，不要把账号、密码或令牌放入 Expo 公开环境变量。

缺少任一配置时，应用仍可浏览原生产品页，但不会创建默认 API 客户端，也不会猜测要恢复哪个作用域。显式配置存在时，`apps/native/index.ts` 在注册根组件前导入 `src/app/bootstrap.ts`；该模块创建唯一的云端客户端、SecureStore 凭据适配器、认证管理器和 QueryClient，并启动一次会话恢复，因此不依赖 React 页面挂载。

## 认证状态和凭据

认证 Nano Store 只公开 `restoring`、`anonymous`、`authenticated` 和 `unavailable`。已确认时只包含 `userId`、`username`；不保存令牌、密码或完整资料。注册返回账号但不建立会话；登录先保存完整令牌对，再调用本人账号接口确认身份。

`expo-secure-store` 适配器把 Access/Refresh Token 作为一条 JSON 记录整体读写。存储键由规范化服务根地址和普通渠道确定，因此切换服务或渠道不会混用令牌。读写删除失败转成不含底层异常的 `CredentialStorageError`；不会回退到 MMKV、普通文件、Query Cache 或日志。

启动时没有记录则进入 `anonymous`。身份确认收到明确认证失效时按普通受控刷新规则处理；网络、超时或 5xx 使状态变成 `unavailable`，保留仍可能有效的安全凭据，不伪装成未登录。刷新凭据明确失效时删除本地令牌对。安全存储故障也发布 `unavailable`，受保护操作在状态恢复前被拒绝。

## 受保护请求与退出

应用 auth 模块识别 `401 / INVALID_TOKEN`，同一会话并发共享一次 Refresh Token 轮换；成功写入整对令牌后才更新内存 Access Token，并至多重发原业务请求一次。已使用新令牌的迟到 401 不再启动重复刷新。403、其他业务错误、网络失败和超时不触发通用刷新/重试；登录和刷新请求本身不进入受保护重发流程。

退出或重新登录会立即推进会话代次、移除内存 Access Token、中止旧代次受保护请求并清理相应查询和变更缓存。安全凭据写入与删除串行化，旧代次不能把晚到的令牌写回当前会话。退出会尽力用最新 Refresh Token 请求远端撤销；本地清理与远端确认分别返回结果。本地删除失败返回 `credentialDeletion: failed` 并将状态标为 `unavailable`，不伪装成本地退出成功。远端网络失败仍允许本地退出，但不会显示为已确认远端撤销；客户端丢弃旧 Access，不表示服务端立即撤销了已签发的 Access。

## React Query 数据边界

QueryClient 对查询和变更都关闭通用自动重试，不安装缓存持久化。本人账号、资料、模型目录、任务列表和详情等受保护资源按服务根地址、渠道和会话代次生成查询键；查询配置只在当前代次已确认认证时启用，并通过 auth 受保护请求入口传递取消信号。

注册、登录、刷新和登出直接消费 SDK 结果，不进入通用 `QueryCache` 或 `MutationCache`。资料 PATCH 只提交明确字段，成功后以服务端返回的完整资料替换当前代次资料缓存。退出/换账号仅清除匹配的受保护查询与变更，不删除其他服务、渠道、代次或非认证偏好。

产品页直接消费这一认证状态：仅 `authenticated` 展示固定本地 mock；`anonymous`、`restoring`、`unavailable` 不展示 mock 健康读数。mock 不进入 Query Cache 或持久化，注册、登录、登出仍复用现有 auth 模块与服务端请求。

## 登录、注册与退出操作反馈（2026-11-04）

- 本地表单校验仍以内联字段提示为准；登录、注册请求错误使用不可关闭结果 Toast，不写入字段错误。登录与注册分别显示过程文案，提交锁同时阻止按钮和键盘重复提交；登录成功进入“我的”，注册成功返回登录页并预填用户名。
- 认证过程 Toast 不显示关闭控件，触摸、横向滑动和系统返回均不能关闭；开发区保留普通可关闭 Toast。过程 Toast 不自动过期，替换结果后从替换时开始计时 3.5 秒。开发区的“认证过程到结果（不可关闭）”在 1.2 秒后受控替换为结果，用于原生验收，不发起真实请求。
- 登录、注册和退出按钮 Loading 使用原有 `LoaderCircle` 图形，按主题 `loadingCycle`（900 ms）旋转；减少动态效果时静止。按钮仍不可重复触发，Loading 保留完整主题渐变与白色前景，普通禁用态仍为灰色。按钮 Loading 不显示原有装饰箭头。
- 退出只在确认后开始；本地会话可先转为游客，但延迟中的退出命令仍占用操作区并显示“退出中…”，不允许从账号入口开始新登录。结果分别说明凭据删除失败、远端撤销未确认、成功或意外失败；远端未确认不会呈现为已确认撤销。
- Pixel 5 AVD（Android API 37）配合本地内存 HTTP mock 和受控延迟，实际检查注册、登录、失败重试、退出，按钮与 Toast 同步 Loading，过程替换结果及跨导航保留。普通成功 Toast 可通过关闭控件关闭；认证 Toast 在点击、滑动和系统返回后仍可见。真实生产后端和实体设备未在本轮重复验证。
- `AccessibilityInfo` 减少动态效果通过 Android `transition_animation_scale=0` 检查；加载图标保持静止后恢复到原值 `1.0`。本轮使用的临时 mock 账号已退出，不在文档中保存账号凭据。
- Pixel 5 AVD 小屏（1080×1920）和 `font_scale=1.3` 检查中，首页与“我的”内容可滚动，认证字段、提交按钮和表单下方的模式切换仍可读；结束后恢复物理分辨率 1080×2340、字号比例 `1.0`。
- 登录请求 Loading 时，根级 Toast 与 `AuthToolbar` 重叠，遮住页面返回和顶部模式切换控件；Android 系统返回仍可用，且不会关闭 Toast。该遮挡本轮未修改。
- 点击用户名框后，AVD 的 Gboard 仅显示侧边快捷条；`show_ime_with_hard_keyboard` 设为 `0` 或 `1` 均未显示完整软键盘，因此键盘弹起时的布局和遮挡未能验证。设置已恢复为 `0`。
