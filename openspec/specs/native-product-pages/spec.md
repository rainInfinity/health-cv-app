# native-product-pages Specification

## Purpose

为心沐原生应用提供可由游客自由访问的中文健康主页、功能目录和用户中心，并将真实账号认证与开发阶段的健康展示数据分开，使空态、账号状态变化及尚未开放的入口具有一致且可验证的行为。

## Requirements

### Requirement: 产品页面可由游客自由浏览
应用 MUST 提供健康主页、功能页和我的页面，游客 MUST 能自由访问，不因未登录强制跳转认证。页面 MUST 沿用已确认设计、品牌资源及浅色主题，不使用网页替代原生交互。

#### Scenario: 游客浏览产品页面
- **WHEN** 无已保存会话的用户完成或跳过首次引导
- **THEN** 能在主页、功能和我的之间切换，我的显示游客身份与登录注册入口

#### Scenario: 缺少云端配置
- **WHEN** 应用未配置云端服务
- **THEN** 本地页面仍可浏览，认证入口说明服务不可用，不模拟登录成功

### Requirement: 健康展示严格由确认认证状态决定
应用 MUST 仅在 `authenticated` 展示固定 mock 健康读数及对应时间，不添加示例或演示数据说明。`anonymous`、`restoring` 和 `unavailable` MUST 展示空健康内容；后两者 MUST 在账号区域表达真实状态，不冒充游客。mock MUST 不写入服务端资源、账号资料或采集状态。

#### Scenario: 游客空态
- **WHEN** 当前状态为 anonymous，用户查看主页或详情
- **THEN** 读数显示 --、时间显示暂无记录，仪表无有效填充，不出现评估结论、样例数值或趋势

#### Scenario: 认证成功
- **WHEN** 登录已保存凭据并完成服务端身份确认
- **THEN** 主页与详情显示固定 mock 内容，风险和面部独立记录等没有 mock 的项目仍为空，不编造结果

#### Scenario: 退出时详情仍打开
- **WHEN** 认证明确失效或退出导致当前会话不再已确认，而已有详情仍可见
- **THEN** 主页、详情和功能时间信息均更新为空态，不残留登录态读数

#### Scenario: 会话恢复暂不可确认
- **WHEN** 认证恢复因网络故障进入 unavailable
- **THEN** 产品页仍可浏览且健康内容为空，账号区说明暂不可确认，不删除凭据或显示为已退出

### Requirement: 功能目录按检测部位与指标提供入口
功能页 MUST 保留“按检测部位”和“按指标”分类，默认前者。部位分类保留面部、指尖、指尖＋胸口三张照片卡片；指标分类保留指尖心率与呼吸率、面部心率、血压、血氧、糖尿病风险五项插画。两分类 MUST 共用方式、目标映射及设备级跳过偏好：未跳过进入准备，已跳过直达对应检测且不补声音提醒。游客不得强制登录；面部仍显式开始，指尖使用真实本地采集与展示算法，血压仍反馈尚未接入，不创建或上传云端任务。

#### Scenario: 游客点击测量入口
- **WHEN** 游客点击任一功能或主页测量入口
- **THEN** 不因身份强制登录；功能入口按方式及跳过偏好推进，主页既有入口不在本次改造范围。面部待开始页不启动设备，指尖承接明确入口完成授权及预览准备，覆盖稳定后才正式采集

#### Scenario: 功能最近测量信息
- **WHEN** 游客或已确认账号访问功能页
- **THEN** 游客所有测量时间为空，已确认账号仍仅显示既有固定数据对应时间及真实间隔；无记录和时钟早于记录分别如实表达，不将固定日期改成今天

#### Scenario: 按检测部位进入
- **WHEN** 用户尚未保存该方式跳过偏好，在默认分类点击面部、指尖或指尖＋胸口卡片
- **THEN** 分别进入对应准备页；面部目标仍为面部心率，指尖不预选指标，指尖＋胸口目标仍为血压估计；血压准备确认不新增采集页或设备行为

#### Scenario: 按指标进入
- **WHEN** 用户点击心率与呼吸率、面部心率、血压、血氧或糖尿病风险卡片
- **THEN** 保留原方式及目标映射；指尖目标共用真实指尖页，不按目标执行健康指标推理；面部规则不变，血压继续给出尚未接入反馈，不新建另一套检测

#### Scenario: 已保存跳过偏好的功能入口
- **WHEN** 用户勾选某方式“以后不再提示”后再次点击对应部位或指标卡片
- **THEN** 不显示引导或声音提醒；面部进入待开始页，指尖建立新的真实轮次并准备覆盖观测，血压仍在功能页反馈尚未接入，其他方式偏好不受影响

#### Scenario: 返回保留分类
- **WHEN** 用户选择按指标后进入准备或检测，再返回功能页
- **THEN** 原分类仍选中，不重置为按检测部位，分类选中状态与可见卡片一致

#### Scenario: 新页面不发布健康记录
- **WHEN** 用户结束面部会话或完成真实指尖本地采集后查看首页和功能页
- **THEN** 不改写现有健康摘要、固定测量时间、面部独立记录或风险结果，不将指尖采集完成时间记为最近健康检测，不把覆盖就绪、波形存在或文件完成当作健康结果

### Requirement: 真实注册登录与退出界面
应用 MUST 提供用户名密码登录和注册，注册确认密码只作前端校验，请求仅含接口公开字段。注册成功 MUST 返回登录并预填服务端用户名，不建立会话；登录成功 MUST 回到我的显示真实账号。请求中 MUST 防止重复提交；失败 MUST 区分凭据错误、用户名冲突、输入校验、网络和安全存储问题，不统一解释为密码错误。

#### Scenario: 已配置 Release 包的登录入口可用
- **WHEN** Android Release 使用完整账号服务地址和 channel 构建并安装
- **THEN** 登录页面识别到账号服务已配置，登录按钮可用，不显示“账号服务暂未配置”

#### Scenario: 注册成功后登录
- **WHEN** 服务端返回注册成功
- **THEN** 返回登录并预填用户名，仍为游客空态，直至另一次真实登录确认成功

#### Scenario: 确认密码不匹配
- **WHEN** 注册的密码与确认密码不一致
- **THEN** 在表单相关位置提示且不发注册请求；密码可显隐，不进入通用请求历史或持久化偏好

#### Scenario: 登录返回非成功
- **WHEN** 登录凭据错误、网络失败或凭据保存失败
- **THEN** 呈现对应可处理的中文错误，保留游客浏览路径，不发布虚假已登录状态

#### Scenario: 退出登录
- **WHEN** 用户执行退出
- **THEN** 按真实会话清理结果反馈；本地删除成功后回游客空态，远端失败不阻塞本地退出，本地安全存储删除失败不显示完全退出成功，非认证偏好仍保留

### Requirement: 未开放业务只保留入口
历史、健康资料引导、健康资料、个人资料、健康记录和帮助反馈 MUST 仅保留入口，触发统一未开放说明，不实现表单、趋势、记录查询或反馈提交。历史底栏入口 MUST 不进入伪历史业务页；健康资料引导入口 MUST 不形成首次流程第三步。

#### Scenario: 点击历史或健康记录
- **WHEN** 用户点击历史 Tab、详情历史入口或我的健康记录
- **THEN** 显示未开放弹窗并保留当前页面，不查询健康记录或展示 Demo 历史

#### Scenario: 资料与反馈入口
- **WHEN** 用户点击个人资料、健康资料、后续健康资料引导或帮助反馈入口
- **THEN** 显示相应未开放说明，不出现姓名编辑、健康表单、反馈输入或提交成功；健康资料说明可承载后续引导入口
