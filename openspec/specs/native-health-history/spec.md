# native-health-history Specification

## Purpose

为原生应用提供指标选择、日期筛选、趋势、统计和逐条记录一致的只读历史体验，并同步 Demo 已确认的菜单、日历与趋势交互。原生使用已有固定样例并保留认证空态，不接真实结果、文件或后端记录；Demo 只作本地设计展示，不将演示身份等同于原生认证，不把样例解释为个人健康结论。

## Requirements

### Requirement: 历史健康内容按认证展示真实记录
历史页面 MUST 仅在已确认认证时读取当前账号和渠道的真实健康记录，不再生成固定日期样例。默认血压及截至北京时间当天的七天，产品检测时间统一为submittedAt。未确认认证时保留筛选但清空读数、统计、趋势与记录详情。数据层 MUST 区分成功空记录、请求失败与区间未完成；页面首次获取与刷新共用加载，获取失败与刷新失败共用页面失败及重新获取，不使用 Toast，不用旧内容、样例或零值兜底，不显示技术阶段或分页完整度。

#### Scenario: 登录后浏览默认历史
- **WHEN** 已确认登录用户首次进入历史
- **THEN** 默认查询北京时间今天及前六天的血压记录，展示实际返回内容；不再固定为十月末或每天一条

#### Scenario: 退出或认证暂不可确认
- **WHEN** 历史、全部记录或详情可见时认证不再已确认
- **THEN** 立即清空旧账号健康内容和详情，阻断迟到响应，不把暂不可确认等同凭据必然失效

#### Scenario: 固定样例与真实采集隔离
- **WHEN** 指尖或血压得到云端有效结果，或面部／无扰本地采集结束
- **THEN** 前者通过服务端健康查询刷新记录，后者不入云端历史；不直接用本地完成事实或样例追加记录

### Requirement: 历史指标提供下拉和相邻名称切换
原生与 Demo 历史顶部 MUST 居中显示较大字号、主题色的当前指标与下拉入口，顺序为血压、心率、呼吸率、血氧饱和度、糖尿病风险。入口 MUST 打开从底部滑出、占所属屏幕高度60%的滚动单选菜单，顶部固定为左取消、居中标题、右确认，选中项用主题色与勾选标记。菜单选择只更新草稿，确认才切换指标；取消、遮罩或系统返回不提交。两侧相邻名称仍可直接切换，首尾留空且不循环，不用圆形箭头；两种入口共用筛选并保留日期区间。

#### Scenario: 从血压切换到心率
- **WHEN** 用户点击右侧心率名称，或在底部指标菜单选择心率并确认
- **THEN** 当前指标、趋势、统计及记录同步切为心率，日期区间不变；血压左侧及风险右侧没有可循环入口

#### Scenario: 指标草稿取消与滚动
- **WHEN** 用户打开指标菜单、滚动并选择其他指标，再取消、点遮罩或按系统返回
- **THEN** 操作栏固定且只有选项区域滚动，原指标及日期区间不变；再次打开以已提交指标选中，不残留未确认草稿

### Requirement: 历史周期与自定义日期共用日历区间
历史 MUST 沿用当前日／7天／30天／自定义交互，固定周期包含基准日，不按自然周月取整；前后箭头整体移动周期，切换周期保留基准日。自定义仅在显式选日且确认有效起止后提交，取消或仅浏览年月不改变区间；自定义隐藏平移箭头。Tab内保留筛选，进程重启使用以北京时间当天为基准的默认区间。

#### Scenario: 切换30天并前后移动
- **WHEN** 用户选择30天并移动到上一周期
- **THEN** 按日历日整体移动30天，metric/from/to与查询同步，缺失日期不生成记录

#### Scenario: 自定义日期确认与取消
- **WHEN** 用户编辑起止日期或仅浏览年月
- **THEN** 只有实际选定合法日期并确认才提交，反向区间提示且不请求，取消或没有选日保持原筛选；确认后分段选中自定义并隐藏周期箭头

#### Scenario: 未选择日期时原样返回
- **WHEN** 用户打开自定义日历后未点选日期，或只浏览年月就确认或关闭
- **THEN** 弹窗关闭并返回原筛选，不把预填范围自动提交为自定义，也不丢失已经提交的自定义区间

### Requirement: 日期弹层保持稳定布局与年月选择
日历 MUST 使用居中加粗标题、无右上角关闭图标及紧凑的标题下间距，底部左“取消”右“确认”横向等宽，取消为描边按钮。年月头 MUST 显示“2026年10月”，年份范围显示“2016至2027”，支持分别选择年份与月份，当前入口和选中项用主题色；选年进入月份，选月回到日期。日期 MUST 固定七列、六行，星期标题另计，不足补空白，切月不跳高，内容超高时内部滚动。原生选中及区间背景 MUST 在原日格内居中形成1:1圆角正方形并留间隔，不改变触控格；Demo 保留其内缩背景。

#### Scenario: 跨月浏览不改变日期面板高度
- **WHEN** 用户在只有四行、五行或需要六行的月份之间切换
- **THEN** 日期面板始终保留六行，日期位置与触控区域按七列排列，不足部分留空，底部横向按钮不随月份行数跳变

#### Scenario: 选择年份和月份
- **WHEN** 用户分别点击年份或月份并选中一个值
- **THEN** 可浏览十二年分页和十二个月，当前选项使用主题色；选年进入月份、选月返回日历，头部使用中文年月及“至”连接年份范围，不因此提交日期草稿

### Requirement: 历史时间统一为中文北京时间
历史及原生首页关联时间 MUST 使用北京时间中文日期和24小时制，不因设备地区回退为英文或 AM/PM。历史正文短时间为“10月31日 08:30”，完整时间为“2026年10月31日 08:30”，记录日期为“10月31日”；趋势轴使用紧凑日期或时间。格式化 MUST 不改变记录时刻、日历筛选、统计或采集计时。

#### Scenario: 查看列表和趋势提示中的时间
- **WHEN** 用户查看历史记录、记录详情或趋势读数
- **THEN** 日期与08:30样例时刻使用对应中文、24小时格式，轴标签仍可紧凑显示，不出现英文月份或上午下午标识，不改写记录

### Requirement: 历史趋势保持真实日期坐标与交互语义
趋势 MUST 直接绘在页面渐变背景上，不包卡片，使用主题青绿平滑线及向下淡出的面积，血压以实线／虚线区分双序列。图表高232逻辑单位，Y轴在右，左侧不预留Y标签空间，X轴含区间起点且首标签左对齐；图例在图内右上并留间距。数据按真实日期时间定位，缺失不补零，单条不连线，白心点只在交互时出现。原生提示 MUST 为无边框柔和阴影浮层，显示完整日期及读数。两端 MUST 支持按下后横向拖动连续查看最近实际记录、松手保留，纵向仍允许页面滚动，不平移或缩放坐标。指标、日期及图例变化 MUST 使用约350毫秒过渡，不改记录、统计或最终坐标，不影响实时脉搏波。

#### Scenario: 点击读数或切换图例
- **WHEN** 用户点击趋势位置或点击图例
- **THEN** 交互点以白心和曲线同色外圈显示日期、时间及读数，血压同时显示两项；图例可隐藏或恢复对应曲线、面积及极值，不改变统计或记录

#### Scenario: 横向拖动连续查看
- **WHEN** 用户按下趋势图后横向拖动并松手
- **THEN** 浮层、指示线及白心点随最近的实际记录更新，不需要反复点击；松手保留最后选择，指示线不叠加追随延迟，纵向操作仍可滚动页面，原生浮层不因选点反复闪烁

#### Scenario: 筛选和图例变化时平滑过渡
- **WHEN** 用户切换指标、日期区间或图例显隐
- **THEN** 曲线和面积以约350毫秒过渡到新展示，不残留已移除的序列或旧提示；原生首次约350毫秒入场渐入不因筛选或拖动重播，统计与记录始终对应当前筛选

#### Scenario: 区间无数据或只有一条
- **WHEN** 当前指标区间没有记录或仅有一条记录
- **THEN** 无记录显示空态且无统计卡；单条保留实际时间位置和可查看读数，不连出虚构趋势；切换指标、区间或离页后不残留旧图形和交互提示

### Requirement: 趋势极值与统计卡来自同一区间记录
趋势极值及统计 MUST 使用当前指标与日期范围完整取得的全部有效记录，不按来源、采集方式、算法或版本分组。重复极值取时间顺序首次位置，相等合并，不增加常驻圆点。统计卡继续白底细边框、圆角、无阴影，显示平均、最高和最低及单位；血压两项独立计算。计算保留原精度，最终展示直接舍弃小数，缺失不补零，图例显隐不影响统计，不以颜色推断医学等级。

#### Scenario: 切换指标和日期
- **WHEN** 用户切换指标或日期
- **THEN** 读取期间统一显示筛选下方大加载圈，不展示旧筛选或同区间缓存内容，不沿用首分页统计；完整后极值、统计和记录数来自当前指标与日期范围全部有效记录，不将本轮部分页当作最终结果

#### Scenario: 同区间包含多个算法版本
- **WHEN** 当前指标记录具有不同来源、采集方式、实际成员算法或固定versionId
- **THEN** 全部有效记录仍属于当前指标和日期区间的原有趋势与统计；不新增分组、选择菜单、算法版本说明或来源展示

### Requirement: 最近记录全部记录与详情共用当前筛选
历史 MUST 从同一真实筛选区间提供倒序最近十条、完整记录列表及单条详情，数据层保留recordId及taskId，不以日期充当唯一身份。页面和详情 MUST 保留原有日期、时间及单位，不显示算法、版本、来源、质量阈值、原始编码等新增信息，也不增加完整任务报告按钮。风险 MUST 将服务端riskLevel的0／1／2分别映射为较低风险／中风险／较高风险，字号20、行高26，使用与其他读数一致的主文字色，第一行等级、第二行“风险”，两行居中；列表与记录详情同步，记录行自然增高。风险使用最近评估记录标题，不显示概率，不生成风险均值、趋势或临床等级；缺失等级仍为 `--`。

#### Scenario: 浏览30天记录与单条详情
- **WHEN** 用户打开30天区间及完整列表中的一条记录
- **THEN** 最近列表最多十条，完整列表覆盖实际返回记录，允许同日多条；详情与列表同源，返回保留筛选，不因数据接入增加展示行或操作入口

#### Scenario: 查看风险历史
- **WHEN** 用户选择糖尿病风险
- **THEN** 有记录则按服务端0／1／2编码显示较低风险／中风险／较高风险，两行20／26居中展示并使用读数主文字色，第二行固定“风险”；无记录仍为空态，缺失等级不默认低风险，不展示概率或原始编码，不重算档位或解释为血糖、临床患病概率，不生成统计和趋势

### Requirement: 历史页面沿用主题并保留可达操作
历史 MUST 使用同源健康页柔和青绿渐变、系统字体和圆角，不显示额外“健康历史”页头；原生页面边距为24逻辑单位，当前指标为20／28字号行高及深青主题色，各区域间距独立对齐。周期分段 MUST 使用浅灰柔和内阴影凹槽、青绿渐变滑块及柔和外阴影，不加硬轮廓；文字颜色与滑块同组执行约240毫秒过渡，含自定义选中态。参考声明 MUST 仅在记录下方居中随内容滚动，文案为“检测仅供健康管理参考，非医学诊断依据。”；列表以分隔线而非逐条阴影组织。原生页面与各浮层 MUST 按安全区和触摸适配，常规竖屏默认字号下可滚动到达必要操作。

#### Scenario: 正常竖屏浏览与返回
- **WHEN** 用户滚动历史、打开日期或记录弹层，并通过页内操作或 Android 返回关闭
- **THEN** 正文、底栏和必要操作可见可达，返回先关闭当前浮层，不丢失已提交筛选，不显示浏览器控件或桌面预览外框

### Requirement: 区间完整性决定最终趋势和统计可用性
历史 MUST 连续读取筛选区间所有分页后才能发布本轮最终趋势和统计，不能把最近十条或当前一页当完整区间。后续页失败 MUST 保留内部未完成及错误，统一展示获取失败与重新获取，不展示旧完整缓存、不使用 Toast。再次进入、显式重新获取或切换筛选从第一页重读。已知新有效结果、total变化或重复recordId时 MUST 整段刷新，不混页，不增加分页完整度或常驻刷新按钮。

#### Scenario: 区间超过一页
- **WHEN** 筛选结果超过服务端单页上限
- **THEN** 连续读取全部页；首次读取与同区间刷新共用大加载圈，不展示旧内容，本轮最终统计、趋势和记录在完整取得后统一更新，不展示分页过程说明

#### Scenario: 翻页中断或集合变化
- **WHEN** 后续页失败或记录集合变化
- **THEN** 不把失败当空页结束、不输出部分统计；任一页失败统一展示获取失败及重新获取，隐藏旧完整内容。新读取从第一页开始，隔离旧轮迟到页，不无限自动重取

### Requirement: 健康记录时间明确按北京时间解释
历史和首页 MUST 将服务端无时区后缀的submittedAt明确解释为北京时间，保持中文24小时制展示；日期请求使用北京时间YYYY-MM-DD闭区间。应用 MUST 不将时间直接当UTC、依赖设备默认解析或改用createdAt／finishedAt／本地采集开始时间归档；原始响应字符串保持不变。

#### Scenario: 设备时区不同或提交跨日
- **WHEN** 设备不在东八区，或采集结束与服务端提交处于不同北京时间日期
- **THEN** 记录归入submittedAt对应的北京时间日，展示无八小时偏移，首页该指标最近时间与历史一致

### Requirement: 历史加载空态与失败操作沿用设计稿
原生和 Demo 的历史页面 MUST 保留指标和日期筛选，首次读取、切换筛选、同区间刷新及重新获取统一在筛选下方剩余区域居中显示大旋转图形，替代旧趋势、统计、记录及声明。加载、空态和失败区 MUST 填满筛选下方至底栏前的可用空间，成功长内容仍可滚动。成功空区间 MUST 使用无图标的“当前区间暂无{指标}记录”、原辅助文案及“前往检测”主题色文字箭头；获取或刷新失败 MUST 统一显示“历史数据获取失败”和“重新获取”文字箭头，不显示旧内容或声明，不使用 Toast、按钮外形或新增技术说明。Demo 不再保留历史刷新及刷新失败独立预览入口。

#### Scenario: 首次与刷新共用加载
- **WHEN** 首次读取、切换指标或日期区间、刷新同一区间或重新获取
- **THEN** 筛选保留可操作，下方只显示大加载圈，不显示骨架、旧记录或健康声明；完成后切换到对应成功、空态或失败展示

#### Scenario: 已有完整缓存时离线刷新
- **WHEN** 当前区间已有完整缓存，用户离线返回历史或切换到该缓存区间，新一轮读取因离线暂停
- **THEN** 仍使用统一页面加载，不展示旧趋势、统计、记录或声明，不把暂停读取当成本轮成功或另加Toast

#### Scenario: 空区间前往检测
- **WHEN** 用户在成功空区间点击“前往检测”
- **THEN** 进入功能页，由用户明确选择检测；不直接启动设备或生成记录

#### Scenario: 失败后重新获取
- **WHEN** 当前区间获取或刷新失败，用户点击“重新获取”
- **THEN** 显示统一页面加载状态，从当前指标及日期范围第一页重读；不更改筛选、不读取旧筛选页补齐

#### Scenario: 已有完整记录的刷新失败
- **WHEN** 当前完整区间后续刷新任一页失败
- **THEN** 结束页面加载并显示统一失败及重新获取，不使用 Toast，不继续展示旧完整数据；内部缓存可保留，但失败轮次不替换为部分记录、空数据或最终统计
