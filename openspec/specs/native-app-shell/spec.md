# native-app-shell Specification

## Purpose

为现有原生能力验证应用提供一致的入口、导航、浅色视觉和基础交互，使页面改造后仍可独立控制主动相机、被动服务与传感器，并避免导航生命周期变化造成资源泄漏、误停或虚假成功。

## Requirements

### Requirement: 产品与开发入口使用统一底部导航
应用 MUST 提供健康、功能、历史、我的、开发五个底栏入口，其中历史仅触发未开放说明而不切入历史业务页。开发入口 MUST 集中承载已有验证页面及相关操作，当前阶段可见，并允许通过单一集中配置在后续隐藏；本次 MUST 不删除原验证能力或将其混为产品测量功能。健康、功能、历史、我的四个产品入口的图标 MUST 对齐 Demo 对应几何，选中使用实心图形与 `#0AB6C0`，未选中使用描边图形与 `#666666`，标签颜色与当前状态一致；视觉调整 MUST NOT 改变入口行为、路由或既有资源交接。

#### Scenario: 进入开发验证
- **WHEN** 用户从任一可浏览产品页面点击开发 Tab
- **THEN** 进入统一开发入口，可打开既有验证页，返回时导航层级明确，不创建第二套独立应用导航

#### Scenario: 历史入口未开放
- **WHEN** 用户点击历史底栏入口
- **THEN** 展示说明弹窗，保留原选中页面和可恢复状态，不显示空壳历史业务页

#### Scenario: 产品底栏选中与未选中图形
- **WHEN** 用户在健康、功能和我的页面间切换
- **THEN** 当前产品 Tab 使用 Demo 对应的实心图形和 `#0AB6C0`，其他产品 Tab 使用描边图形和 `#666666`，标签颜色随选中状态一致切换；历史不因视觉调整变成可进入的业务页，开发入口仍保留

### Requirement: Tab 切换遵守采集资源所有权
从主动相机页切换 Tab MUST 等待现有命令与本轮原生关闭及文件收尾，失败时 MUST 保留主动页及重试入口，不因为页面仍挂载而继续占用相机。显式血压轮次离页 MUST 连同本轮 IMU 一起关闭；独立被动服务与组外传感器 MUST 不仅因 Tab 切换而停止。返回页面 MUST 显示原生真实状态，不自动重新采集。

#### Scenario: 主动采集中点击健康 Tab
- **WHEN** 用户在主动相机打开或采集中点击其他 Tab
- **THEN** 等待关闭和文件收尾后才切换，完成文件按真实结果展示；关闭失败则不切换，若当前为血压轮次则同时等待本轮 IMU 和联合文件屏障

#### Scenario: 被动及传感器切换 Tab
- **WHEN** 用户保持应用前台并从正在运行的独立被动或传感器页切到产品页再返回
- **THEN** 各能力按原有所有权继续运行且状态刷新，不被统一页面卸载策略停止；血压页只关闭自己明确取得的组内 IMU，不把独立会话纳入本轮

### Requirement: 中文页面适应字号与输入环境
页面 MUST 允许系统字号缩放，使用系统字体；本版中文正文、按钮和输入错误 MUST 不因固定高度裁切。导航、页面与固定操作区 MUST 明确分配安全区，输入时 MUST 可看到当前输入与相关操作，不重复叠加安全区或被键盘遮挡。

#### Scenario: 大字号中文配置表单
- **WHEN** 用户使用较大系统字号，在小屏设备上编辑相机、传感器或认证表单
- **THEN** 标签和按钮可换行或滚动访问，键盘不遮挡当前字段与必要操作，内容不发生不可访问的横向溢出

### Requirement: 本地验证入口独立可用

应用 MUST 在开发 Tab 提供验证入口列表，可访问原始主动 PPG、主动 RPPG、被动 RPPG、传感器和既有语言页面；语言页本版仅说明简体中文状态，不开放切换。被动页面 MUST 展示实时阶段、当前逐搏初步心率及本地结果，另保留历史视频查询。逐搏值与频谱结果及其平均 MUST 明确区分，缺值、过期、停止或没有当前会话时不得显示历史逐搏值冒充实时结果。未登录、认证恢复未完成或未配置云端服务时，本地入口 MUST 仍可使用。启动及进入页面 MUST NOT 自动打开相机、启用被动服务或开始采样。

#### Scenario: 没有云端配置的冷启动
- **WHEN** 未配置云端服务且没有登录会话，用户启动应用并经开发 Tab 进入任一采集页
- **THEN** 正常显示能力与显式操作入口，不因缺少云端崩溃，也不自动采集；被动页面区分新的实时结果和历史视频

#### Scenario: 被动测量中显示初步心率
- **WHEN** 当前被动会话已确认合格逐搏间隔但频谱窗口尚未完整
- **THEN** 页面独立显示标为初步的逐搏值，不将其记入频谱平均，不把它称为稳定或医学结果

#### Scenario: 当前逐搏结果被清空
- **WHEN** 当前输入失效、结果过期、会话停止或切换
- **THEN** 页面显示等待或不足，不沿用先前 bpm；页面订阅的有无不改变服务生命周期和算法

### Requirement: 返回与被动深链具有一致导航语义

应用 MUST 支持 Android 返回键、页面返回操作和 `healthcvapp://passive-capture` 深链；冷启动或运行中接收深链 MUST 到达开发栈的被动页面且不自动启用服务。重复打开同一深链 MUST NOT 堆叠重复的被动页面，深链落地后 MUST 可返回开发验证入口。冷启动开屏及首次引导优先级 MUST 遵循启动契约。

#### Scenario: 冷启动深链
- **WHEN** 应用未运行，用户通过被动采集深链打开应用
- **THEN** 开屏结束后显示被动页面的真实状态，返回后到达开发验证入口，不启动录像

#### Scenario: 运行中重复深链
- **WHEN** 应用运行中连续收到同一被动采集深链
- **THEN** 只保留一个被动页面目标，不重复订阅、启用服务或累积相同返回层级

### Requirement: 离开主动页安全释放相机
产品面部、指尖及血压 MUST 在离开前等待本轮已发命令、相机与文件收尾，不只依赖卸载后的异步清理。指尖及血压 MUST 先取消本轮观测与尚未执行的自动开始，未完成权限或布局等待不得在离页后打开设备；血压 MUST 同时等待本轮 IMU 停止和联合收尾。关闭只作用于本调用方、本轮实际持有的资源，不得停止组外传感器、相机或被动服务。关闭失败保留页面与重试，不自动导航或启动其他相机；恢复焦点或前台不得续采。历史错误不冒充本次关闭失败，旧轮回调不得影响新轮，完成文件不得因离页删除，Dev 验收范围保持不变。

#### Scenario: 正在采集时返回
- **WHEN** 用户在产品面部、指尖或血压采集中返回
- **THEN** 阻止重复离开，等待本轮关闭与文件屏障后才交接，不把仍在写入的文件显示为成功；血压还须停止本轮 ACC／陀螺仪并等待联合收尾

#### Scenario: 主动页通过深链跳转
- **WHEN** 产品主动相机打开时收到既有导航 URI
- **THEN** 先等待本轮关闭和文件收尾，血压同时等待本轮 IMU 关闭，成功后才导航，失败留页可再关闭；不启用目标采集或停止组外传感器与被动服务

#### Scenario: 产品面部页启动中返回
- **WHEN** 面部相机打开或检测启动尚未完成时请求返回
- **THEN** 保留既有命令等待及关闭规则，迟到结果不能在目标页重开相机或更新状态

#### Scenario: 产品面部页深链交接失败
- **WHEN** 面部页导航交接时真实相机或文件关闭失败
- **THEN** 保留当前页的反馈和再次关闭入口，不先跳转，不统一关闭其他独立服务

#### Scenario: 指尖展示不参与相机关闭
- **WHEN** 指尖尚未取得本轮相机，例如权限拒绝或其他所有者占用时，用户返回或收到深链
- **THEN** 只取消本页展示、等待和未执行动作，不向其他所有者发送停止；已取得本轮相机的真实指尖不适用无设备关闭路径，必须等待其资源屏障

#### Scenario: 相机忙后的首次返回不重抛历史错误
- **WHEN** 面部、指尖或血压启动因其他所有者占用相机失败，本轮已无资源，用户请求返回
- **THEN** 本次关闭成功即可离页，历史 CAMERA_BUSY 不冒充当前关闭错误，也不释放占用者租约；真实关闭失败仍阻止离页

#### Scenario: 指尖授权或覆盖就绪期间返回
- **WHEN** 指尖权限弹窗、预览就绪等待或覆盖自动开始尚未完成时请求返回
- **THEN** 关闭意图先阻断未执行动作，再等待已发命令及本轮资源；权限返回、迟到布局或旧覆盖就绪不能重新启动本轮

#### Scenario: 血压准备或联合开窗中返回
- **WHEN** 血压授权、预览就绪、指尖覆盖、贴胸准备或联合启动尚未完成时请求返回
- **THEN** 先阻断本轮自动开窗及迟到授权／布局／准入动作，再等待已发命令并关闭本轮相机、ACC／陀螺仪和已创建的 writer；未取得的资源不发送全局停止，旧回调不能在目标页启动设备

#### Scenario: 血压部分关闭失败
- **WHEN** 本轮相机、IMU 或文件任一关闭屏障未成功
- **THEN** 保留当前页及真实错误，必要重试仅关闭本轮尚未完成的资源，不先导航、不宣称整组已释放，也不触及独立传感器或其他相机所有者

### Requirement: 页面切换不改变独立采集所有权

应用 MUST 区分页面切换、页面卸载和宿主后台。独立被动服务与组外传感器 MUST NOT 仅因页面离开而停止；返回页面 MUST 刷新原生真实状态。血压轮次明确持有的 ACC／陀螺仪属于该轮资源，离开血压页时 MUST 按联合屏障关闭，不适用独立传感器的前台切页继续规则。独立传感器后台中断及被动服务后台运行仍遵循既有契约，导航不得自动恢复采集或级联停止其他源。

#### Scenario: 传感器运行中切页
- **WHEN** 用户启动可用独立传感器后切换至主动 PPG 页，再返回传感器页，期间应用保持前台
- **THEN** 原传感器会话继续且可单独停止，页面显示该会话真实状态与产物

#### Scenario: 被动服务运行中离开页面
- **WHEN** 用户明确启用被动服务后返回入口或进入语言设置
- **THEN** 页面切换不停止服务，返回后状态与原生服务一致

#### Scenario: 血压离页不停止组外传感器
- **WHEN** 血压轮次结束或离页，而另有该轮未持有的独立传感器会话
- **THEN** 只关闭血压本轮持有的 IMU 与相机；独立会话继续按原有所有权运行，血压未能取得的类型也不得被其取消、失败或离页路径停止

### Requirement: 浅色视觉遵循已确认令牌

现有三个验证页、相机查询及配置面板、新入口和语言设置 MUST 使用 `docs/development/frontend-development.md` 中已确认的视觉令牌，允许统一语义映射但 MUST NOT 更改已确认色值、字体和尺度。系统深色模式 MUST 不改变应用浅色主题；应用 MUST 不提供主题切换或持久化主题偏好。

#### Scenario: 系统切换深色模式
- **WHEN** 用户将设备切换到深色模式并返回应用
- **THEN** 页面、导航和系统栏仍适配浅色应用表面，文字与操作可读，不出现主题选择入口

#### Scenario: 操作错误不冒充评估结论
- **WHEN** 权限拒绝或采集命令失败
- **THEN** 界面以错误说明和操作反馈表达，不把该错误解释为健康风险或根据原始读数自行设置评估状态

### Requirement: 基础操作可访问且防重复提交

交互目标 MUST 至少为 48 dp，按钮 MUST 提供可感知按压、加载和禁用反馈，加载或禁用期间 MUST 不再次执行同一操作；业务命令 MUST 同时防止并发重复执行。图标操作 MUST 有可访问名称，装饰图标 MUST 不重复朗读。状态 MUST 不只靠颜色区分。

#### Scenario: 连续点击采集命令
- **WHEN** 用户在启动或停止命令未完成时连续点击操作
- **THEN** 只执行一次对应命令，界面表明处理中，并向辅助技术暴露忙碌或禁用状态

### Requirement: 既有采集能力和产物保持真实

迁移后的页面 MUST 保留相机查询与配置、原始主动预览与双 CSV、主动 RPPG 波形与三件套、被动启停与实时结果、历史视频查询，以及四种传感器独立控制和产物展示。全量样本 MUST 不进入页面或查询缓存；页面切换、退出和缓存回收 MUST 不删除完成文件，不生成占位数据。新被动执行不再产生视频，不将历史视频包装为已计算的脉搏或心率。

#### Scenario: 完成采集后切页并返回
- **WHEN** 用户正常完成原始 PPG、主动／被动 RPPG 或传感器采集后切页再返回
- **THEN** 可按各能力查询真实产物，已完成文件可读取；RPPG 来源和结束状态明确，原始 CSV 及历史视频格式和完成语义不改变

#### Scenario: 查询升级前的视频
- **WHEN** 被动页面查询已有视频文件
- **THEN** 仍显示真实视频路径及媒体元数据，不删除、不自动上传，也不以新流程不录视频为由隐藏其查询能力

### Requirement: 产品检测页面独立于开发验证导航
应用 MUST 全局固定竖屏，在现有根导航中提供产品准备及面部／指尖／血压页面和本轮指尖详细结果页，不显示产品底栏，不新增导航容器、Tab 或公开产品深链；只增加承接真实血压检测及指尖结果展示所需的页面目标，不改造首页导航。面部返回 MUST 回到发起功能页并保留分类；指尖与血压未跳过时返回各自准备页，已跳过或当次跳过时直接返回原功能页。指尖详情返回 MUST 恢复本轮已完成的检测页及简要结果，不创建新轮。已跳过入口 MUST NOT 挂载隐藏引导页或补声音提醒。真实检测离页 MUST 等待本轮关闭屏障；详情往返只保留已释放资源轮次的展示数据，不继续占用相机，不适配或扩大既有 Dev 验收。

#### Scenario: 功能进入面部检测并返回
- **WHEN** 用户从功能页确认进入面部检测，再通过页内或 Android 返回离开
- **THEN** 保留无底栏布局，资源安全关闭后返回原功能分类，不露出多余准备页或开发验证页面

#### Scenario: 未跳过时指尖返回引导
- **WHEN** 用户未跳过引导，从指尖检测页返回且当前未展开结果弹层
- **THEN** 先取消本轮待执行自动开始、结果等待及回调，并等待命令、相机和文件收尾，再回到准备页并清理本轮展示；再次返回可到原功能分类，不进入开发相机页

#### Scenario: 已跳过时指尖返回功能
- **WHEN** 用户通过已保存或当次跳过入口进入指尖检测后返回，且当前未展开结果弹层
- **THEN** 完整关闭并清理本轮展示后直接回到原功能分类，不显示引导或声音提醒；再次明确进入建立新轮，不继承上轮覆盖、时间、曲线或样例结果

#### Scenario: 未跳过时血压返回准备
- **WHEN** 用户未跳过血压引导，从指尖覆盖、贴胸准备或正式血压采集阶段返回
- **THEN** 阻断未执行自动开始并等待本轮相机、IMU 和文件完整关闭，再回到血压准备页；再次返回保留原功能分类，不进入开发传感器或相机页面

#### Scenario: 已跳过时血压返回功能
- **WHEN** 用户通过已保存或当次跳过的血压入口进入后，通过页内或 Android 返回离开
- **THEN** 等待本轮联合关闭屏障后直接回到原功能分类，不挂载隐藏准备页或声音提醒；再次明确进入建立新的独立轮次，不继承旧覆盖、IMU 准入、计时或产物关联

#### Scenario: 从可用简要结果进入详情
- **WHEN** 用户在本轮结果弹层中点击“查看详细结果”
- **THEN** 进入独立指尖详情页，无产品底栏，不经过开发入口；底层检测轮次已释放相机，仍保留完成展示和真实波形，返回动作不会开启新检测

#### Scenario: 详情页内及系统返回
- **WHEN** 用户在指尖详情页点击返回或按 Android 返回键
- **THEN** 回到原检测页并展示同一轮简要结果，不回到准备或功能页，不重复三秒等待；再次返回先收起弹层，弹层收起后才按原入口规则退出检测
