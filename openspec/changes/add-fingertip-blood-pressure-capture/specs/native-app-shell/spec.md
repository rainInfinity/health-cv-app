# Spec Delta

## MODIFIED Requirements

### Requirement: 产品检测页面独立于开发验证导航
应用 MUST 保持全局竖屏，在同一根导航中提供产品准备、面部、指尖及血压页面，不显示产品底栏、不新增导航容器、Tab 或公开产品深链。面部保持原返回规则；指尖及血压未跳过引导时返回准备页，已跳过或当次选择跳过时直接返回发起功能页及原分类。已跳过入口 MUST NOT 挂载隐藏引导页或补提醒。本次不新增 Dev 页面，也不顺带删除既有开发能力。

#### Scenario: 功能进入面部检测并返回
- **WHEN** 用户从功能页确认进入面部页，再通过页内或 Android 返回离开
- **THEN** 保留现有无底栏布局，资源安全关闭后返回原功能分类，不露出多余准备页或开发验证页

#### Scenario: 未跳过时指尖返回引导
- **WHEN** 用户未跳过引导，从指尖采集页返回
- **THEN** 先等待本轮真实采集资源和文件收尾，再回到准备页；再次返回可到原功能分类，不进入开发相机页

#### Scenario: 已跳过时指尖返回功能
- **WHEN** 用户通过跳过入口进入指尖采集页并返回
- **THEN** 等待本轮关闭后直接回到原功能分类，不显示引导或声音提醒；再次进入为待操作状态，不恢复上轮设备

#### Scenario: 血压准备与直接入口
- **WHEN** 用户分别通过未跳过的准备确认、当次跳过或已保存跳过偏好进入血压页
- **THEN** 使用同一血压根栈页面；未跳过返回准备，其余返回原功能分类，均不以提醒确认自动启动 PPG 或加速度

### Requirement: 离开主动页安全释放相机
面部、指尖及血压产品页 MUST 在离开前等待本轮在途命令、主动相机及文件收尾；血压还 MUST 等待本轮持有的加速度源收尾，不只等待相机。关闭失败 MUST 保留页面、错误和再次关闭入口，不先导航或全局停止其他源。返回页面 MUST NOT 自动重开或续采。旧轮回调不得修改新轮状态，完成文件不得因离页删除；不重复扩大前置提案已有 Dev 验收。

#### Scenario: 正在采集时返回
- **WHEN** 用户在面部、指尖或血压采集中返回功能页
- **THEN** 阻止重复离开，等待本轮所有资源和文件屏障，再按实际结果交接；仍在写入的文件不被显示为完成

#### Scenario: 主动页通过深链跳转
- **WHEN** 产品主动相机打开时收到既有导航 URI
- **THEN** 等待本轮关闭与收尾后才执行目标导航，失败保留当前页，不自动启用目标采集或关闭被动服务

#### Scenario: 产品面部页启动中返回
- **WHEN** 面部相机打开或启动尚未完成时请求返回
- **THEN** 保留现有等待命令、关闭及迟到结果隔离，不因新增页面而允许旧回调重开相机或更新目标页

#### Scenario: 产品面部页深链交接失败
- **WHEN** 面部页处理导航时真实相机或文件关闭失败
- **THEN** 保留当前页的反馈和再次关闭入口，不先跳转，不统一关闭其他独立服务

#### Scenario: 指尖只关闭本轮真实采集
- **WHEN** 用户从已准备预览或正在采集的指尖页返回
- **THEN** 等待本轮相机、命令和文件收尾，不再仅取消本地模拟调度，也不停止独立加速度或其他所有者

#### Scenario: 相机忙后的首次返回不重抛历史错误
- **WHEN** 本轮启动因其他所有者占用相机失败，且本轮资源已释放后用户返回
- **THEN** 关闭不把历史 CAMERA_BUSY 当作本次关闭失败，不释放占用者租约；本次真实关闭失败仍阻止离页

#### Scenario: 血压只完成一个源的关闭
- **WHEN** 血压页请求离开，相机已关闭但本轮加速度回调或文件尚未收尾
- **THEN** 继续等待本轮加速度屏障，不提前导航、不从公共控制入口停止后来启动的独立会话

### Requirement: 页面切换不改变独立采集所有权
应用 MUST 区分页面切换、页面卸载和宿主后台。独立被动服务和独立传感器 MUST NOT 仅因页面离开而停止；返回刷新原生真实状态。显式加入产品 PPG 加加速度组合的源 MUST 跟随该组合的主动离页屏障，仅结束本轮所拥有会话。宿主后台仍按各原生运行时中断，不自动恢复采集或停止无关源。

#### Scenario: 传感器运行中切页
- **WHEN** 用户启动独立传感器后切换到主动 PPG 页并返回，期间宿主保持前台
- **THEN** 原独立传感器继续且可单独停止；产品组合遇到该加速度占用时拒绝接管

#### Scenario: 被动服务运行中离开页面
- **WHEN** 用户明确启用被动服务后返回入口或进入其他页面
- **THEN** 页面切换不停止服务，返回时真实状态一致；主动采集不得通过关闭被动服务抢占相机
