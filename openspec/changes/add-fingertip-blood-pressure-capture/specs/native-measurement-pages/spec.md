# Spec Delta

## MODIFIED Requirements

### Requirement: 跳过偏好同时跳过引导与声音提醒
“以后不再提示” MUST 按检测方式保存为设备级偏好，默认不跳过，重启保留且退出账号不清除。未勾选时，开始操作 MUST 在当前引导页内显示声音提醒；勾选后当次开始及后续入口 MUST 不再显示声音提醒，后续入口 MUST 直接跳过引导页。面部、指尖及血压均进入对应待操作页，不自动启动设备。应用 MUST NOT 调整系统音量或将提醒等同于语音播报或相机授权。

#### Scenario: 两个指尖指标共用偏好
- **WHEN** 用户在指尖准备勾选跳过，之后从另一个指尖指标入口进入
- **THEN** 直接进入新的指尖待操作页，不显示引导或声音提醒；面部和血压偏好不受影响，不因目标名称执行健康算法

#### Scenario: 未跳过时声音提醒留在引导页
- **WHEN** 用户未勾选跳过并在引导页点击开始
- **THEN** 提醒标题、声音提示及“立即检测／返回准备”沿用既有准备流程；弹窗在引导页上淡入淡出，淡出完成后才执行确认动作，关闭或返回只收起提醒，不启动采集

#### Scenario: 当次勾选后开始
- **WHEN** 用户在引导页勾选“以后不再提示”并点击开始
- **THEN** 不再弹出声音提醒，进入对应待操作页；之后从功能入口进入也不显示引导，设备仍须在采集页由用户明确准备及开始

#### Scenario: 血压确认
- **WHEN** 用户确认血压准备提醒，或从已保存跳过偏好的血压入口进入
- **THEN** 到达血压采集页，不再显示未接入反馈，不自行打开相机、启动加速度或创建云端任务

### Requirement: 脉搏波统一使用 ECharts 原生 SVG 渲染器
面部脉搏波 MUST 保留 ECharts 原生 SVG 渲染器，不使用 WebView、Skia 或并行手绘路径。图表 MUST 复用实例、随容器调整并在卸载时销毁；关闭曲线入场及更新插值，连续滚动通过原生位移衔接批次，不让历史样点在交接时向右反跳。绘制 MUST 保留真实时间、幅值和缺口，只处理六秒窗口、邻点及有限预绘区。本次指尖和血压没有实时脉搏波合同，MUST NOT 保留模拟曲线或读取文件伪装实时流；共享面部图表不得随模拟消费者删除。

#### Scenario: 真实信号存在缺口
- **WHEN** 面部曲线遇到片段切换、丢批或采集时间不连续
- **THEN** 在缺口处直接断线，不补零、不补造样本、不跨缺口连接，窗口按真实采集时间定位

#### Scenario: 图表尺寸变化与重进
- **WHEN** 面部绘图区尺寸变化，或用户离页后再次进入
- **THEN** 当前图表适配实际区域，旧实例已销毁，新页面不显示上一轮数据；指尖和血压不因此恢复模拟波形

#### Scenario: 连续批次滚动追加
- **WHEN** 连续批次更新面部波形且用户正在跟随最新
- **THEN** 视窗连续向左推进，不因批次交接把历史波峰向右回拨，历史时间和幅值不变，不生成曲线补间样本参与心率或文件记录

#### Scenario: 图表实际运行检查
- **WHEN** 本次迁移触及共享图表调用
- **THEN** 只对受影响面部表面执行必要回归，不用指尖模拟曲线替代真实数据，不扩大为性能矩阵、医学验证或重做前置提案已有验证

### Requirement: 本轮脉搏波支持固定六秒回看与实时跟随
面部 MUST 保留本轮采样历史，每屏固定六秒，开始时从右侧累积、未满六秒时左侧留空，标题只显示非负的当前时间范围。检测中默认跟随最新；超过六秒后 MUST 支持水平平移回看，不允许缩放，回看时保持所选绝对时间段且继续采样。结束后 MUST 仍可回看本轮历史。回看时 MUST 显示绘图区右侧圆形“回到最新”图标，其垂直中心不包含标题；点击后回到最新窗口、恢复跟随并隐藏，结束后回到最后窗口。本要求不要求指尖或血压构造不存在的脉搏波。

#### Scenario: 检测开始不足六秒
- **WHEN** 面部本轮刚取得波形且时长不足六秒
- **THEN** 最新样本位于绘图区右侧，左侧留空，不补点或开放历史平移，标题不显示负时间

#### Scenario: 检测中拖动回看
- **WHEN** 面部本轮已超过六秒，用户在绘图区水平拖动回看
- **THEN** 所选时间段保持不动，新采样继续追加，右侧显示相对绘图区居中的返回最新图标，双指不改变窗口跨度

#### Scenario: 返回最新或结束后回看
- **WHEN** 用户点击返回最新，或面部检测结束后再次拖动波形
- **THEN** 点击恢复最新六秒窗口并隐藏图标，检测中继续自动跟随；结束后可在本轮历史内平移并返回最后窗口

### Requirement: 脉搏波以纵轴映射保留数据留白
面部脉搏波区域高度、坐标绘图区及原有上下间距 MUST 保持不变，通过纵轴将数据映射到高度 10%–85%，以底边为 0%；MUST NOT 改写采样幅度或增加百分比布局留白。面部 MUST 使用本轮累计原始幅值范围，不随回看窗口重新缩放，新极值可扩展纵轴。产品 MUST 保留淡基线和可见视窗左侧 14% 渐隐，二者固定于视窗，渐隐从不可见平滑过渡到正常线色。本次不再保留指尖模拟固定纵轴及其幅值假设。

#### Scenario: 回看与新极值
- **WHEN** 用户回看面部已有历史，或本轮产生新的幅值极值
- **THEN** 单纯回看不改变纵轴，新极值可扩展本轮显示范围，历史原始幅值不变，不通过缩小绘图区获得留白

#### Scenario: 跟随与回看时左侧渐隐保持固定
- **WHEN** 面部波形跟随最新、回看或结束后查看历史
- **THEN** 基线和左侧渐隐的位置及宽度不变，曲线平滑显现，不被不透明遮挡，返回最新后仍保留渐隐

### Requirement: 指尖提示居中显示于放大的圆形预览内
指尖 MUST 保留品牌顶栏、圆形真实相机预览、居中轻量提示及全宽圆角状态面板的视觉层级。提示沿用主题白色表面、边框和 14 dp 圆角，文字 14／22 dp，水平 16 dp、垂直 12 dp 内边距，含边距最大宽度为预览的 80%，最多两行且不拦截操作。MUST 移除模拟红色覆盖层和覆盖百分比；经验遮挡提示只能表达调整建议，未知时不得显示完整覆盖或质量通过。装饰圆框和水纹不得冒充检测结果。

#### Scenario: 真实遮挡经验提示
- **WHEN** 原生报告应调整遮挡，或提示尚未评估
- **THEN** 页面分别提供相应操作建议或等待说明，不将布尔值映射为覆盖百分比，也不把动画完成当作手指已就绪

#### Scenario: 完成后保留产品提示
- **WHEN** 本轮原生正常完成并发布文件
- **THEN** 页面显示采集完成及实际时长、文件状态，不生成健康指标，不以覆盖满环或模拟末波形证明成功

#### Scenario: 外部模拟控制不迁入原生
- **WHEN** 页面改为真实采集
- **THEN** 不新增模拟放置、模拟未检测手指或假摄像头切换入口，真实操作来自用户动作和原生状态

### Requirement: 页面还原按等价视口与状态验收
页面 MUST 遵守既有前端设计规范，在常规 Android 竖屏、默认字号及正常动态效果下检查布局、圆角、配色、操作图比例、安全区和必要操作可达。指尖和血压采集测试页 MUST 延续已确认产品视觉，不因功能聚焦退化为裸控件或调试文本堆叠，不要求尚无设计的血压页逐像素对照 Demo。面部既有布局、图表及交互 MUST 保持；MUST NOT 为本次新增横屏、多尺寸、大字号或专项无障碍验收。

面部取景四角 MUST 继续采用画面内侧 24×2 dp 实色线段，不因裁剪缩成半宽；面部脉搏波画布 MUST 填满标题与主按钮之间的剩余区域，不固定为最小高度。新增采集页不改变这些既有面部布局约束。

#### Scenario: 面部与指尖主要状态对比
- **WHEN** 本次变更替换指尖模拟流程并新增血压采集页
- **THEN** 实际原生页面的准备、预览、采集、收尾、完成及失败表面保持产品视觉和清晰操作，面部原有主要状态不因共享组件迁移回退；不以编译或网页截图代替原生检查

#### Scenario: 常规竖屏操作
- **WHEN** 用户在常规设备、默认字号下使用准备及采集页面
- **THEN** 图形等比，正文、状态和按钮完整可读，必要操作可达，安全区不重复叠加，超长详情可滚动而非裁掉

### Requirement: 进行中状态使用旋转 spin
面部进行中及指尖／血压的设备准备、采集、收尾状态 MUST 使用既有 900 ms 匀速旋转 spin，真实阶段与文字同时表达状态。待操作、完成和失败时 MUST 静止；保留已有减少动态效果行为，不将动效结束作为业务阶段推进条件。

#### Scenario: 正常动效下正在检测
- **WHEN** 正常动态效果下真实设备仍在准备、采集或收尾
- **THEN** 页面以旋转指示及阶段文案表达进行中，不以固定满环冒充设备状态，也不增加虚构的进度值

## REMOVED Requirements

### Requirement: 指尖展示不调用采集或结果接口
**Reason**: 产品指尖页改为用户显式启动的真实采集测试页，原有禁止权限、设备与产物的展示约束不再适用。
**Migration**: 使用下述真实采集页合同；仍不调用云端算法或更新健康结果，仍不得影响其他所有者。

### Requirement: 指尖覆盖与检测倒计时相互独立
**Reason**: 固定覆盖动画和本地模拟倒计时被真实预览、用户开始及原生正式窗口替换。
**Migration**: 删除模拟进度与后台暂停续演，使用原生阶段、剩余时间及后台中断终态，不提供覆盖百分比。

### Requirement: 指尖底部分页不改变演示会话
**Reason**: 本次没有真实指尖脉搏波合同，不再提供模拟波形分页或假采样历史。
**Migration**: 以操作说明、真实采集状态和本轮产物组织内容，保留必要产品布局；面部共享图表继续使用。

## ADDED Requirements

### Requirement: 指尖与血压测试页具有一致产品设计质量
两页 MUST 使用现有主题 token、系统字体、中文文案、样式和组件约定，不建立第二套色表或直接搬入开发配置控制台。页面 MUST 具有品牌顶栏、对应操作图／真实预览、简洁指引、层次清晰的状态面板及品牌主按钮；按钮提供加载、禁用和至少 48 dp 触控区域。必要错误使用统一反馈，文件和采样参数位于次级详情，不挤占主操作；不得新增仅解释测试身份的冗余文案。

#### Scenario: 血压采集页首次进入
- **WHEN** 用户进入新增血压页
- **THEN** 页面沿用指尖＋贴胸操作资源和产品布局，以两个源的状态表达采集准备，不展示原始路径堆叠、未证实血压读数或虚构质量分

### Requirement: 两页显式准备预览后再开始正式采集
页面进入 MUST 无设备副作用。用户明确准备后才授权、挂载有效预览宿主及打开后摄；用户确认放置后再次明确开始正式采集。页面 MUST 使用实际设备能力生成冻结配置，原始 PPG 固定单块，不静默替换镜头或忽略不支持的补光请求。默认目标为 30 秒工程采集窗口，不承诺模型质量或医学有效性。

#### Scenario: 准备但尚未开始
- **WHEN** 用户打开真实预览但还没有点击开始采集
- **THEN** 页面可提供放置操作建议，正式时间仍为零，不写入本轮正式数据；声音提醒确认不替代该操作

#### Scenario: 必需设备不可用
- **WHEN** 后摄、明确需要的补光或血压加速度计不可用，或设备已被占用
- **THEN** 页面反馈可处理的中文错误，不显示正在正式采集、不换用旧文件或假输入，也不接管占用者

### Requirement: 原生状态驱动采集时间和本轮完成面板
页面 MUST 订阅原生有限采集状态，以同一窗口的实际经过／剩余时间显示计时，不用 JS 时钟与原生绝对时间相减。采集停止后 MUST 等待完整收尾，完成面板只显示本轮实际文件、样本数和时长，并区分到时、提前结束和中断。血压 MUST 同时显示 PPG 与加速度状态，任一路技术失败不得显示整组完成。

#### Scenario: 一路文件仍在收尾
- **WHEN** 血压目标时长已到，只有一路文件已定稿
- **THEN** 页面保持收尾和禁用重测，不显示整体完成；全部必需源正常完成后才显示本轮三份文件的完成状态

#### Scenario: 重新采集
- **WHEN** 用户在本轮完整结束后明确重新采集
- **THEN** 清除旧轮展示关联、建立新轮身份并重新准备预览；旧回调和旧产物不能恢复为本轮结果，已有文件不因清空展示而删除

### Requirement: 本地采集不发布健康结果或暂停续采
两页 MUST 在未登录、无云端配置或离线时可用，不创建云端任务、不上传、不调用指标推理、不更新首页、历史或最近健康测量时间。宿主后台 MUST 由原生中断本轮采集，返回后展示真实状态，不自动续采。页面退出 MUST 通过本轮资源收尾屏障，不清理独立会话或完成文件。

#### Scenario: 无网络完成真实本地采集
- **WHEN** 用户未登录且无网络，明确完成指尖或血压采集
- **THEN** 可取得真实本地产物，不依赖服务端返回，不生成任何健康指标或修改健康记录

#### Scenario: 采集中进入后台再返回
- **WHEN** 真实采集期间应用进入后台后回到前台
- **THEN** 页面显示本轮已中断的真实状态和可用恢复操作，不像旧模拟流程一样从暂停进度继续采样
