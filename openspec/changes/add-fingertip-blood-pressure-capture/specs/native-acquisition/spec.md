# Spec Delta

## ADDED Requirements

### Requirement: 显式有限采集支持 PPG 与 PPG加速度组合
系统 MUST 提供原生控制的有限时长原始 PPG 采集，以及原始 PPG 加加速度计的显式组合采集。创建控制对象、订阅、挂载预览及进入产品页面 MUST NOT 启动设备。预览准备与正式开始 MUST 分开；准备完成且本轮源就绪后才能进入正式采集。目标时长 MUST 为明确的有限正数，配置在本轮冻结；不得把组合采集描述为血压推理或硬件同步。

#### Scenario: 指尖单源采集
- **WHEN** 调用方明确准备后摄预览，再开始仅含 PPG 的有限采集
- **THEN** 系统只为本轮记录 PPG 与配对帧元数据，不注册加速度计，也不依赖云端或登录

#### Scenario: 血压所需双源采集
- **WHEN** 调用方明确请求 PPG 加加速度组合并开始
- **THEN** 系统关联本轮两个源的独立会话、冻结配置及正式窗口，不把预览或源准备阶段样本当作正式组合输入

### Requirement: 原生截止与低频进度具有同一窗口依据
原生 MUST 以单调时钟定义正式窗口和截止；到时封闭本轮数据入口并收尾，计时不得依赖 JS 定时器、页面订阅或动画。低频状态 MUST 提供本轮身份、实际阶段、目标及已用／剩余时间，时长与截止来自同一原生依据；启动和文件收尾耗时不得计入正式目标时长。到时后的回调不得延长本轮窗口或进入新会话。

#### Scenario: 页面未及时消费进度
- **WHEN** 正式采集期间 JS 没有及时处理通知且原生已到目标截止
- **THEN** 原生仍停止接收本轮新样本并进入收尾，页面恢复后读取真实状态，不补采缺失时长

#### Scenario: 用户提前结束
- **WHEN** 用户在目标截止前明确停止
- **THEN** 原生结束实际窗口并记录提前停止，不宣称达到目标；停止完成仍等待在途处理和文件定稿

### Requirement: 组合采集只控制本轮取得的资源
有限采集 MUST 遵守现有相机互斥及同类型单传感器会话约束，不抢占、复用或停止其他所有者的活动会话。双源启动中任一路失败，MUST 停止并等待本轮已启动的另一路收尾；采集中任一路技术失败 MUST 终止组合成功路径并释放本轮源。该级联仅限明确加入本轮组合的源，不影响其他传感器或被动服务。

#### Scenario: 加速度计已由独立会话占用
- **WHEN** 独立加速度采集正在运行而用户请求 PPG 加加速度组合
- **THEN** 组合请求报告资源忙，原独立会话保持运行和原配置；本次请求不得接管该会话或在清理时停止它

#### Scenario: 双源启动部分失败
- **WHEN** 本轮一个源已启动而另一个源启动失败
- **THEN** 系统等待本轮已启动源停止并释放资源后报告失败，不保留后台运行的半组采集，不返回组合完成产物

### Requirement: 组合完成引用保留原文件与实际时间语义
完成结果 MUST 包含本轮组合标识、采集模式、结束原因、目标和实际单调窗口，以及每个源的会话标识、配置摘要、真实样本数、首末采样时间及完整文件引用。原有 PPG／frame／加速度 CSV 的列、单位和原始时间戳 MUST 保持不变；不得归零、插值、补帧或宣称已自动对齐。相机采样时钟不能确认时 MUST 如实保留未知语义，不能与加速度时间直接换算成同步结论。

#### Scenario: 正常双源收尾
- **WHEN** 本轮 PPG 双文件及加速度文件都已关闭并完成各自发布
- **THEN** 调用方取得只关联本轮三份文件的组合完成引用，能够区分本轮身份、原始采样时间与控制窗口，而非按行号配对两路样本

#### Scenario: 两路首样本时刻不同
- **WHEN** PPG 与加速度的第一条实际样本没有同时到达
- **THEN** 结果保留各自真实首末采样时间，不通过修改 CSV 时间、补值或以请求频率推算样本数掩盖差异

### Requirement: 组合发布等待所有必需文件且不隐式删除
本轮所有必需源均有实际样本、正常收尾且各自文件完整、本轮设备资源已释放后，系统 MUST 才发布组合完成引用及可追溯元信息。任一源无样本、技术失败或资源关闭失败 MUST 不发布成功组合；已经独立完成的文件仍保留真实完成状态，不自动删除或跨源回滚。查询只提供当前进程已完成组合引用，不增加落盘 manifest、重启恢复或目录清理承诺。

#### Scenario: 加速度没有有效样本
- **WHEN** 本轮 PPG 已写入而加速度直到停止仍没有被接受的实际样本
- **THEN** 本轮报告失败，不发布成功组合、不选择旧加速度文件替代，已完成的独立文件按现有策略保留

#### Scenario: 文件尚未定稿
- **WHEN** 目标时长已到但任一路仍有在途回调、尾批或文件关闭工作
- **THEN** 状态仍为收尾，不允许重测或发布组合完成引用；完成引用中的路径不指向临时文件

### Requirement: 前台中断与关闭保持本轮终态
有限主动采集 MUST 在宿主后台或运行上下文销毁时停止本轮数据入口并释放本轮资源，区分中断与达到目标。返回前台 MUST NOT 自动续采。关闭 MUST 等待本轮在途命令及资源、文件屏障；关闭失败保留可处理错误，不假报释放完成。正常提前停止与中断均不得被解释为算法有效或健康结果成功。

#### Scenario: 双源采集中进入后台
- **WHEN** PPG 加加速度组合采集中宿主进入后台
- **THEN** 本轮两路都结束并释放，结果如实记录中断；回到前台保持停止状态，不启动新会话或补足原剩余时长
