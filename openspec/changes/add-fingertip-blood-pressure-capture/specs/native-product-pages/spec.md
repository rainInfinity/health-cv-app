# Spec Delta

## MODIFIED Requirements

### Requirement: 功能目录按检测部位与指标提供入口
功能页 MUST 保留“按检测部位”和“按指标”分类，默认前者。部位分类保留面部、指尖、指尖＋胸口三张照片卡片；指标分类保留指尖心率与呼吸率、面部心率、血压、血氧、糖尿病风险五项插画。两个分类 MUST 共用方式、目标映射和方式级跳过偏好。未跳过时进入准备，已跳过时直达对应待操作页。游客 MUST 可进入本地采集；指尖和血压不自动启动设备、不执行云端算法，目标名称只表达入口说明，不证明已生成健康指标。

#### Scenario: 游客点击测量入口
- **WHEN** 游客点击任一功能或主页测量入口
- **THEN** 不因游客身份强制登录；功能入口按方式及偏好推进，主页既有入口不在本次改造范围；面部、指尖及血压进入页面均不自动授权或采集

#### Scenario: 功能最近测量信息
- **WHEN** 游客或已确认账号访问功能页
- **THEN** 游客所有测量时间为空，已确认账号仍仅显示既有固定数据对应时间及真实间隔；无记录和时钟早于记录分别如实表达，不将固定日期改成今天

#### Scenario: 按检测部位进入
- **WHEN** 用户尚未保存跳过偏好，在默认分类点击面部、指尖或指尖＋胸口卡片
- **THEN** 分别进入对应准备页；面部目标仍为面部心率，指尖不预选单项指标，指尖＋胸口目标为血压；确认后分别进入对应待操作页

#### Scenario: 按指标进入
- **WHEN** 用户点击心率与呼吸率、面部心率、血压、血氧或糖尿病风险卡片
- **THEN** 保留已有方式及目标映射，指尖目标到同一指尖采集页、血压到血压采集页；不根据所选目标发起指标推理，不在本次决定后续云端任务拆分

#### Scenario: 已保存跳过偏好的功能入口
- **WHEN** 用户保存某方式跳过偏好后再次点击对应部位或指标入口
- **THEN** 不显示引导或声音提醒，不挂载隐藏准备页，直接进入对应待操作页；指尖不再自动运行模拟覆盖，血压不再反馈未接入，设备仍须用户明确准备和开始

#### Scenario: 返回保留分类
- **WHEN** 用户选择按指标后进入准备或采集，再返回功能页
- **THEN** 原分类仍选中，不重置为按检测部位，卡片与分类一致

#### Scenario: 新页面不发布健康记录
- **WHEN** 用户结束面部会话或完成指尖／血压原始采集后查看首页和功能页
- **THEN** 本次不改写健康摘要、固定测量时间、面部记录或风险结果，不把采集完成时间记为最近健康测量，不将本地文件存在当作健康指标有效
