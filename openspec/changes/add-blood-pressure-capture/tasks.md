# Tasks

本变更只实现已确认的 Android 血压本地采集，不实现云端或血压估值。以当前真实指尖及其已完成增量为基线，不修改其他变更规划。每组同步补充自身需要的回归与长期文档，改动完成后统一运行受影响检查，不在实施中反复执行构建／格式化／测试。设计中仅能量、包络相关门槛和滤波建立段的精确初值留给本组真机校准，不改变30°、持续心震观测或准入表达式；不能把实际算法留作占位。验证结果只在交付回复说明，不写验收流水。

## 1. 传感器观测、所有权与有限正式窗口

- [ ] 1.1 在现有 Android 传感器来源与会话中分离取得类型占用、注册原生观测、准备正式输出、安装正式窗口及封闭释放；复用同一个 ACC 来源分流判定与保存，gyro可仅观测不生成文件。以准备期无正式记录、未开窗取消不发布空产物及独立采集仍可正常完成的定向会话回归证明完成。
- [ ] 1.2 为独立传感器与血压组内占用统一调用方／确切会话授权，迁移全部实际控制调用方，不保留按类型无条件停止的旁路；以同类型忙、非所有者不能停止、旧轮停止不影响新轮及组外类型继续采集的回归验证，不改造 Dev 页面。
- [ ] 1.3 为血压 ACC 接受共同原生接收半开窗口，检查回调接收上下界及原始事件边界，保留独立入口原有窗口规则；扩展 `SensorCaptureSessionTest` 覆盖准备历史、截止后回调、尾批与非空完成，检查原始六列、毫秒、含重力 m/s² 与设备坐标未改变。
- [ ] 1.4 更新 `docs/acquisition/android-sensors.md` 的显式血压组内协调例外、观测／正式保存区别与停止所有权；以文档和实际公开合同一致、独立四类型入口与原始CSV语义仍明确作为完成依据，不引入跨源共享文件事务或高采样率权限。

## 2. 原生姿态、稳定性与持续心震判定

- [ ] 2.1 实现本轮有界 ACC／gyro 输入与姿态／稳定处理，请求间隔分别为5,000／20,000微秒、按真实事件时间处理；按设计的一秒滑窗、两秒持续确认及低频加速度／角速度RMS求稳定，明确屏幕相对水平面0–90°并以>=30°包含边界。以不稳定不放行、30°边界、进入时已倾斜无需动作历史及缺口清旧累计的确定性行为回归验证。
- [ ] 2.2 实现真实 `-accZ` 的因果带通、建立段、四秒有限窗口、原始量纲能量及包络自相关重复性，连续评估形成未知／未满足／满足候选；以常量、低幅噪声、单次冲击不冒充候选，连续候选可识别及时间缺口重置的定向回归验证，不用每窗z-score放大噪声、不搬离线VMD、不输出健康指标。
- [ ] 2.3 将姿态与心震作为并行观测，贴胸准备、启动准备及整个正式采集均持续处理；以倾角>=30°仍更新心震、低于30°可由候选放行、两条路径均必须稳定、正式候选消失不暂停／补时／重启的回归证明。实际采样带宽不足时心震为未知，不缩窄频带或伪造通过，姿态路径仍独立使用真实条件。
- [ ] 2.4 使用现有真实传感器采样能力取得正常斜靠胸口、躺卧平放、持续晃动、移动后重新稳定及未贴胸平放的必要对照，确定能量／重复性阈值和滤波建立段，固定可追溯本地参数；以两条路径及持续检测有真实运行依据完成，不用合成输入代替人体信号、不设临床准确率或设备矩阵，也不因效果问题自动扩大为模型或确认入口。
- [ ] 2.5 在 `docs/acquisition/android-ppg.md` 维护血压工程准入、30°定义、持续心震观测和实时／离线算法差异，写明可追溯参数及原始记录不变；以文档对应实际算法与未知语义、没有胸口精确识别或医学质量承诺作为完成依据，不保存采样或验收流水。

## 3. 血压原生轮次与双源收尾

- [ ] 3.1 在既有 Acquisition Nitro／TypeScript 客户端接入血压开始、快照／订阅、按captureId停止及close屏障，定义轮次、低频阶段、覆盖／IMU事实、进度、原因和组合结果；以类型检查及创建／查询／订阅无设备副作用、无原始IMU／血压波形桥接的行为覆盖验证，保持现有手动PPG、指尖与RPPG调用方可用。
- [ ] 3.2 实现覆盖观测到贴胸准备的原生状态迁移，复用完整覆盖三秒和新鲜度，在准入通过及正式准备后再次复核；以覆盖就绪不提前保存、进入第二阶段重建IMU观测、准备失效撤销writer并重新观测、并发就绪只建一轮的回归验证，不复用指尖单源自动开始命令绕过贴胸条件。
- [ ] 3.3 在PPG和ACC均准备成功后统一安装原生 `[T0,T0+30s)` 接收窗口与组内激活，原生统一计时和截止；复用PPG准备／开窗及元数据屏障，以JS不消费进度仍截止、准备不入窗、双源共用控制边界及原始采样时间不改写的定向回归验证，不宣称硬件曝光与事件精确对齐。
- [ ] 3.4 实现组内取消／错误级联和完整关闭，正式覆盖维持沿用95%及1.5秒宽限，准备中覆盖就绪失效则撤销旧准入；以覆盖丢失、后台、启动失败、关闭与开窗竞态、非所有者关闭及迟到回调隔离回归证明只结束本轮资源、不自动续采、不停止组外会话。
- [ ] 3.5 实现组合结果关联及文件／资源分别表达：同轮PPG双CSV与ACC均非空定稿且资源释放才正常完成，gyro无第四文件要求；以单源失败、部分文件保留、关闭失败可再关闭及旧列表不能补全本轮的回归验证，完成引用不包含临时或仍写入文件。
- [ ] 3.6 更新 `docs/acquisition/android-ppg.md`、`android-sensors.md` 及必要架构模块说明中的真实API、低频合同、共同接收窗口和组内边界；以公开方法／类型与文档一致、时钟与原始毫秒语义分别明确、独立指尖及传感器行为保持作为完成依据，不修改旧编排提案。
