# Spec Delta

## Purpose

为游客与已登录用户提供基于 Android 系统事实的通知设置和隐私授权管理，区分运行时授权、应用通知及渠道状态和采集服务启用，避免将演示偏好或一次设置跳转误认为系统授权已经生效。

## ADDED Requirements

### Requirement: 本地权限设置对游客开放
通知设置和隐私与授权 MUST 对游客和已登录用户均可访问，展示应用实际使用的相机及通知权限用途和状态，不要求云端服务或健康资料。MUST 不展示未使用权限或假偏好开关，不实现提醒计划、消息推送或新增产品被动采集开关。

#### Scenario: 未配置云端服务的游客查看设置
- **WHEN** 游客在无云端配置的应用中打开通知或隐私设置
- **THEN** 可查看本地实际权限状态与操作入口，不要求登录，不发送后端请求

### Requirement: 权限状态以系统事实为准
设置 MUST 区分已授权、未授权和无法确认；通知状态 MUST 根据系统版本核对运行时通知权限、应用通知总开关及已有相关渠道状态，不把单项权限等同于通知实际可用。页面聚焦或从系统设置返回 MUST 重新查询，不以旧内存开关或曾申请成功作为当前状态。

#### Scenario: 从系统设置撤销权限后返回
- **WHEN** 用户在系统设置撤销相机授权或关闭应用通知后返回
- **THEN** 页面重新核对并显示最新状态，不保留已开启假象；查询失败如实显示无法确认

#### Scenario: 运行时权限与通知开关不一致
- **WHEN** 系统允许运行时通知权限，但应用总开关或既有相关渠道已关闭
- **THEN** 页面不宣称通知已完全可用，并提供相应系统设置操作

### Requirement: 显式申请与系统设置跳转不启动采集
MUST 仅在用户明确点击后请求对应权限；永久拒绝、系统总开关或无法由应用撤销的权限 MUST 引导至系统设置，不模拟可直接开关。权限操作 MUST 不打开相机、启动被动服务、开始传感器采样或调度通知；打开设置 MUST 不被视为授权成功。

#### Scenario: 仅申请通知权限
- **WHEN** 用户点击通知授权
- **THEN** 仅执行当前系统支持的通知权限流程，不连带申请相机，不启用被动录像

#### Scenario: 权限永久拒绝
- **WHEN** 系统不再允许应用内再次申请权限
- **THEN** 显示明确说明及系统设置入口，返回后按实际结果刷新，不循环申请或显示虚假成功

#### Scenario: 查看授权引导
- **WHEN** 用户仅浏览首次授权说明或进入设置页
- **THEN** 不发起任何权限申请，不自动打开设备或启用服务
