# Spec Delta

## ADDED Requirements

### Requirement: 当前开放语言资源使用分类 JSON

所有用户可见译文 MUST 从随应用打包的 locale JSON 文件加载，沿用既有 namespace 并为新增页面、启动、认证和反馈增加稳定分类。TypeScript 模块 MUST NOT 存放译文；MAY 注册 JSON 文案 Store，或将稳定状态／错误码映射到 message key。当前仅开放 zh-CN，新中文资源 MUST 完整，不要求同步扩展未开放的英文资源。加载 MUST 不依赖网络。

#### Scenario: 离线加载中文页面
- **WHEN** 用户在离线状态启动应用或进入本地产品、开发页面
- **THEN** 应用从打包中文 JSON 显示文案，不等待远程下载

#### Scenario: 当前发布资源缺失
- **WHEN** 当前开放的中文资源缺少已使用的 namespace 或 message key
- **THEN** 资源检查报告缺失，不将未开放英文资源尚未同步视为当前版本失败

### Requirement: 当前版本有效语言固定简体中文

本版应用 MUST 仅开放 zh-CN，默认和回退语言均为 zh-CN。设备语言或已有 en-US/system 偏好 MUST 不改变当前产品页、开发页、导航和错误提示的中文展示；首屏 MUST 不短暂显示英文。首批文案 MUST 随应用打包，不依赖网络；既有国际化基础和资源 MUST 保留，不要求补齐英文版本。

#### Scenario: 英文设备首次离线启动
- **WHEN** 英文系统设备尚无已保存偏好且离线启动应用
- **THEN** 首个可交互页面及导航显示简体中文，不出现短暂英文页面，也不等待远程翻译

#### Scenario: 已保存英文偏好升级
- **WHEN** 设备已有 en-US 或 system 偏好并启动本版
- **THEN** 开屏、产品页和开发页均为中文，不因恢复旧偏好切成英文

### Requirement: 语言入口仅说明中文且保留旧偏好

本版语言入口 MUST 显示简体中文及当前仅支持中文的说明，MUST 不提供可生效的英文或跟随系统选择。既有语言偏好及持久化基础 MUST 保留，但不决定本版有效语言；退出账号 MUST 不清除非认证偏好。不允许通过开发语言入口绕过当前中文发布约束。

#### Scenario: 查看语言入口
- **WHEN** 用户打开我的语言入口或开发区已有语言页面
- **THEN** 看到当前中文状态和说明，不出现能将当前应用切到英文或跟随系统的选择器

#### Scenario: 退出并重启
- **WHEN** 用户退出账号并重启应用
- **THEN** 界面继续显示中文，旧非认证偏好未因退出被删除

### Requirement: 中文展示不因系统语言变化重置业务

当前版本入口、导航、产品页、开发验证页、相机查询配置、状态、权限说明、确认和错误 MUST 统一显示中文。系统语言变化 MUST 不重启采集、不重置输入或改变界面语言；已知状态和错误 MUST 由原始事实生成中文，不将译文写入业务实体。通用组件 MUST 接收展示文本而非绑定具体业务翻译键。

#### Scenario: 错误状态下修改系统语言
- **WHEN** 页面保留已知错误码且用户切换系统语言后返回
- **THEN** 仍显示中文错误说明，原始错误码与会话不变，不重复执行失败操作

#### Scenario: 保留参数草稿
- **WHEN** 用户在未提交相机或传感器参数时修改系统语言并返回
- **THEN** 界面维持中文；仍保留在导航中的页面不因语言刷新重置草稿，正常离页生命周期不额外承诺持久化

### Requirement: 中文格式化保持业务数值与时间语义

本版日期、时间与数字 MUST 使用 zh-CN 格式化；原始值 MUST 保留数值和时间语义。单位、服务地址、渠道和会话缓存作用域 MUST 不因系统语言或旧语言偏好改变；原生单调时间 MUST 不作为 Unix 日期显示，缺失值 MUST 不补为零或健康默认值。

#### Scenario: 中文展示传感器产物
- **WHEN** 设备使用英文系统语言，用户查看传感器记录数、时间区间与物理单位
- **THEN** 展示按中文格式化且单位、坐标和毫秒／微秒含义不变，不将单调时间格式化为日历日期

## REMOVED Requirements

### Requirement: 跟随系统保存选择语义
**Reason**: 本版明确只开放中文，不提供随系统改变当前应用语言的行为；继续要求跟随系统生效会与本版发布范围冲突。
**Migration**: 保留原偏好值、解析工具及资源供后续版本使用；当前有效语言固定为 zh-CN，系统语言变化不改变界面，不破坏性删除已有偏好。

### Requirement: 翻译资源使用分类 JSON
**Reason**: 原要求对中英键集合完全相等的约束不再适用于当前仅中文发布，替换为当前开放语言资源契约。
**Migration**: 沿用分类 JSON、离线资源与错误映射，新增中文资源不要求同步未开放英文。

### Requirement: 首次启动默认简体中文
**Reason**: 原要求同时公开支持中英，本版改为有效语言固定中文，替换为明确的单语言发布契约。
**Migration**: 默认中文和无首屏英文闪烁继续保留，旧语言偏好不决定当前有效语言。

### Requirement: 显式语言选择持久保留
**Reason**: 本版不再提供英文或跟随系统的公开选择，不能继续要求其生效。
**Migration**: 保留原持久化值和基础代码，语言入口改为中文说明，退出不清除非认证偏好。

### Requirement: 全部现有展示文案实时切换
**Reason**: 本版取消公开语言切换，用系统语言变化不影响中文和业务状态的契约替代。
**Migration**: 保留中文资源、安全错误映射、草稿和采集不因语言变化重置的保护，不补新英文。

### Requirement: 格式化不改变业务语义
**Reason**: 原要求包含切换英文格式化，本版替换为固定中文的格式化契约。
**Migration**: 数值、单位、时区、单调时间和缺失值语义保持不变，仅固定本版显示 locale。
