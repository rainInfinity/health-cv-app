- [x] 1.1 在采集包公共类型及原生配置模型定义相机 ID、查询支持状态／范围、完整模式配置、两元素分块数组、请求／提交摘要及锁状态；通过类型检查和原生值模型行为测试验证约束。Nitro 新方法与打开签名分别随第 2、3 组的真实实现及调用方同批迁移、重新生成绑定，不先加入不可编译的抽象方法或占位实现。
- [x] 1.2 实现 JS 与 Kotlin 两侧的数值／安全整数、模式互斥、设备范围、网格长度／乘积及未知能力校验；以非法曝光／ISO、自动模式携带手动值、手动模式锁 AE、非自动 AWB 锁定及越界网格的行为测试，验证错误分类明确且不占相机／创建文件。
- [x] 1.3 在 `docs/acquisition/android-ppg.md` 更新配置字段、纳秒／屈光度／EV 索引含义及破坏性接口迁移；以实际类型检查和合法／非法本地配置调用核对示例，不写纯类型复制、桥接转发或字段回显测试。

- [x] 2.2 实现按相机返回曝光／ISO／补偿步长、AWB／AF、torch、AE/AWB 锁定及尺寸能力，独立提供 `requestCameraPermission`；通过未授权、授权后重查、明确不支持及缺失字段场景，验证 supported／unsupported／permission-required／unknown 不混淆，查询不会自动弹授权或改变已有会话。
- [x] 2.3 实现未绑定 Preview + YUV 组合的尺寸／FPS 候选查询与兼容性结果，并返回本地最大块数和尺寸约束；用组合不兼容、无法确认和查询后权限／设备条件变化场景验证不把单项能力笛卡尔积当作组合保证，打开时会重新核验。
- [x] 2.4 在 `docs/acquisition/android-ppg.md` 补充授权、枚举、能力、组合查询的调用顺序和未知值语义；在应用运行环境执行查询示例并记录无预览、无补光、无会话文件的结果。

## 3. 配置应用、打开周期与自动算法锁定

- [x] 3.1 同批迁移 `Acquisition.nitro.ts`、`ppg/client.ts`、导出、现有页面打开调用与 `HybridAcquisition`／`PPGController`／`CameraSource`，重新生成绑定并删除无参打开路径；按精确 cameraId 绑定、冻结配置并应用尺寸／FPS、torch、AE／曝光／ISO／补偿、AWB 和 AF／手动距离。以类型检查、原生编译及两组合法配置的真实 CaptureResult 核对请求、提交、实际值分开，不保留旧别名或静默降级。
- [x] 3.2 在打开／采集／停止中再次传配置时明确拒绝，查询失败不污染运行会话；通过状态冲突、关闭重开、迟到回调及权限失效场景验证周期隔离。统一正常关闭、后台中断、设备／锁定失败收尾，在设备解绑后幂等释放匹配周期的 `CameraUseLease`；验证无租约残留、旧清理不会释放新持有者，不能等待页面卸载才解除互斥。
- [x] 3.3 在 `startCapture` 增加当前周期 AE/AWB 锁定确认屏障及有限失败等待，确认后才创建文件、建立正式窗口，并排除确认帧和更早在途图像；行为测试覆盖无确认、超时、乱序／旧结果、关闭与后台中断，验证不提前显示 capturing 或交付产物。
- [x] 3.4 在正常停止后解除所需锁定并确认，重复开始重新锁定当时结果；验证第二次会话不能复用旧确认，完成文件后解锁失败仍保留产物并关闭相机、报告错误，不声称 preview 可复用。
- [x] 3.5 在 `docs/acquisition/android-ppg.md` 更新配置冻结、尺寸／FPS 协商、锁定时机及失败语义；在支持设备执行手动曝光／ISO、补光、AWB／AF 和自动锁定操作，检查真实结果而不是只看设置 Future 或配置回显，并记录不支持项与未验收项。

## 4. 二维网格与像素统计

- [x] 4.1 实现基于实际有效 crop 的 `[rows, columns]` 几何、行优先编号、有限最大块数与实际尺寸复核；用 `[1,1]`、`[N,1]`、`[1,N]`、`[2,3]`、非整除 5×3 和非零裁剪起点测试，验证全部亮度像素恰好归属一个非空块，旋转／镜像预览不改变块身份。
- [x] 4.2 扩展 `PixelStatisticsExtractor`／`FramePipeline`，共享计算全帧与各块 Y/U/V，按与块相交的色度单元计数；使用奇数边界、共享交错色度、行填充及 pixelStride 回归，核对块均值与真实分母，确保全帧提示不受网格改变。
- [x] 4.3 迁移 `PPGRecordProcessor`／`PPGFrameHandler` 为同步作用域内产生完整帧块数值，复用几何／累加缓冲且不复制整帧；通过失败路径测试验证一次帧释放、无像素借用逃逸、任一块失败不能提交部分成功帧。
- [x] 4.4 在 `docs/acquisition/android-ppg.md` 写明分块数组、坐标、余数像素和色度共享边界规则；实际采集条带及矩形网格，按已知像素夹具的独立数值核对规则，不以块数增长或源码文本代替正确性证据。
