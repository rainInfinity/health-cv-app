# Spec Delta

## MODIFIED Requirements

### Requirement: 会话隔离且资源释放不删除产物
每次采集 MUST 在应用专属外部持久目录使用独立会话标识和 `ppg.csv`、`frame.csv` 文件路径；结束会话的迟到回调不得写入下一次采集。关闭相机或界面卸载 MUST 结束采集并释放运行资源，MUST NOT 隐式删除已经完成的文件；任一未完成文件不得冒充完成产物。已有内部文件 MUST 保留，不自动迁移或删除。

#### Scenario: 重复采集后旧回调到达
- **WHEN** 新采集已经开始而上一会话的迟到回调到达
- **THEN** 该回调不进入新文件，两个会话的记录和路径保持隔离

#### Scenario: 正常停止后关闭相机
- **WHEN** 文件已完成且用户关闭相机
- **THEN** 相机与队列资源释放，已经返回的文件仍然存在于应用专属外部持久目录

## ADDED Requirements

### Requirement: 新采集产物使用应用专属外部目录
新采集产物 MUST 位于 `Android/data/<包名>/files/` 下，保留原有采集子目录及可读绝对路径契约，不新增存储权限。该目录 MUST NOT 被描述为所有普通应用可自由访问的公共目录，卸载应用仍会删除其中的文件。外部目录不可用 MUST 明确失败，不静默回退内部目录。

#### Scenario: 通过 ADB 提取文件
- **WHEN** 新采集完成且设备允许 ADB 访问该外部目录
- **THEN** 完成引用指向该目录下的真实文件，可通过 ADB 读取或拉取，不依赖应用可调试或 `run-as`

#### Scenario: 外部目录不可用
- **WHEN** 系统无法提供应用专属外部目录
- **THEN** 相关操作明确失败，不返回内部目录文件冒充外部产物
