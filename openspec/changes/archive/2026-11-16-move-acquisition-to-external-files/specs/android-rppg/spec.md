# Spec Delta

## MODIFIED Requirements

### Requirement: 会话形成三份可解释本地产物
每个已实际收到正式会话相机帧且文件系统正常的新会话 MUST 输出应用专属外部目录中按会话隔离的 `session.json`、`pulse.csv`、`hr.csv`，分别保存元信息、完整定稿波形及心率窗口。无脸、无有效心率或合法中断也 MUST 保留可解释结论，空序列使用表头文件；默认不新增视频、图像、关键点或逐帧 RGB 文件，不发网络请求。已有内部完整三件套 MUST 继续可查询，不自动迁移或删除。

#### Scenario: 正常完成一次测量
- **WHEN** 达到目标测量时长且全部结果正常收尾
- **THEN** 三份文件可读取且会话记录实际范围、目标完成与信号结论，不以文件存在推断心率有效

#### Scenario: 观察超时或全程无有效心率
- **WHEN** 会话已有相机帧但没有可接受心率
- **THEN** 仍有元信息及两份 CSV，空序列只有表头，无效原因可追溯，不补占位行

#### Scenario: 切换目录后查询已有结果
- **WHEN** 内部目录已有完整三件套，外部目录又完成了新会话
- **THEN** 按来源可查询新旧完整结果，各自引用真实路径；临时或不完整目录仍不属于完成产物
