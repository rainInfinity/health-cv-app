# Spec Delta

## MODIFIED Requirements

### Requirement: 实时结果与历史视频是独立持久产物
新被动会话 MUST 使用应用专属外部目录中的独立会话路径及 `android-rppg` 的三份本地文件，并标记来源、结束原因、信号结论；正常结束无心率与合法中断不等于技术写入失败。仅完整关闭并发布的三件套可查询。已有内部 RPPG、旧视频文件及其查询能力 MUST 保留，不自动迁移、不转成虚假脉搏结果；新解锁不再生成视频，不自动上传或删除产物。

#### Scenario: 正常完成后检查与重开
- **WHEN** 一次被动测量完整收尾，用户关闭服务并重新进入应用
- **THEN** 可查询同一份三件套及真实结束／信号状态，历史视频仍可按既有元数据读取，不只检查文件存在

#### Scenario: 连续录像不覆盖
- **WHEN** 两次符合条件的实时会话完成
- **THEN** 新结果位于不同外部会话路径，不覆盖彼此或任何历史视频，主动结果也不被混入

#### Scenario: 编码或存储失败
- **WHEN** 新路径发生相机、算法、写入或发布失败
- **THEN** 保留可判别错误并释放资源，未完成文件不在完整列表；新路径不伪造视频编码成功或补造脉搏结果
