# Spec Delta

## MODIFIED Requirements

### Requirement: 文件持久且会话路径隔离
系统 MUST 在应用专属外部持久目录为每个源的每次会话分配独立临时与完成路径，拒绝覆盖已有文件。停止、页面卸载、关闭其它源或进程退出 MUST NOT 删除已完成文件。完成列表 MUST 按类型仅返回当前进程已完成引用；进程重启后无扫描恢复时不得伪造旧引用或声称旧文件被删除。已有内部文件 MUST 保留，不自动迁移或删除；新位置不改变文件格式、定稿条件或原生记录边界。

#### Scenario: 同类型连续采集与进程重启
- **WHEN** 同一类型完成两次采集，随后进程重启
- **THEN** 两个文件路径不同且仍然保留于应用专属外部目录；新进程完成列表可为空，界面明确只查询本进程记录
