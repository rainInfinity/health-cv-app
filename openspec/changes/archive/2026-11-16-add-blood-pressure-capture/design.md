# Design

## Context

动机与本期边界见 `proposal.md`。本变更同时涉及原生会话、IMU 推断、跨源资源及页面合同，符合需要技术设计的条件。

- 原生指尖已经交付真实后摄、空间覆盖、三秒完整覆盖准入、有限 PPG 窗口和文件／相机屏障。`FingertipController` 的覆盖就绪会直接调用自动开始，不能仅在 UI 增加等待贴胸状态而继续使用其原入口。
- `PPGCaptureSession` 已拆分 `prepare()`、`openWindow()`、`sealEntrance()`；正式帧按处理入口的单调时间入窗，原始 Camera2 时间用于元数据精确配对。
- `SensorCaptureSession.start()` 当前将文件准备、自取起点、开放入口及注册监听耦合；现有四种传感器按类型独立，公开停止没有跨调用方的组内所有权，不能用两个 JS start／stop 调用冒充统一窗口。
- 功能、引导和方式级跳过偏好均已存在，`chest` 入口仍返回未接入。指尖预览、分页、两幅放置图和十五秒指导弹窗可复用；现有提醒直到 `capturing` 才撤销，血压须在进入贴胸准备时提前撤销。
- Web 血压通过外部按钮模拟贴胸；第二页为两幅六帧 SVG，320 ms／帧。视觉与分页可迁移，模拟覆盖、贴胸按钮、浏览器后台暂停续演不可迁移。
- 后端 `health-service` 的血压预处理取 `-accZ`，二阶 1–25 Hz Butterworth、离线 `filtfilt` 和 z-score，再以 VMD 的 8–24 Hz 候选模态重建 AO；后端没有 SCG 质量门禁。这不是已验证的端侧贴胸判定器。

## Goals / Non-Goals

**Goals:**

- 覆盖、IMU、正式窗口与完成文件分别有真实来源，自动准入和截止不依赖 React、分页或订阅。
- 原生以一次血压轮次关联相机、ACC、陀螺仪及文件；用户可取消准备、离页并等待完整关闭，不能误停组外资源。
- 用简单可解释特征交付本期工程准入，30°为已确认初值，其余效果在核心真机验证后评估，不把参数调优升级为模型研究项目。

**Non-Goals:**

- 不估计手机相对人体的空间坐标，不识别精确胸口接触，不计算或发布医学指标；不使用前摄或动作模型。
- 不实现硬件同步曝光／采样、JS 原始样本流、离线 AO/VMD、云端编排、恢复数据库或新文件清理策略。
- 不把血压接入变成整个 measurement 包重构、指尖产品重新设计或 Dev 页面改造。

## Decisions

### 1. 在 acquisition 内增加有限血压轮次，不复用单源自动开始命令

新增血压专属原生控制器，复用覆盖估计器、相机锁定／PPG 准备及传感器来源，不复制像素处理、CSV writer 或通用状态引擎。指尖单源入口继续在覆盖就绪后自动开始，血压必须由自己的准入决策开窗。

在现有 `AcquisitionClient`／Nitro 控制实例增加以下接口，名称在公共合同实施时统一使用，不保留第二套别名：

| 接口 | 行为 |
| --- | --- |
| `openCamera(config)` | 沿用真实后摄与原生预览准备，不写正式记录。 |
| `startBloodPressureCapture({ durationMillis })` | 本所有者在有效预览上创建轮次并开始覆盖观测；产品传入 30,000 ms，返回本轮身份，不等待采满。 |
| `getBloodPressureSnapshot()`、`subscribeBloodPressure()` | 提供本轮低频阶段、覆盖、IMU 判定、原生进度、终止与文件事实；读取和订阅没有启动副作用。 |
| `stopBloodPressureCapture(captureId)` | 只停止指定所有者的指定轮次，准备也可取消，等待组内完整屏障。 |
| `closeCamera()` | 优先撤销本所有者的未发动作，等待在途命令、血压组内 IMU、PPG／ACC 文件和相机释放；没有取得资源时不得停止占用者。 |

血压不订阅或生成指尖展示脉搏，不增加 SCG 波形接口。所有接口保持独立于认证和云端。相机控制实例仍只能持有一种主动方案，不让手动 PPG、指尖和血压绕过彼此所有权。

替代方案：调用现有指尖入口后在页面阻止倒计时无法阻止正式文件提前入窗；分别从 JS 启停 PPG／ACC 也不能提供统一截止与组合屏障，均不采用。

### 2. 两阶段准备与真实正式状态

低频阶段采用 `observing_finger / awaiting_chest / starting / capturing / stopping / completed / interrupted / failed`，轮次未建立时为空。

- `observing_finger`：沿用真实完整覆盖连续三秒及 200 ms 新鲜度，倒计时保持 `00:30`；只准备预览，不写正式记录。
- `awaiting_chest`：进入一次时自动翻第二页，登记本轮 ACC／陀螺仪并清空 IMU 历史、稳定累计与候选；检测已贴靠进入的用户，不要求先观察一次竖起动作。观察样本仅在原生有限内存用于判断，不创建正式样本。
- `starting`：当前准入通过后准备 PPG 锁定、两个正式 writer 与组内窗口。最后再次检查覆盖、稳定、倾角或心震候选、样本新鲜度以及取消意图，再建立正式窗口。
- 开窗前覆盖失效退回 `observing_finger` 并清除旧准入；IMU 稳定／姿态或候选失效仅退回贴胸等待。撤销未开窗 writer 准备，不发布只有表头的伪产物；恢复条件后重新准备。
- `capturing`：原生正式三十秒，IMU 持续观测，但准入状态不是暂停或结束开关。稳定、倾角及心震候选变化不暂停、不补时、不重开正式窗口。
- `stopping` 直到两源及相机屏障结束。正常到时才以实际完成事实进入 `completed`；中断与失败使用统一反馈，不包装成正常采满。

普通指尖的三秒、95%维持门槛和 1.5 s 丢失宽限保持不变。血压复用相同覆盖维持规则，但确认丢失时封闭整个本轮 PPG＋ACC，而非仅关闭相机。贴胸等待不设置超时自动放行。

### 3. 统一的判定表达式，倾角与心震并行

准入只由原生求值：`coverageReady && stable && (tiltDegrees >= 30 || scgCandidate == true)`。

倾角定义为屏幕平面与水平面的无向夹角，范围 0–90°，平放（朝上或朝下）为 0°、竖直为 90°。根据原始设备坐标中的重力估计 `g`，计算 `acos(clamp(abs(g.z) / norm(g), 0, 1))`；不依赖屏幕显示方向、左右手或竖屏／横握，不把门槛解释为偏离竖直 30°。30°包含边界，不能在校准时未经再次确认改为另一个姿态合同。

心震在 `awaiting_chest`、`starting` 和整个 `capturing` 持续计算，与倾角是否达标、另一条路径是否通过以及展示分页无关。状态区分未知、未满足和满足；尚无完整窗口、输入缺口或无法执行频带时是未知，不补成成功。倾角达标且稳定时不必等待四秒心震窗口或强制候选成立；倾角不足时，仍可由候选和稳定放行。

IMU 判定用于准入和必要操作提示，不在页面声称“已识别胸口”或给出健康质量分。接受本期“姿态合理且持稳但未贴胸”可能通过的限制，亦不把心震候选声明为特异的解剖学位置证明。

### 4. 有限滑窗稳定与心震候选，不迁移离线血压算法

ACC 请求 `samplingPeriodMicros=5,000`，陀螺仪请求 `20,000`；分别为约 200／50 Hz 的请求，不是实采承诺。两种设备均需真实可用且由本轮持有；不额外申请高采样率权限，不以虚构陀螺仪或默认稳定值降级。能力不足、占用及注册失败通过既有错误反馈结束准备。

| 项目 | 本期实现起点 |
| --- | --- |
| 稳定窗口 | 最近一秒，每 100 ms 评估；只有完整新鲜窗口才累计，连续通过两秒，最快约三秒确认。 |
| 平移波动 | 三轴 ACC 先以约 3 Hz 低通分离低频运动，再减去本窗口三轴均值，计算向量 RMS；初始门槛 0.15 m/s²。 |
| 转动 | 本窗口原始三轴角速度向量 RMS；初始门槛 0.05 rad/s。 |
| 心震输入 | 同轮原始 `-accZ` 的推理分支，保持法线轴含义；8–24 Hz 因果二阶 Butterworth 带通，不做 VMD。 |
| 心震观察 | 预留滤波建立段后，最近四秒有限窗口，每 250 ms 更新；绝对幅值形成包络，并去除包络均值后计算归一化自相关，检查多次重复的心搏候选节律。 |
| 心震存在 | 同时要求滤后原始量纲能量超过噪声参考、包络重复性足够；单次碰撞或仅有非零波动不构成候选。以实际贴胸及未贴胸对照确定初始能量／相关阈值，写入固定本地参数，无用户校准步骤或调参界面。 |
| 确认与失效 | 连续两个完整心震评估窗口满足后成立；不满足更新为未满足。任一路 IMU 时间回退或间隔超过 200 ms，撤销稳定累计并清空相关滤波／候选；不跨真实缺口连接信号。 |

稳定的两个 RMS 条件同时成立才通过，使用原生单调持续时间而非请求采样数计秒。重力／倾角从有效低频 ACC 得出，重力模长不可用时倾角未知。能量和相关阈值是实施阶段明确的真机校准参数，算法结构、输入输出、候选持续检测与准入表达式不因此改变；不以“后续优化”为由省略能量或重复性实现。

SCG 频带的实际系数由事件时间估计的采样率确定，不能把请求 200 Hz 当实际。实际 Nyquist 不足以执行候选频带时，心震保持未知，不能假装检测成功或静默缩窄频带；另一条姿态路径仍按真实稳定与倾角事实独立求值。明显采样变化时重新建立滤波，不复制完整历史。内部滤波状态和窗口使用固定容量，时间不连续时重置，不向 JS 发样本。

不先逐窗 z-score 再做存在性判断，避免把低幅噪声放大成有力信号。后端 `filtfilt` 使用未来样本，端侧改为因果滤波并排除建立段；8–24 Hz 是候选机械振动频带，心搏重复率从包络判断，不能将二者混为同一频率。不把直接带通与后端 VMD 的 AO 重建描述为数值等价。

正式采集中继续使用同一原生 IMU 输入做观测。候选弱或消失只改变真实观察状态，不因为竖直路径已通过而停掉计算，也不触发健康风险、自动延时或采集重试。

### 5. 原生资源预留与两个正式接收窗口

为传感器内部补充“取得类型所有权、注册观测、准备正式输出、指定开窗、封闭与释放”的必要能力，独立手动 `SensorClient` 继续使用原来的显式采集语义。相同类型仍只有一个所有者，不为血压再注册第二个 ACC 来源。ACC 一路输入同源分流到判定与原始保存，陀螺仪只参与观测，不要求生成额外正式 CSV。

所有者身份在客户端构造时建立但不注册设备；独立入口与血压均必须核对停止调用方及确切会话。旧 `stopCapture(kind)` 路径不能绕过组内所有权；全部实际调用方在实现时同步迁移到同一授权规则，不保留一条能误停他人的旧路径。该调整仅影响必要控制连接，不改造 Dev 产品界面。

PPG 和 ACC 输出先各自准备，监听可在准备期运行但正式保存入口关闭。最后一次准入复核通过后，从 `elapsedRealtimeNanos` 产生同一 `T0` 与 `T1=T0+30s`，通过同一组内开窗决策安装到两源。每路处理入口须检查组内激活标记及 `[T0,T1)`，避免顺序安装期间一源提前保存；时间／命令调度晚于 T0 的差异体现在真实首样本，不补造边界样本。

**共同窗口定义为原生接收窗口，不是硬件同步采样：**

- PPG 沿用帧处理入口的 elapsed 时间入窗；原始相机时间只用于记录与精确元数据配对，未核实的相机时钟源不冒充 elapsed 域。
- ACC 按回调接收 elapsed 时间的同一上下界入窗，并继续排除事件时间早于 T0 或不早于 T1 的历史／越界事件；组内控制时间与事件时钟对应关系需要在实际设备核查，不能因同为毫秒就宣称与相机采样时标精确对齐。
- 原始 `timestampFrame`、`timestampEvent` 及三列时间、单位、自然设备坐标不变，不归零、不重采样、不用过滤值重写 CSV。各源首末实际样本及共同控制边界分别记录。

原生截止先撤销组内激活并封两路入口，再注销／等待回调、相机配对及各自尾批，不能依赖 JS 是否接收计时。复用既有单源 DataHub 和 writer，不建立跨源共享事务或两阶段提交存储。

### 6. 组合结果与组内关闭

本轮结果包含 `captureId`、PPG／ACC 源身份、目标与实际接收窗口、结束原因、各源帧／样本数与首末真实采样时间、冻结配置、已定稿文件及资源释放事实。跨桥绝对纳秒保持十进制字符串，CSV 继续使用毫秒。

正常完成要求本轮非空 `ppg.csv`、`frame.csv`、ACC CSV 均完成，且相机、补光、ACC／陀螺仪监听及本轮资源已释放。陀螺仪不是第四份必需文件。任一路错误立即取消未发开始、封全部本轮正式入口，并分别等待已有单源收尾；保留分源真实文件／错误，但不组合出正常成功。部分已经完成的文件不得删除或拿旧列表末项补全。

覆盖丢失、用户离开、后台或销毁均保留真实原因。后台不能恢复旧轮；准备观测中的监听与相机同样关闭。并发停止／关闭复用屏障，失败保留原对象和再次关闭能力，历史启动错误不伪装成本次关闭失败。外部独立传感器或被动服务不受血压页关闭影响；资源忙时不抢占。

### 7. 原生产品页迁移与最小实际复用

新增 `pages/measurement/BloodPressureMeasurement`，页面与 Hook 只负责 React 订阅、权限／预览宿主等待、导航、中文提示和本地展示。`app/measurement` 组装真实相机配置和血压客户端；保持能力驱动后摄、可选补光、[1,1] 单块、720 方形／30 FPS 偏好，不能以设备不支持补光为由单独阻断。

从现有指尖提取实际跨页复用的预览、覆盖叠层、放置图与指导弹窗，仍以主题、受控 Props 和真实低频事实驱动；不复制整份指尖 Hook，不把血压阶段分支塞进所有指尖组件。指尖波形、历史和其自动切波形行为保留。

| 区域 | 血压语义 |
| --- | --- |
| 圆形预览、环和标签 | 真后摄、真实覆盖估计；未知占位，百分比固定宽 88 dp，部分覆盖不取整为100%，中央提示复用现有非阻断毛玻璃样式。 |
| 状态及倒计时 | 不随分页移动；所有准备保持00:30，正式计时消费原生 elapsed／remaining，收尾不冒充完成，中断保留真实剩余量。 |
| 第一页 | 复用轻覆后摄与正面持机两图及文案。 |
| 第二页 | 迁移现有贴胸双图十二帧矢量路径，两图共享320 ms六帧时序，保持手型、肩部透视、轻量阴影和后半段贴靠高亮；高亮不代表识别结果。 |
| 手势与自动翻页 | 原生横向整页分页及至少48 dp点击入口，200 ms标识过渡；进入贴胸准备／正式开始各切第二页一次，开窗前覆盖退回切第一页；手动切页不推进或重置会话，正常完成不强制改页。 |
| 动画生命周期 | 原生驱动离散帧序列，不对人体路径插值、不逐帧更新React；仅当前页且页面前台可见时播放，切离停止，遵循现有原生减少动态效果约定而不增加专项验收。 |

SVG 用 `react-native-svg`，主题同源、实例唯一 ID、数值变换及真实容器坐标，不能用 WebView、截图或在产品运行时读取 Demo JS。正尺寸布局和 Nitro 引用同时成立后才打开预览。页面低频快照普通变化最多250 ms合并，整秒及阶段驱动父页；相机和动画不随每次 IMU 更新重建，不在首屏增加倾角、相关分数或技术参数面板。

放置指导从第一阶段真实观测起十五秒每轮最多一次；进入 `awaiting_chest` 即清计时并收起，不在贴胸等待误报。确认只关闭指导，不能干预稳定与覆盖；开窗前退回第一阶段不重复弹已经使用的本轮提醒。失败、后台、离页与重试撤销旧轮回调。

### 8. 入口、返回与已有变更的边界

新增根栈 `BloodPressureMeasurement`，不显示产品底栏、不新增产品深链。`entry.ts`、导航类型及根栈同步接通，移除血压旧未接入分支及失效文案实际调用。部位与指标共用 `chest` 方式级偏好，未跳过保留准备页供返回，已跳过或当次勾选则直接返回原功能分类，不挂载隐藏引导。声音提醒仍只是已有准备提醒，不意味着语音已实现。

沿用 acquisition 离页守卫：先同步登记取消意图，解除可取消的预览布局等待，再等已发命令与整组关闭。权限弹窗无法取消时，返回后必须检查入口仍有效、页面仍在前台；系统授权造成的暂时失活不能误中断尚未取得资源的有效入口。关闭失败留页处理，成功才放行导航，迟到动作不能打开新资源。

## Risks / Trade-offs

- [稳定且倾角达标仍可能未贴胸] → 这是本期已接受的工程准入限制，不加主动确认或用固定等待假装位置识别；先取得正常操作效果，再决定是否优化。
- [心震微弱且设备噪声／衣物影响大] → 以原始量纲能量与重复性共同判定，不以z-score放大噪声；真机校准初值，未知不虚构通过，不承诺接触或医学质量。
- [实时带通不等于后端离线AO重建] → 只借鉴轴向和候选频带，因果处理留建立段，不宣称两端数值等价；正式原始文件不变。
- [统一控制窗口被误称为硬件同步] → 明确接收时间上下界、源内时间及相机时钟源限制，核查实际文件而不改写样本对齐。
- [类型级全局停止误停血压或独立来源] → 所有调用方及确切会话授权统一迁移，显式组内协调不扩散到独立传感器默认行为。
- [旧主规格及未实施编排提案与真实指尖冲突] → 在本次增量保留已完成指尖合同并明确协调例外，不修改其他变更或引入新旧双运行路径。
