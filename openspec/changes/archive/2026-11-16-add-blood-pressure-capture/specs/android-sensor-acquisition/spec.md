# Spec Delta

## MODIFIED Requirements

### Requirement: 同类型单活动会话与异类型隔离
每种类型 MUST 只有一个活动采集会话；该类型开始或收尾期间再次启动 MUST 返回 `SENSOR_BUSY`，不重复注册设备。不同类型 MUST 拥有独立状态、配置、会话、有限缓冲、停止结果和文件，任何类型的停止或采集失败不得自动停止或发布其他类型；唯一例外为显式血压轮次对自己持有的组内源按 `native-acquisition` 协调结束。血压的 ACC／陀螺仪占用 MUST 纳入同类型互斥，绑定调用方和轮次，不接管已有独立会话；普通停止命令不得越过所有权停止组内源，血压关闭不得停止组外会话。

#### Scenario: 同类型从两个客户端重复启动
- **WHEN** 一个客户端已启动加速度计，另一个客户端请求启动同类型
- **THEN** 后者取得 `SENSOR_BUSY`，前者的监听、参数和会话继续，不被替换

#### Scenario: 停止一路不影响另一路
- **WHEN** 加速度计与陀螺仪同时独立采集，调用方仅停止加速度计
- **THEN** 只完成加速度计文件，陀螺仪继续接受其后实际事件，直到它被单独停止

#### Scenario: 血压与独立入口争用同类型
- **WHEN** 独立加速度计或陀螺仪会话仍活动，血压请求取得该类型；或血压已占用该类型而独立入口请求启动
- **THEN** 新占用请求以 `SENSOR_BUSY` 失败，不复用、替换或停止已有会话，不将已有独立记录作为血压输入或产物

#### Scenario: 血压组内结束不影响组外类型
- **WHEN** 血压因截止、取消或组内失败关闭其 ACC／陀螺仪，而独立磁力计或重力传感器仍运行
- **THEN** 只结束该调用方及轮次持有的组内监听与文件，独立类型继续按原有参数采集，旧轮关闭不得注销后来轮次的监听

### Requirement: 原生正式窗口与迟到回调隔离
系统 MUST 用本源原生单调时间建立正式起止边界，并将回调绑定到创建它的会话；独立采集只接受入口开放且事件时间属于该窗口的记录。开始前历史事件、入口关闭后的事件以及旧会话迟到结果 MUST NOT 写入新会话。显式血压轮次的 ACC MUST 按回调接收的启动后单调时间检查本轮共同半开控制边界 `[T0,T1)`，并排除原始事件时间早于 T0 的历史事件；观测及准备期不属于正式保存。原始事件时间保持不变，共同控制边界不能替代事件时间。窗口不构成收齐全部硬件事件、精确曝光／事件对齐或跨源硬件同步的承诺。

#### Scenario: 注册后收到历史事件
- **WHEN** 新会话开始后收到事件时间早于其正式开始边界的样本
- **THEN** 该样本不进入本次文件，不伪造新的事件时间使其进入窗口

#### Scenario: 前次回调晚于下次开始
- **WHEN** 第一次采集已停止，第二次已开始，第一次的回调迟到
- **THEN** 它不能写入第二次的队列或文件，也不能改变第二次的运行状态

#### Scenario: 血压观测转为共同正式窗口
- **WHEN** 血压已经注册 ACC 用于贴胸观测，随后本轮共同正式窗口建立
- **THEN** 只有入口开放、回调接收时间落在本轮 `[T0,T1)` 且原始事件时间不早于 T0 的新记录才进入正式 ACC 文件，不把观测历史回填到文件；截止封闭后到达的回调也不因事件较早而重新入窗

### Requirement: 物理单位与设备坐标保持原始含义
各类型的三个轴列 MUST 保存标准 Android 默认传感器三轴值：加速度计含重力、重力传感器为 m/s²，陀螺仪为 rad/s，磁力计为 μT。坐标 MUST 基于设备自然方向，X 向右、Y 向上、Z 向屏幕外，不随屏幕旋转重映射；原始 CSV MUST NOT 去重力、滤波或校准，产物 MUST 明确类型、单位和坐标标识。显式血压轮次可在原生内部副本或有界状态上做姿态、稳定性和心震候选处理，但 MUST 保持原始文件的三种时间、轴值、单位、坐标和列协议不变，不以滤波结果替换原始记录，也不向 JS 推送三轴样本。

#### Scenario: 旋转屏幕但不旋转设备坐标定义
- **WHEN** 采集期间屏幕显示方向改变
- **THEN** 文件轴顺序与 Android 自然设备坐标保持一致，不静默交换 x/y，也不把加速度单位换成 g

#### Scenario: 血压内部处理同一条原始 ACC 输入
- **WHEN** 血压使用真实 ACC 执行去重力或滤波等内部判定，并将该事件作为正式记录接受
- **THEN** ACC CSV 仍保存该事件原始含重力三轴值和各自真实时间，内部状态保持有界，不将处理后的值、姿态角或心震候选写入原始轴列

### Requirement: 联合采集由 JS 编排且不改变其他能力
各源 MUST 允许 JS 分别发出控制命令；默认原生不得提供自动组合 PPG 与传感器的联合启停或失败级联。唯一例外 MUST 是用户显式发起的血压轮次，由原生按 `native-acquisition` 协调自己拥有的 PPG、ACC 与陀螺仪观测、共同正式接收窗口及组内结束；不得推广到独立入口。任何模式 MUST NOT 引入跨源共享文件事务。新增能力 MUST 保持既有 PPG 双 CSV、独立传感器四类型入口、相机页面清理、被动录像及相机互斥行为，不新增通知、共享存储或高采样率授权要求；血压沿用真实相机授权。并发启动命令及共同控制窗口不得被描述为跨源硬件同步。

#### Scenario: 传感器与 PPG 前台并行
- **WHEN** 用户先启动可用传感器，再在前台主动 PPG 页打开后摄、完成采集并关闭相机
- **THEN** 两路分别形成自己的原生记录，关闭 PPG 不停止传感器；由 JS 决定何时另行停止传感器，不宣称样本已对齐

#### Scenario: 显式血压轮次协调结束
- **WHEN** 用户明确发起血压轮次且本轮已取得所需源，共同窗口截止或组内任一路失败
- **THEN** 原生按该轮次关闭组内正式入口并等待各自收尾，不需要 JS 先后发出多个停止决定共同截止；组外独立源和文件保持不变

#### Scenario: 普通传感器失败
- **WHEN** 不属于血压组的独立传感器采集失败，且另一个独立源或 PPG 仍运行
- **THEN** 仍只封闭失败本源，不触发新增血压协调行为，不改变其他源的截止、监听或产物

## ADDED Requirements

### Requirement: 血压 IMU 观测必须使用真实 ACC 与陀螺仪
显式血压轮次 MUST 使用实际可用且成功注册的默认加速度计与陀螺仪，在贴胸准备至正式采集结束期间提供本轮原生观测，沿用明确的请求／注册采样间隔及真实事件时间，不承诺稳定实采频率。任一必要设备缺失、注册失败或有效输入失败 MUST 阻断准入并按组内合同收尾，不用模拟输入、其他传感器、固定稳定值或仅倾角分支降级放行。陀螺仪仅用于判定，本次 MUST NOT 要求生成陀螺仪文件。

#### Scenario: 倾角足够但设备没有陀螺仪
- **WHEN** 设备屏幕倾角可达到 30°，但默认陀螺仪不存在或监听注册失败
- **THEN** 血压如实报告设备或注册错误并关闭本轮已取得资源，不因姿态路径满足而跳过陀螺仪、不伪造稳定结果；独立可用类型仍可按原合同使用

#### Scenario: 血压运行而无陀螺仪产物
- **WHEN** 本轮真实 ACC 与陀螺仪已支持观测，并正常完成 PPG 双 CSV 与 ACC 文件
- **THEN** 组合成功不要求陀螺仪 CSV，不把内部陀螺仪观测发布为独立采集完成文件；独立陀螺仪入口原有 CSV 能力不变

### Requirement: 血压 IMU 观测与正式 ACC 文件分离
血压原生 IMU 观测 MUST 有界，并保留同轮身份、输入有效性与新鲜度；覆盖失效退回指尖阶段时 MUST 清除既有稳定性及心震准入累计，重新贴胸准备后取得新的有效观测。只有共同窗口内正式接受的 ACC 样本才写入本轮原始文件，正常定稿仍须实际样本、回调屏障、尾批写入与文件关闭完成。观测、解除页面订阅或内部滤波不得绕过文件错误、容量和收尾合同，也不得输出原始 IMU 给 JS。

#### Scenario: 准备观测没有正式开窗即取消
- **WHEN** 血压仍在贴胸观测或正式启动准备时取消本轮
- **THEN** 撤销自动开始并等待本轮 IMU 注销及在途回调结束，不把观测样本或仅表头文件作为正常完成 ACC 产物

#### Scenario: 覆盖退回后再次进入贴胸准备
- **WHEN** 覆盖失效导致血压退回指尖阶段，随后重新满足完整覆盖三秒
- **THEN** 当前准入不沿用退回前的稳定性、心震候选或旧窗口，必须基于新有效观测判定；准备样本仍不回填正式文件

#### Scenario: 正式 ACC 没有实际样本或收尾失败
- **WHEN** 共同窗口结束但 ACC 未接受实际样本，或 ACC 尾批、关闭、定稿失败
- **THEN** 按原传感器错误合同失败，不发布空文件或临时路径为成功 ACC，也不让 PPG 已完成替代整组成功
