# Spec Delta

## MODIFIED Requirements

### Requirement: 启用时说明厂商后台活动设置
应用 MUST 仅在用户从功能页无扰心率开关或开发被动采集页面明确发起启用时，说明设备厂商后台活动设置可能影响运行。按钮 MUST 与 Demo 相同，从上至下为“已设置／不适用，继续”（主按钮）、“打开应用设置”、“取消”；确认后才继续原有授权，打开设置或取消不启用。两个原生入口 MUST 控制同一真实服务并沿用相同相机与通知检查。该设置不是通用 Android 运行时权限，应用 MUST NOT 声称自动授予或验证；普通进入页面、返回前台及主动 PPG 操作 MUST NOT 提示或自动启用。

#### Scenario: 用户确认后台活动设置
- **WHEN** 用户在开发页点击“授权并启用无扰采集”，或在功能页请求开启无扰心率检测
- **THEN** 应用说明 Honor 等设备的“允许后台活动”设置路径；用户确认已设置或设备不适用后，才继续原有相机和通知授权流程并启用同一服务，成功后等待新的解锁事件而不立即打开相机

#### Scenario: 取消或仅打开系统设置
- **WHEN** 用户取消启用说明，或仅选择打开应用设置而未确认继续
- **THEN** 不执行启用；返回时重新读取实际服务状态，不将打开设置、授予权限或旧开关位置视为启用成功

#### Scenario: 从其他入口关闭后回到功能页
- **WHEN** 用户从开发页或持续通知关闭服务并完成收尾，再返回功能页
- **THEN** 产品开关显示真实未启用，不保存相反的本地偏好，不因为切页重新开启，已完成本地产物仍按原契约保留
