# Spec Delta

## MODIFIED Requirements

### Requirement: 血压页面迁移真实双阶段原生界面
血压页 MUST 沿用已确认设计的圆形真实后摄预览、覆盖环、固定宽 88 dp 百分比标签、镜头中央非阻断毛玻璃提示及底部状态／倒计时，提供指尖放置与贴胸指引两页。布局 MUST 使用原生逻辑尺寸、安全区、主题和等比图形，毛玻璃复用既有原生相机适配，不以网页或截图承载页面。准备及采集中 MUST NOT 挂载脉搏波、血压读数、倾角／质量／判定参数面板、用于采集准入的主动确认、手动开始或外部模拟控件，也不得改变真实指尖单源行为；操作指导的确认只收起说明。正常联合收尾后允许独立固定样例结果弹层及详情，不回填采集界面或改变准入。

血压镜头中央提示 MUST 复用指尖的主题混色：心率红 `accent.rose`、薄荷绿 `brand.gradient.end` 分别与正文色 `text.primary` 按 70%／30% 混合。等待或部分覆盖、等待贴胸及中断后的重测指引用红色，完整覆盖待开始与正式检测用绿色，收尾和完成用正文色；颜色只表达操作阶段，不改变覆盖、贴胸准入或健康评估。

#### Scenario: 明确进入血压页
- **WHEN** 用户经准备确认或跳过偏好明确进入血压检测
- **THEN** 建立新轮并显示第一阶段指尖指引，按真实授权、预览引用及正尺寸布局就绪路径准备后摄；本轮尚未观测时覆盖未知，不用红色模拟层、等待动画或假 IMU 填补真实输入

#### Scenario: 相机或必需 IMU 不可用
- **WHEN** 相机授权被拒绝、后摄或本轮所需 ACC／陀螺仪不可用，或资源被其他所有者占用
- **THEN** 沿用统一中文反馈和必要重试／返回，不伪装为检测中，不新增无 IMU 的兼容路径，也不停止占用者；可选补光仍遵循既有真实指尖能力合同

#### Scenario: 常规 Android 页面还原
- **WHEN** 在常规竖屏、默认字号及正常动态效果下检查血压页面
- **THEN** 按等价内容视口对照设计稿的构图、配色、圆角、照片及插画层级，必要返回、分页及反馈操作可达，安全区不重复；真实相机内容不要求逐像素一致，不增加横屏、多设备矩阵或专项无障碍验收

### Requirement: 血压终态服从联合收尾且不自动续采
血压页 MUST 仅在同轮 PPG 双 CSV 与 ACC 文件均正常定稿、全部本轮资源释放后显示正常采集完成，保留结束覆盖快照、00:00、两页指引及用户当前分页，再进入独立三秒样例结果等待。结果可用后允许查看样例血压及显式重新检测，但不得上传、发布真实健康结果或写健康记录。正式采集覆盖丢失、后台、离页或技术失败 MUST 结束整轮并沿既有反馈提供必要重试／返回，保留实际计时而不冒充采满；重新放置或返回前台不得自动续采，明确重试 MUST 先完整关闭旧轮。

#### Scenario: 联合采集正常完成
- **WHEN** 同轮联合正式三十秒到时且 PPG 双 CSV、ACC 与资源屏障全部成功
- **THEN** 镜头提示可以移开手指并放下手机，冻结真实覆盖快照和 00:00，保留指引且不强制改变当前分页，进入结果等待；冻结值不表示相机继续识别，随后固定读数不代表本轮算法输出，不改写首页或最近检测时间

#### Scenario: 正式采集中覆盖丢失
- **WHEN** 正式窗口内原生按维持阈值及丢失宽限确认覆盖丢失
- **THEN** 结束本轮相机及本轮 IMU，停止正式计时并反馈中断；不得像 Web 模拟流程那样复位为等待放置后自动开始新轮，不拼接移开前后数据，不把单一路完成当作整体成功，也不展示样例结果

#### Scenario: 后台返回或关闭失败
- **WHEN** 准备或正式采集中宿主进入后台后返回，或本轮相机、IMU、文件收尾失败
- **THEN** 刷新真实终态并提供既有必要反馈，不进入结果等待，后台不暂停续演；关闭失败保留页面及再次关闭能力，重新放置、恢复订阅和前台恢复均不重开本轮，只有完整关闭后的明确重试才能清空旧关联建立新轮

### Requirement: 指尖结果看板复用四项固定展示内容
弹层和详情 MUST 展示同源两行两列看板：心率、呼吸率、血氧饱和度、糖尿病风险，读数保持中性色，不从参考区间推断健康等级。图形 MUST 复用对应 SVG 轮廓、比例和主题色，血氧看板使用完整半圆仪表，风险值按等级／风险两行展示。卡片 MUST 保持 16 dp 内边距；弹层及详情均使用纯白底、浅色细边框、22 dp 圆角和无阴影，不改变读数、角标与图形排布。

#### Scenario: 两处看板展示一致
- **WHEN** 用户查看简要结果或详细结果
- **THEN** 均显示心率 72 次/分、呼吸率 16 次/分、血氧 98% 和较低风险；前三项底部参考区间分别为 60–80 次/分、12–20 次/分、95–100%，风险卡显示“仅供参考”，不加参考区分隔线；心率、呼吸和风险图标均为 56 dp

### Requirement: 指尖详情按总览波形和指标解读组织
详细结果 MUST 不包含摄像预览、倒计时或产品底栏，按结果总览、四项看板、处理后脉搏波和指标解读组织。总览标题右侧 MUST 显示完整时间，不增加报告大标题或检测时长。各指标解读 MUST 使用独立白底、22 dp 圆角、浅色细边框、无阴影、16 dp 内边距的卡片，间距 12 dp；上排为名称及 48 dp 图标与读数、评估、介绍，下方建议或风险说明占整行，不截断。

#### Scenario: 浏览总览与解读
- **WHEN** 用户进入详情并向下滚动
- **THEN** 可查看四项总览、质量说明、处理后波形，以及与 Demo 一致的三项生命体征解读和糖尿病风险说明；解读区血氧使用原有血氧 SVG 图形和主题玫红而非半圆仪表，风险读数保持单行

#### Scenario: 健康参考声明只出现一次
- **WHEN** 用户查看简要结果或详细结果
- **THEN** 原生与 Demo 的弹层在指标卡下方、操作按钮上方居中展示一次“检测结果仅供健康管理参考，不能替代医学诊断。”，与下方主按钮仅保留12逻辑单位间距，不叠加声明底部外边距；详情仍在总览标题与时间行下方、看板之前左对齐展示一次“检测结果仅供健康管理参考，不能替代医学诊断。如有持续不适，请及时就医。”，不在报告末尾重复，不改变详情声明间距

#### Scenario: 风险含义不扩张
- **WHEN** 用户阅读糖尿病风险解读
- **THEN** 保留 Demo 的风险参考、必要咨询与检查建议，明确该结果不等于血糖值、患病概率或确诊，不计算风险分数

### Requirement: 处理后波形独立展示三十秒固定样例
指尖详情及血压详情的 PPG MUST 独立显示三十秒处理后波形固定样例，不读取、加工或替换检测页的真实采集曲线。样例生成源 MUST 使用负向原始幅值，经统一绘图层 `displayY = -rawY` 后呈现正向脉搏，固定显示纵轴为 `[-0.135, 1.212]`；不在调用适配层重复翻转。窗口 MUST 初始为 0–6 秒、每屏固定六秒，只能横向平移至全轮范围，不能缩放，不自动连续滚动或提供拖动条。波形卡 MUST 使用白底、浅色细边框、22 dp 圆角及无外部阴影，保留品牌 1.5 dp 细线、绘图区圆角及浅绿模糊内边缘，不改写生成后的样例值或影响实时波形的缩放策略。

#### Scenario: 拖动查看全轮处理后波形
- **WHEN** 用户在详细结果的波形内横向拖动
- **THEN** 仅改变六秒视窗及范围文字，可从 0–6 秒查看至 24–30 秒；标题、“处理后”与“左右滑动查看”同行，范围和“共 30 秒”位于波形下方，不增加重复说明或实时回到最新按钮

## ADDED Requirements

### Requirement: 血压正常收尾后等待三秒并自动展开一次
血压 MUST 在本轮正常目标完成、联合文件及全部本轮资源收尾成功且无失败或离开请求后，按前台且本页可见时间累计三秒结果等待。等待 MUST 独立于正式计时、原生状态和语音，期间显示等待状态、加载入口及 loading Toast“等待检测结果，请稍候…”，保留真实结束覆盖和00:00。到期结果可用并只自动展开一次，倒计时归零、声音结束或任一单源完成均不构成资格。

#### Scenario: 等待完成与重复通知
- **WHEN** 同轮累计可见等待达到三秒，之后继续收到完成通知或用户收起结果
- **THEN** 关闭本轮等待 Toast，恢复“查看本次结果”入口，首次自动展开；之后不重等、不重置或再次自动展开

#### Scenario: 等待期间后台及退出
- **WHEN** 等待中进入后台、恢复前台，或真正退出、重测、卸载
- **THEN** 后台暂停等待并清理本轮 Toast，前台有效等待时恢复；退出、重测和卸载撤销旧轮资格与计时，迟到回调不弹结果或误关其他提示，不重新打开相机

### Requirement: 血压简要结果沿底部面板展开
血压结果弹层 MUST 沿用指尖约420毫秒上移动画、青绿至白色柔和背景、自然内容高度、安全区内滚动及独立顶部边缘箭头。内容依次为40逻辑单位成功图形与检测完成、移开手指并放下手机提示、完整固定时间、血压主卡、一次居中短声明及“查看详细结果／重新检测”。原生与 Demo 的短声明和下方主按钮 MUST 仅保留12逻辑单位间距，不叠加声明底部外边距。背景遮罩隔离操作；弹层不额外显示质量长说明，收起入口不推移底层状态与分页，详情声明布局保持不变。

#### Scenario: 收起重开和返回优先级
- **WHEN** 用户点击边缘箭头、遮罩或按 Android 返回
- **THEN** 只收起弹层而不离开检测页，可通过“查看本次结果”重开同轮结果，箭头不随正文滚动裁切；弹层展开时背景预览、分页及返回不响应

### Requirement: 血压弹层与详情共用固定主卡
血压主卡 MUST 为白底、浅色细边框、22逻辑单位圆角及无阴影；展示三个相连的参考区间带、固定正常区标记、“血压正常”、估计血压值及信号质量82分。收缩压118、舒张压73分别带 mmHg 与参考区间90–139、60–89。时间固定为2026年10月31日08:30，弹层和详情一致。质量不代表医学准确率，评估和标记不由前端阈值计算，不增加“血压评估”标题或评分角标。

#### Scenario: 主卡参考带和读数层级
- **WHEN** 用户查看任一血压结果主卡
- **THEN** 16逻辑单位高的三段带上边平直、下边圆拱且相接，90/60、140/90各对齐分界虚线并带相邻区间配色的小三角；偏低／正常／偏高位于带上方，薄荷绿“本次结果”标记以向上三角指向正常区；36／44字号行高的“血压正常”与上下内容各间隔12，双读数为32／40，单位位于指标名称旁，质量文字位于“估计血压值”右侧

### Requirement: 血压详情组织总览波形与结果解读
血压详情 MUST 不显示摄像预览、倒计时或产品底栏，依次提供总览与完整固定时间、左对齐完整健康声明、同源主卡、质量说明、PPG及SCG两张处理后波形卡、结果解读。解读分别涵盖整体评估、收缩压、舒张压和日常建议，主卡、波形卡及解读卡统一白底、浅色细边框、22逻辑单位圆角及无阴影；不新增校准或历史趋势入口。

#### Scenario: 阅读质量与健康参考
- **WHEN** 用户滚动血压详情
- **THEN** 质量说明明确满分100且不代表血压估计准确率，完整声明仅在总览和主卡之间出现一次；保留使用经验证上臂式血压计确认及不据本次估计自行调整用药的建议，不增加前端医学判定

### Requirement: 血压报告两种波形独立回看固定样例
血压详情 MUST 纵向显示“PPG 脉搏波”和“SCG 心震波”，各自保留完整三十秒固定样例，初始0–6秒、每屏六秒，可独立横向平移至24–30秒，不缩放或自动滚动。PPG使用30Hz处理后样例；SCG使用独立100Hz正负振动样例，不复制PPG形态，不读取真实加速度。绘图区高164逻辑单位，品牌细线及内边缘效果与指尖相同，纵轴固定并使样例占高度10%–85%。

#### Scenario: 两图拖动互不影响
- **WHEN** 用户将SCG拖到最后窗口，再查看PPG
- **THEN** SCG显示24–30秒，PPG仍在原窗口，样本和全轮固定纵轴不变；离页释放两图，重新进入详情从初始窗口展示，不增加检测页或简要结果中的波形

### Requirement: 血压同轮详情往返保留展示且重测清空
血压 MUST 只在已释放资源的同轮检测页与详情之间保留完成状态、结束覆盖、当前指引分页及样例结果，不重复等待、采集或语音。详情返回恢复简要结果；重新检测先确认旧轮安全关闭，再清空结果资格、覆盖、计时、分页及旧轮关联，建立新的真实轮次。真正退出或卸载 MUST 清理展示内存和迟到回调，不持久化结果、不删除完成文件，也不影响指尖结果。

#### Scenario: 详情返回与明确重测
- **WHEN** 用户从血压详情返回，随后在简要结果点击重新检测
- **THEN** 返回时恢复原轮结果，不重开设备；重测后覆盖未知、倒计时00:30、第一页指尖指引，须重新满足真实覆盖及联合准入，旧轮结果不在新轮出现

#### Scenario: 样例与真实记录隔离
- **WHEN** 用户查看或离开血压结果
- **THEN** 固定读数、评估、时间、质量和两种处理后波形不回填真实采集、不写首页或历史、不更新最近测量时间、不发起上传、推理或结果请求；未正常完成的轮次不能从导航绕过资格进入详情
