# Spec Delta

## MODIFIED Requirements

### Requirement: 产品与开发入口使用统一底部导航
应用 MUST 提供健康、功能、历史、我的、开发五个底栏入口，其中历史进入可浏览的指标历史页面，不再拦截为未开放说明。开发入口 MUST 集中承载已有验证页面及相关操作，当前阶段可见，并允许通过单一集中配置在后续隐藏；本次 MUST 不删除原验证能力或将其混为产品测量功能。健康、功能、历史、我的四个产品入口的图标 MUST 对齐 Demo 对应几何，选中使用实心图形与 `#0AB6C0`，未选中使用描边图形与 `#666666`，标签颜色与当前状态一致；除明确开放历史及关联入口外，视觉调整 MUST NOT 改变既有资源交接。

#### Scenario: 进入开发验证
- **WHEN** 用户从任一可浏览产品页面点击开发 Tab
- **THEN** 进入统一开发入口，可打开既有验证页，返回时导航层级明确，不创建第二套独立应用导航

#### Scenario: 历史入口未开放
- **WHEN** 用户点击此前仅显示未开放说明的历史底栏入口
- **THEN** 选中历史Tab并展示同一历史页面，保留已提交的指标及日期筛选；未确认认证时显示健康空态，不触发后端记录查询

#### Scenario: 产品底栏选中与未选中图形
- **WHEN** 用户在健康、功能、历史和我的页面间切换
- **THEN** 当前产品 Tab 使用 Demo 对应的实心图形和 `#0AB6C0`，其他产品 Tab 使用描边图形和 `#666666`，标签颜色随选中状态一致切换；开发入口仍保留

### Requirement: 产品检测页面独立于开发验证导航
应用 MUST 全局固定竖屏，在现有根导航中提供产品准备、面部／指尖／血压页面及本轮指尖／血压详细结果页，不显示产品底栏，不新增导航容器、Tab 或公开产品深链。首页及指标详情的检测动作 MUST 共用原有方式映射与跳过偏好；未跳过时指尖与血压保留准备页，已跳过或当次跳过时不挂载隐藏准备页或补声音提醒。面部及完成后的退出按发起来源返回，功能页不再存在分类状态；详情返回 MUST 恢复本轮完成检测及简要结果，不创建新轮。真实检测离页 MUST 等待本轮关闭屏障，详情往返只保留已释放资源轮次的展示数据，不保持相机或IMU占用，不扩大既有Dev验收。

#### Scenario: 功能进入面部检测并返回
- **WHEN** 用户从功能页确认进入面部检测，再通过页内或 Android 返回离开
- **THEN** 保留无底栏布局，资源安全关闭后返回功能部位目录，不露出多余准备页或开发验证页面

#### Scenario: 未跳过时指尖返回引导
- **WHEN** 用户未跳过引导，从指尖检测页返回且当前未展开结果弹层
- **THEN** 先取消本轮待执行自动开始、结果等待及回调，并等待命令、相机和文件收尾，再回到准备页并清理本轮展示；再次返回可到发起来源，不进入开发相机页

#### Scenario: 已跳过时指尖返回功能
- **WHEN** 用户从功能页通过已保存或当次跳过入口进入指尖检测后返回，且当前未展开结果弹层
- **THEN** 完整关闭并清理本轮展示后直接回到原功能部位目录，不显示引导或声音提醒；再次明确进入建立新轮，不继承上轮覆盖、时间、曲线或样例结果

#### Scenario: 未跳过时血压返回准备
- **WHEN** 用户未跳过血压引导，从指尖覆盖、贴胸准备或正式血压采集阶段返回
- **THEN** 阻断未执行自动开始并等待本轮相机、IMU 和文件完整关闭，再回到血压准备页；再次返回可到原首页或功能目录，不进入开发传感器或相机页面

#### Scenario: 已跳过时血压返回功能
- **WHEN** 用户从功能页通过已保存或当次跳过的血压入口进入后，在结果弹层未展开时通过页内或 Android 返回离开
- **THEN** 等待本轮联合关闭屏障后直接回到原功能部位目录，不挂载隐藏准备页或声音提醒；再次明确进入建立新的独立轮次，不继承旧覆盖、IMU准入、计时或产物关联

#### Scenario: 从可用简要结果进入详情
- **WHEN** 用户在本轮指尖或血压结果弹层中点击“查看详细结果”
- **THEN** 进入对应方式的独立详情，无产品底栏，不经过开发入口；底层已释放相机及本轮IMU，仍保留完成展示，指尖保留真实波形，返回动作不会开启新检测；两方式不串用轮次或结果

#### Scenario: 详情页内及系统返回
- **WHEN** 用户在指尖或血压详情点击返回或按 Android 返回键
- **THEN** 回到对应原检测页并展示同一轮简要结果，不回准备或功能页，不重复三秒等待；再次返回先收起弹层，弹层收起后才按原入口规则退出检测

#### Scenario: 从首页及指标详情发起检测
- **WHEN** 用户从首页血压主按钮或指标详情的测量操作进入检测
- **THEN** 先结束指标浮层，再按方式及跳过偏好进入同一产品检测流程，退出恢复发起的首页，不创建重复Tab容器、隐藏准备页或开发页面
