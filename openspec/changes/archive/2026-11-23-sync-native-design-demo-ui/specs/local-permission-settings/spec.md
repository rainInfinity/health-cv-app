# Spec Delta

## MODIFIED Requirements

### Requirement: 本地权限设置对游客开放
通知设置和隐私与授权 MUST 对游客和已登录用户均可访问，展示应用实际使用的相机及通知权限用途和状态，不要求云端服务或健康资料。MUST 不展示未使用权限或假偏好开关，不实现提醒计划或消息推送。功能页允许提供控制同一真实被动服务的“无扰心率检测”开关，但权限页仍只管理真实系统授权，不新增独立被动偏好或将权限已授权当作服务已启用。

#### Scenario: 未配置云端服务的游客查看设置
- **WHEN** 用户在无云端配置的应用中打开通知或隐私设置
- **THEN** 可查看本地实际权限状态与操作入口，不要求登录，不发送后端请求

#### Scenario: 权限与产品开关相互独立
- **WHEN** 用户仅在权限页授予相机或通知权限，再返回功能页
- **THEN** 无扰心率开关仍按真实服务状态展示，不仅因授权成功自动开启；功能页启用仍须用户明确操作并遵循既有被动服务要求
