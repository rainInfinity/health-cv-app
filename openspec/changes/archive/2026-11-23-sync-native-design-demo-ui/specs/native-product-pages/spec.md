# Spec Delta

## REMOVED Requirements

### Requirement: 功能目录按检测部位与指标提供入口
**Reason**: 功能页已确认移除双分类与指标列表，原条款中的分类及分类保留场景不再适用。
**Migration**: 由“功能目录直接按检测部位提供入口”替代；三个部位、指标详情的方式映射、跳过偏好及真实采集边界保留。

## MODIFIED Requirements

### Requirement: 健康展示严格由确认认证状态决定
首页、指标详情与历史 MUST 仅在 `authenticated` 展示固定 mock 健康读数及对应时间，不添加示例或演示数据说明。`anonymous`、`restoring` 和 `unavailable` MUST 展示空健康内容；后两者 MUST 在账号区域表达真实状态，不冒充游客。原生首页与历史时间 MUST 使用北京时间中文日期和24小时制，不因设备地区改成英文或 AM/PM，不改变原时刻。mock MUST 不写入服务端资源、账号资料或采集状态。检测流程内的独立固定样例结果仍遵循对应检测规格，不成为首页或历史的数据来源。

#### Scenario: 游客空态
- **WHEN** 当前状态为 anonymous，用户查看主页、指标详情或历史
- **THEN** 读数显示 --、时间显示暂无记录，仪表无有效填充，不出现评估结论、样例数值或趋势；历史筛选可用但记录为空

#### Scenario: 认证成功
- **WHEN** 登录已保存凭据并完成服务端身份确认
- **THEN** 主页与指标详情显示固定 mock 内容，历史展示其固定日期样例；风险和面部独立记录等没有 mock 的项目仍为空，不编造结果

#### Scenario: 退出时详情仍打开
- **WHEN** 认证明确失效或退出导致当前会话不再已确认，而已有详情、历史或记录浮层仍可见
- **THEN** 主页、详情和历史健康内容均更新为空态，不残留登录态读数；功能部位入口和真实被动服务开关仍可访问

#### Scenario: 会话恢复暂不可确认
- **WHEN** 认证恢复因网络故障进入 unavailable
- **THEN** 产品页仍可浏览且健康内容为空，账号区说明暂不可确认，不删除凭据或显示为已退出


### Requirement: 未开放业务只保留入口
健康资料引导、健康资料、个人资料和帮助反馈 MUST 仅保留入口，触发统一未开放说明，不实现表单、资料编辑或反馈提交；健康资料引导 MUST 不形成首次流程第三步。历史 Tab、指标详情历史入口及“我的健康记录”改为可进入的只读固定样例历史，不再触发未开放说明，不查询后端记录。

#### Scenario: 点击历史或健康记录
- **WHEN** 用户点击历史 Tab、详情历史入口或我的健康记录
- **THEN** 进入同一个历史页面，详情入口选中对应指标，其他入口保留当前筛选；未确认认证时展示历史空态，不改变真实认证或生成记录

#### Scenario: 资料与反馈入口
- **WHEN** 用户点击个人资料、健康资料、后续健康资料引导或帮助反馈入口
- **THEN** 仍显示相应未开放说明，不出现姓名编辑、健康表单、反馈输入或提交成功；健康资料说明可承载后续引导入口

## ADDED Requirements
### Requirement: 功能目录直接按检测部位提供入口
功能页 MUST 直接显示面部、指尖、指尖＋胸口三张照片卡片，不再提供分类切换或五指标列表。三入口 MUST 沿用检测方式、目标映射及设备级跳过偏好，未跳过进入准备，已跳过直达检测且不补声音提醒；游客不强制登录。面部仍显式开始，指尖及血压仍使用各自真实本地采集；本页不创建或上传云端任务，不因样例结果更新最近测量信息。

#### Scenario: 游客点击测量入口
- **WHEN** 游客点击功能页任一部位卡片
- **THEN** 不强制登录；按方式及跳过偏好推进，面部待开始页不启动设备，指尖等待覆盖稳定，血压等待真实双阶段联合准入

#### Scenario: 功能最近测量信息
- **WHEN** 游客或已确认账号访问改造后的功能页
- **THEN** 显示三个部位入口和操作说明，不再显示已移除指标列表的最近测量行，不将本轮采集或样例结果时间作为新健康记录

#### Scenario: 按检测部位进入
- **WHEN** 用户尚未保存该方式跳过偏好，点击面部、指尖或指尖＋胸口卡片
- **THEN** 分别进入对应准备页；面部目标仍为面部心率，指尖不预选指标，指尖＋胸口仍为血压估计，不增加主动确认或手动开始门槛

#### Scenario: 指标入口统一方式映射
- **WHEN** 用户从首页指标详情而非已移除的功能分类进入检测
- **THEN** 心率、呼吸率、血氧和糖尿病风险进入同一指尖方式，血压进入指尖＋胸口方式，沿用同一准备偏好和真实检测，不按指标名称另建推理或采集流程

#### Scenario: 已保存跳过偏好的功能入口
- **WHEN** 用户勾选某方式“以后不再提示”后再次点击对应部位卡片
- **THEN** 不显示引导或声音提醒；面部进入待开始页，指尖与血压分别建立新的真实轮次，其他方式偏好不受影响

#### Scenario: 返回保留来源
- **WHEN** 用户从功能页进入准备或检测后返回
- **THEN** 回到同一部位目录而非开发页或旧指标分类；未跳过时指尖与血压先返回准备页，已跳过或当次跳过时完整关闭后直接回功能页

#### Scenario: 新页面不发布健康记录
- **WHEN** 用户结束面部、指尖或血压真实本地采集，或查看其独立固定样例结果后回到首页、功能和历史
- **THEN** 不改写既有健康摘要、固定时间、面部独立记录或风险历史，不将覆盖、波形、心震候选、文件完成或固定结果当作真实健康记录，不上传任务

### Requirement: 功能页无扰心率开关反映真实被动服务
功能页 MUST 在面部卡片上方展示“无扰心率检测”卡片及“日常解锁使用手机时，自动测量心率”说明。只有右侧图标开关可以启停，卡片空白和文字不触发。开关 MUST 复用真实被动服务，游客及无云端配置也能操作，不存独立演示偏好；启用先完成既有后台活动说明与权限检查，关闭等待真实收尾，失败反馈原因而不显示虚假成功。

#### Scenario: 关闭与开启外观
- **WHEN** 服务处于未启用或已启用的稳定阶段
- **THEN** 关闭为灰色轨道、白色滑块和灰色同源心率图案，开启为青绿渐变轨道、右侧白色滑块、深青图案及青绿双波纹；轨道为柔和内阴影而非硬轮廓，心率滑块以柔和外阴影区分背景，切换沿用约240毫秒过渡，点击目标至少48逻辑单位，不因动效启停服务

#### Scenario: 等待服务确认及防重复
- **WHEN** 用户发起授权、启动或关闭，或服务仍在启动／收尾
- **THEN** 开关表达处理中且不可重复触发，不通过先翻转本地状态宣称成功；取消启用说明不执行命令，拒权或失败保留真实状态并提供必要反馈和设置入口

#### Scenario: 开发页通知和页面返回同步
- **WHEN** 用户在开发页或通知栏改变服务，或从系统设置、后台、其他页面返回功能页
- **THEN** 开关按真实服务状态更新，页面离开只解除展示订阅而不关闭服务；重新进入、应用重启或退出账号不会仅因旧开关偏好自动启用，也不把实时被动读数写入产品健康展示

### Requirement: 首页及指标详情衔接检测与历史
已确认登录时，首页血压主按钮 MUST 进入血压检测准备或按已保存偏好直达检测，详情按钮仍打开指标详情。指标详情 MUST 保留读数、时间和指标说明，增加“历史与趋势”和“功能说明与入口”操作，分别进入对应指标历史及对应真实检测方式；不得复制 Web 的假测量说明。游客首页入口仍沿用登录引导，不改变功能页本地检测对游客开放的规则。

#### Scenario: 血压主按钮与详情分工
- **WHEN** 已确认登录用户点击首页血压主按钮或详情按钮
- **THEN** 主按钮进入血压检测流程，详情按钮仍打开指标详情；返回按原来源恢复，不绕到开发页

#### Scenario: 从指标详情查看历史或检测
- **WHEN** 用户在心率、呼吸率、血氧、糖尿病风险或血压详情选择历史或测量
- **THEN** 历史选择对应指标并保留日期区间；测量遵循同源方式映射和跳过偏好，先关闭指标浮层再进入目标，不让旧浮层残留在检测页下方

### Requirement: 设计稿无扰开关只模拟确认与启停等待
Demo 的功能页无扰开关和隐私偏好 MUST 共用本地状态及启停流程，明确确认后等待约1秒再更新开启，关闭同样等待。等待中 MUST 保留上次确认外观、显示局部加载并禁用重复操作；取消、关闭说明或仅去设置不启用，切页与重置撤销未完成动作，刷新恢复关闭。Demo MUST 不申请真实权限、不打开系统设置、不启动相机或被动服务，不生成心率或回写健康内容；此本地偏好不得作为原生服务状态来源。

#### Scenario: Demo 明确继续后等待启用
- **WHEN** 用户在 Demo 请求开启并选择“已设置／不适用，继续”
- **THEN** 等待约1秒后才显示开启，期间保持原开关外观并禁止重复；关闭也经过同样等待，已确认的本地状态可在本次标签页内切页保留

#### Scenario: Demo 取消或只去设置
- **WHEN** 用户取消、关闭或点遮罩收起说明，或只选择“打开应用设置”
- **THEN** 不启用；设置动作只进入 Demo 的隐私授权展示，不打开真实系统设置，返回后仍须重新明确确认

#### Scenario: Demo 等待期间离页或重置
- **WHEN** 启停尚未完成时切换页面或重置演示
- **THEN** 撤销未完成动作和局部加载，不让旧计时在新页面翻转状态，也不申请权限、启动服务或改写健康数据
