# Proposal

## Why

将已确认的结果卡片、血压结果、历史记录和健康功能页展示迁移到原生，并把后续菜单、日历、趋势与无扰开关的交互调整同步到对应 Demo 设计。两端保持设计语义一致，原生保留真实采集、认证及资源生命周期，Demo 保留本地演示边界，不把固定样例或模拟等待解释为真实测量与服务成功。

## What Changes

- 对齐指尖详细结果的卡片外观：结果看板、处理后波形和解读卡统一白底、浅色细边框、圆角、无阴影，保留已实现的布局、质量角标及本轮详情往返。
- 在血压真实联合采集正常完成并释放资源后，增加三秒结果等待、简要结果弹层和独立详细结果；使用 Demo 对应的固定血压读数、质量、评估、解读及独立三十秒 PPG／SCG 样例，不处理真实 ACC 或推理血压。
- 开放原生历史 Tab，使用已有固定日期样例实现五指标切换、日／7天／30天／自定义区间、趋势与统计、最近10条、全部记录及单条详情；保留只有认证已确认才展示健康样例的规则，不新增样例或放开游客。
- 功能页移除“按检测部位／按指标”分类及指标列表，只保留面部、指尖、指尖＋胸口三个部位入口；顶部增加 Demo 样式的“无扰心率检测”卡片，复用真实被动服务启停、授权与状态，不新增假偏好。
- 衔接首页血压主按钮、指标详情的历史／测量入口及“我的健康记录”，共用既有检测方式映射、设备跳过偏好和历史筛选状态。
- 原生与 Demo 的历史指标入口统一采用底部占屏幕60%的滚动单选菜单，顶部为取消、标题、确认；自定义分段直接打开日期日历，只有明确选日并确认后才应用且保持分段选中，未选日期返回时保留原筛选。
- 日期日历支持年份、月份和日期面板，固定预留六行日期，标题加粗居中且无关闭图标，底部取消与确认横向等宽排列；保留原七列与触控布局，原生日期选中及区间背景使用居中1:1圆角正方形。
- 对齐历史主题色标题、区域间距、原生中文北京时间和两端健康参考声明，保留柔和阴影的凹槽与滑块；原生趋势浮层使用无边框阴影，两端支持按下后横向拖动查看及约350毫秒数据更新动画，不改变记录、统计、坐标或实时脉搏波。
- 缩短两种简要结果弹窗声明与主按钮的间距至12逻辑单位；原生无扰开关轨道与心率滑块使用柔和阴影，后台设置说明按钮顺序与 Demo 一致，Demo 补齐确认、取消和启停等待而不调用真实权限或服务。
- 明确替代现行规格中“历史未开放”“功能必须双分类”“血压不提供完成后结果／重测”“指尖详情轻阴影”及“不得新增产品被动开关”的限制，保留其余真实能力边界。

## Capabilities

### New Capabilities

- `native-health-history`：原生指标历史的日期筛选、同源趋势统计、记录列表与详情，以及固定样例和认证空态边界。

### Modified Capabilities

- `native-product-pages`：功能目录改为三个部位入口，接入真实无扰心率开关，开放历史及相关产品入口；个人资料和帮助反馈仍未开放。
- `native-measurement-pages`：统一指尖结果卡片外观；增加正常联合采集后的血压样例结果、报告波形、详情往返与重测。
- `native-app-shell`：历史 Tab 变为可进入页面，补血压详细结果导航和首页衔接，保留开发入口与真实资源交接。
- `local-permission-settings`：允许功能页新增真实被动服务开关，权限页仍只管理真实授权，不复制 Demo 的假偏好。
- `android-passive-capture`：功能页启用同样经过既有后台活动说明、权限和通知检查；产品、开发页与通知操作控制同一个真实服务。

## Impact

- 目标端为 `apps/native` 与 `docs/design-demo`。原生实现完整产品交互与既有真实业务边界；Demo 仅同步已确认的历史背景、底部菜单、日期日历、自定义区间、趋势交互、结果声明间距及无扰确认等待，不迁移模拟采集或演示认证到原生。
- 涉及原生 `pages/measurement`、`pages/history`、`pages/features`、`pages/home`、`pages/user/UserScreen`、`shared/components`、`shared/dateTime`、`app/navigation`、`app/measurement/entry.ts`、`app/passive-capture.ts`、文案与对应 Demo 页面模块；同步前端、测量与 Demo 说明，不写验收流水。
- 沿用 styled-components/native、现有主题与 SVG、ECharts 原生 SVG 渲染；不新增 WebView、后端接口、数据库、查询缓存或通用状态框架。
- 不修改原生采集算法、覆盖／贴胸准入、正式时钟、文件协议、相机所有权、被动触发周期或真实认证。固定结果不写首页、历史、最近测量时间或云端；被动服务可产生其既有本地产物，但本次不将其接入产品健康展示。
- 不开放个人资料编辑、健康资料表单、帮助反馈提交；不加入校准、医学阈值推断、风险分数、长期后台可靠性或多设备专项验收。
