# Spec Delta

## MODIFIED Requirements

### Requirement: 认证操作同步反馈过程与结果
用户提交通过本地校验的登录、注册，或确认退出登录后，应用 MUST 同时在操作按钮和居中 Toast 表达处理中状态，按钮 MUST 禁止重复提交；过程 Toast MUST 不可点外部关闭且不自动过期，持续到操作实际完成，不以固定延时冒充完成。成功或失败 MUST 用实际结果替换过程 Toast；成功默认1.5秒、错误默认3.5秒，结果允许点外部蒙版关闭，点击卡片不关闭，认证过程与结果均不通过 Android 系统返回关闭。按钮 MUST 在完成后退出 Loading，失败时允许重试；导航 MUST 不清除结果 Toast。登录成功 MUST 返回发起登录的原页面，保留原Tab、筛选和准备上下文，经过注册返回登录仍保留来源，不自动启动检测。按钮 Loading MUST 保留 Demo 的完整主题渐变、白色前景与旋转加载图标，不采用普通禁用态的纯灰外观；普通禁用态仍使用灰色外观。

#### Scenario: 登录过程与成功
- **WHEN** 用户提交通过本地校验的登录表单
- **THEN** 登录按钮显示加载指示和“登录中…”，Toast 显示“正在登录…”；完成凭据保存和账号确认后替换为登录成功，返回发起登录的原页面，保留原Tab、历史筛选或准备上下文，不统一跳转到“我的”，不自动开始检测

#### Scenario: 注册过程与成功
- **WHEN** 用户提交通过本地校验的注册表单
- **THEN** 注册按钮显示加载指示和“注册中…”，Toast 显示“正在注册…”；注册成功后 Toast 提示“注册成功，请登录”，返回登录页并预填用户名，不建立会话，后续登录成功仍返回注册前发起登录的原页面

#### Scenario: Loading 按钮保留 Demo 主题外观
- **WHEN** 登录、注册或退出按钮处于 Loading
- **THEN** 按钮显示完整主题渐变、白色文字与旋转加载图标，同时保持不可重复触发；普通禁用按钮仍使用灰色外观

#### Scenario: 失败后重试
- **WHEN** 登录或注册请求失败
- **THEN** 过程 Toast 替换为对应安全错误提示，按钮结束 Loading 并允许重新提交；再次提交拥有新的过程反馈，旧操作清理不会关闭新 Toast，失败不改变来源或执行成功导航

#### Scenario: 连续触发提交
- **WHEN** 某次认证提交尚未完成，用户连续点击按钮或通过键盘再次提交
- **THEN** 不创建第二个同类在途操作，不重置当前过程 Toast，不产生重复成功导航

#### Scenario: 本地校验未通过
- **WHEN** 用户未填写必填字段、用户名超长或注册确认密码不一致
- **THEN** 对应字段持续显示本地校验说明，按钮和 Toast 不进入请求 Loading

#### Scenario: 认证结果外部关闭与返回分开
- **WHEN** 认证过程或结果 Toast 正在显示，用户点击外部蒙版、卡片或按 Android 系统返回
- **THEN** 外部点击只关闭非加载结果，点击卡片和系统返回均不关闭；加载等实际操作结束，关闭反馈不取消认证或改变导航结果

#### Scenario: 离开登录后的迟到成功
- **WHEN** 用户已经离开登录页，本次登录请求才成功返回
- **THEN** 不再次执行返回或重置其他页面，不因迟到响应自动开始检测，旧操作只更新自己持有的反馈

### Requirement: 退出反馈独立于认证状态提前切换
退出登录 MUST 保留事前确认，取消或关闭确认弹窗不得开始退出。确认后按钮 MUST 显示加载指示和“退出中…”，Toast MUST 显示“正在退出登录…”。即使本地认证状态已变为未登录，页面 MUST 在退出操作完成前保留退出按钮过程态，不展示可立即发起新登录的账号入口。完成时 MUST 根据本地凭据删除与远端撤销的真实结果展示成功或安全错误 Toast，恢复与实际会话状态匹配的页面；不得为保持 Loading 延迟本地会话隔离。

#### Scenario: 取消退出
- **WHEN** 用户取消退出确认或通过系统返回关闭确认弹窗
- **THEN** 不执行退出，不展示退出 Loading 或退出过程 Toast

#### Scenario: 本地已退出但远端仍在处理
- **WHEN** 本地会话已清理而远端撤销仍未完成
- **THEN** 账号展示遵循真实未登录状态，但操作区域仍为禁用的“退出中…”按钮；账号登录入口也暂不可触发，居中的退出 Loading Toast 继续显示

#### Scenario: 退出操作完成
- **WHEN** 本地凭据删除及远端撤销均完成且成功
- **THEN** 用退出成功 Toast 替换过程 Toast，结束按钮 Loading，显示未登录页面及可用登录入口

#### Scenario: 部分退出失败
- **WHEN** 安全凭据删除失败，或本地退出完成但远端撤销未确认
- **THEN** 用对应真实错误 Toast 替换过程 Toast，结束按钮 Loading，不宣称全部撤销成功；页面按真实认证状态保留必要说明和恢复入口
