## 3. 文件传输与进度

- [x] 3.1 实现单文件引用上传，规范化 URI、发送 `logicalName/file` 并由运行时生成 boundary；通过实际 RN 合成文件上传取得真实 `fileId`、逻辑名和大小，确认未使用整文件字符串或 Base64 上传路径。
- [x] 3.2 实现输入和输出下载，返回 Blob 与可取得的媒体类型/附件头，并对输出逻辑名按路径段编码；通过 RN 原输入下载和内容校验确认二进制可读取，另验证错误 JSON 能恢复为结构化错误而非正常文件，不调用文件保存能力。
- [x] 3.3 接入可选 `onProgress` 和取消信号，提供已传输字节与可选总量并终止迟到通知；添加回归覆盖未知总量、传输 100% 后失败、取消后不再通知，且用实际 RN 传输观察字节事件，不伪造中间进度或固定频率。
- [x] 3.4 在 `docs/development` 记录文件引用、下载返回值和进度消费方式；记录实际验证的平台、文件规模、总量可得性及取消结果，明确进度不含后端处理和上层落盘，未验证平台不得宣称通过。

- [x] 4.1 接入与当前 Expo SDK 兼容的 `expo-secure-store` 及 CNG 配置，实现按服务地址/渠道保存单条令牌对记录的适配器；以原生读写/删除 smoke 验证作用域隔离，并添加存储失败回归确认无普通存储回退和令牌混搭。
- [x] 4.2 实现应用端 auth 命令、只读 Nano Stores 状态及启动恢复，覆盖无凭据、账号确认、暂不可确认和最终认证失败；通过确定性状态转换回归确认网络/5xx 不清空为未登录，公开状态不含令牌、密码或整份资料。
- [x] 4.3 实现应用端注册及登录接入，直接消费敏感认证响应、保存凭据后确认账号；验证注册不自动登录，凭据保存与账号确认失败分别表达，完成调用后通用 Query/Mutation 缓存不保留密码或令牌对。
- [x] 4.4 实现统一受保护调用入口、共享刷新、令牌修订号和至多一次认证重发；添加并发失败只刷一次、迟到 401、403 不刷新、等待者取消、刷新超时及轮换后存储失败回归，确认没有网络写入重试或旧 Refresh 回滚。
- [x] 4.5 实现退出、凭据串行写入/删除及会话代次检查；通过回归验证 `data=null` 的登出成功、网络失败仍可本地退出、退出与刷新/新登录竞争、删除失败显式反馈，以及旧结果不能恢复新会话。
- [x] 4.6 更新架构文档中的 auth 与 Store 归属，并在 `docs/development` 说明恢复/不可确认/退出语义、安全存储和敏感数据限制；检查说明与已验证行为一致，不声称退出立即撤销旧 Access 或卸载必然清除凭据。
