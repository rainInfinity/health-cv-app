## 3. 像素读取与处理器组合

- [x] 3.1 实现 `PixelReader` 和只读 `PixelFrameView`，表达 Y/U/V 平面、字节偏移、行／像素步长、裁剪、方向及时间信息；用带行填充、共享色度存储和非零裁剪偏移的确定性输入验证实际像素读取，不假定紧密排列。
- [x] 3.2 实现 `FramePipeline` 的借用作用域和统一释放边界，使处理器可访问完整像素且异常时也释放帧；以处理失败和作用域结束场景验证不会重复释放或在释放后保留异步像素消费。
- [x] 3.3 实现一次遍历的 `PixelStatisticsExtractor` 和独立 `PpgRecordProcessor`，沿用八列字段、Android 时间含义与每帧一个全帧块；用有效区域和不同 stride 的小型输入验证均值、通道计数及帧身份，不为字段转发或默认参数单独建测试。
- [x] 3.4 实现独立 `CoverageHintProcessor`，复用共享统计、沿用旧亮度／颜色比例判断，并表示未评估和合并最新提示；测试阈值两侧、比例和非正、未取得输入等行为，确认不依赖文件批次，也不输出面积百分比或固定质量通过。
- [x] 3.5 在 `docs/acquisition/android-ppg.md` 补充像素借用、完整像素处理扩展方式、CSV 八列时间／单位和经验提示算法；核对文档不把均值限定为所有算法输入，也不把旧 Android 的 `timestampSystem` 解释为 Unix 日期。
