# Design

## Context

动机和目标范围见 `proposal.md`。本次有结果流程、导航和资源生命周期的交叉改动，需要先明确展示状态与原生状态的关系。

- Demo 的 `fingertip-results.js` 定义固定四项结果、两处共用看板、独立处理后波形及解读；`contact-measurement.js` 定义三秒等待、原底部面板上移展开和详情往返。血压与面部没有本次对应结果设计。
- 原生 `FingertipMeasurementScreen` 已有真实预览、状态、倒计时和说明／真实波形分页。`getFingertipPresentation` 只在原生完成且 `resourcesReleased` 时投影为正常完成，必须保留这道屏障。
- `useContactMeasurementSession` 当前在页面失焦时调用 `disposeRound`，指尖的实现会清空 `fingertipWaveform`。直接压入结果详情将导致返回后失去真实波形，不能只增加一个路由按钮。
- `HealthIndicatorArtwork` 已有心率、呼吸、血氧仪表及风险 SVG，但尺寸和装饰面向首页；结果看板需要 56 dp 指标图标、解读需要 48 dp 图标，解读区血氧使用 Demo 的独立旧项目路径而不是半圆仪表。
- 现有 `PulseWaveHistory` 默认从最新窗口开始并按可见真实幅值缩放；Demo 处理后波形从 0–6 秒开始、固定纵轴，不能不加区分地套用实时视图的默认行为。

## Goals / Non-Goals

**Goals:**

- 保留真实采集契约，在其之后增加独立的局部结果展示阶段，不把三秒展示等待写入原生采集状态。
- 保留 Demo 的信息层级、底部面板展开关系、完整内容及核心操作，以原生实现适配布局、渲染、手势和生命周期。
- 让简要结果与详情消费同一套只读展示数据和指标组件；检测页真实波形与详情固定处理后波形互不替换。
- 在常规 Android 实际页面上，通过核心交互检查和对应截图确认迁移效果。

**Non-Goals:**

- 不接入结果 API、上传、健康推理、医学分级、历史存储或跨轮恢复，不预建这些能力的接口和仓库。
- 不迁移面部或血压结果，不修改 Demo，不迁入手机外的模拟操作，不增加产品深链或永久开发预览入口。
- 不调整覆盖门控、正式计时、语音录音／调度或采集算法，不重构整个测量业务为新包。

## Decisions

### 1. 采集事实与结果展示分层

原生阶段仍是权威。指尖本轮首次达到 `completed` 且 `resourcesReleased`、无当前错误或退出请求时，建立绑定 `captureId` 的局部结果阶段：`waiting → available`；`available` 的弹层展开／收起另用局部可见性管理。不要反写原生快照，也不要用倒计时归零或结束语播完触发等待。

等待累计前台且本页可见的 3000 ms，显示“等待检测结果／正在处理，请稍候”，面板顶部的同名入口禁用并以加载圈替代箭头。镜头提示“检测完成，可以移开手指”，原生计时保持 `00:00`，覆盖末值和真实曲线冻结。后台暂停剩余展示等待，回前台继续，不重新采集；离开本流程、重测或卸载取消旧计时和回调。完成后转换为“检测完成／本次检测已结束”，入口变为“查看本次结果”，每轮仅自动展开一次。

等待期间复用全局 loading Toast“等待检测结果，请稍候…”。Toast 只随本页前台可见的等待展示，后台或失焦关闭，返回前台且仍在等待时恢复；结果可用、重测、真正退出和卸载均关闭。清理携带本提示 ID，不能关闭已替换成其他内容的新反馈，不以 Toast 计时推进结果。

选择页面局部展示状态而不是更改原生 `phase` 或引入查询状态，原因是这里没有真实处理请求，三秒也不属于正式采集。重复快照不能重置等待，旧轮到期不能打开新轮弹层。保持既有语音规则：正常到点已启动的结束语可继续，后台、失焦或重测立即停止，不因 UI 等待新增声音。

### 2. 固定样例统一维护，不推导真实结果

在指尖结果功能范围内维护一个带中文字段说明的只读样例模块，不运行时导入 Demo 文件，也不抽象尚不存在的云端服务。其内容与 Demo 保持一致：

| 展示项 | 固定内容 | 算法信号质量分 |
| --- | --- | --- |
| 心率 | 72 次/分；参考 60–80 次/分 | 92 |
| 呼吸率 | 16 次/分；参考 12–20 次/分 | 86 |
| 血氧饱和度 | 98%；参考 95–100% | 96 |
| 糖尿病风险 | 较低风险；仅供参考 | 76 |

检测时间固定为 `2026年10月31日 08:30`；评估、介绍、建议及风险说明沿用 Demo 原文，不按参考区间计算健康状态。结果日期不假冒真实采集完成时间，风险质量分不表示患病概率。对应界面文案接入既有 i18n 资源并维持两份 locale 的键一致性，不新增产品语言能力。

固定处理后波形独立生成一次，完整覆盖三十秒；不读取、加工或替换本轮真实采集波形。业务界面不新增“模拟／演示”说明，开发文档明确样例边界；保留 Demo 已确认的健康参考声明。

### 3. 结果组件按功能边界组合，复用图形而非复制首页整卡

在 `pages/measurement` 下增加指尖结果相关同名组件目录和独立详情页，检测页与详情页共用结果看板、质量角标及文案资源。弹层不显示质量说明，仅在指标卡下方、操作按钮上方居中显示短声明“检测结果仅供健康管理参考，不能替代医学诊断。”；详情保留原有完整声明的位置和质量评分说明，不把详情长文复用于弹层。看板通过结果场景变体区分弹层的纯白边框卡与详情页的白底轻阴影卡，不复制两套四项指标结构。

复用 `shared/graphics` 的同源 SVG 路径，必要时为图形提供明确尺寸和结果所需静态外观；默认首页外观保持不变。解读区血氧补充 Demo 已有 SVG 路径，使用主题玫红。质量角标用 SVG 表达对称圆角倒梯形及左侧渐隐细边，保留 Demo 的路径比例、靠右定位、16 dp 高度和三档主题色；不把质量色用于读数或医学等级。

所有色彩从现有 theme 读取，CSS 变量替换为主题属性；SVG 透明度使用显式 `stopOpacity`、合法停靠点及实例独立 ID。不引入图片化看板、第二套色表或新图标依赖。

### 4. 底部结果是页面内受控面板，不复用居中通用弹窗

使用检测页内绝对定位的底部结果面板和遮罩，保留原面板上移承接的视觉关系。通过布局测量和原生驱动 `translateY` 实现 Demo 的约 420 ms 展开，不把动画进度放入 React 状态，不通过动画完成推进结果有效性；沿用项目现有减少动态效果约定。

面板内容自然撑高，超过安全内容高度时内部滚动，依次保留成功图形、移开手指提示、时间、四卡、短声明和两项操作，不附加质量说明。顶部居中的收起箭头在滚动容器之外，不被裁切、不占正文高度；收起后的入口也嵌在原检测面板顶部，不推移状态、计时和分页。遮罩覆盖检测交互区域，展开时背景不可操作，Android 返回键先消费为收起，不能同时退出检测页。所有操作满足原生至少 48 dp 触控目标。

不使用全局 `FeedbackHost` 的居中弹窗，避免改变贴底展开语义及跨路由残留；不增加可拖拽关闭手势，Demo 仅要求箭头、遮罩和返回关闭。

### 5. 同轮详情往返保留内存，真正退出才释放

根栈增加 `FingertipResults`，使用原生导航转场，无产品底栏、公开深链或另一套导航容器。详情只从已可用的本轮结果进入，导航参数仅携带小型轮次身份，不传完整采样、文件、播放器或函数；固定展示数据由同一结果模块读取。

检测页保持挂载及局部完成展示。调整共用会话现有失焦清理边界：仅对明确进入本轮详情、且该轮已正常完成并释放资源的指尖页面保留历史和结果展示；仍立即停止语音、暂停不可见绘图并处理订阅，不保留相机。普通失焦、深链交接和真正退出仍走既有资源关闭与清理，血压默认行为不变。返回检测页不重新准备、不重播三秒等待、不重开相机；恢复原分页、波形回看位置并重新展示简要结果。

“重新检测”收起结果，取消旧展示计时及动画，沿用现有先关闭旧轮再准备的显式重试能力，清空旧覆盖、真实波形、样例结果资格，返回第一页并恢复 `00:30`。新轮仍由真实覆盖自动开始。无需为两个页面引入全局 Store 或持久化结果仓库。

### 6. 处理后波形复用绘图底座，单独持有报告视窗

结果波形使用既有 ECharts 原生 SVG 绘图层及真实尺寸处理，在结果组件内持有固定六秒窗口和有限样例点。初始从 0–6 秒显示，横向拖动仅平移至 24–30 秒，禁止缩放，不自动连续滚动，也不增加实时视图的“回到最新”悬浮按钮或拖动条。纵向页面滚动仍可使用，窗口范围文字跟随实际手势。

复用现有品牌 1.5 dp 线条、圆角和薄荷绿模糊内边缘，统一绘图层仍负责既有幅值显示方向，调用方不得重复翻转；根据独立样例幅度使用固定纵轴留白，不改变实时波形按窗口自适应的规则。图表随布局调整，离开详情释放实例。选择复用底层而不是原样套用 `PulseWaveHistory`，以免其最新窗口、自动缩放及标题位置改变报告语义；不为单一结果场景扩张实时组件的默认契约。

处理后样例在生成源使用负向原始幅值，统一绘图层按 `displayY = -rawY` 显示后恢复 Demo 的正向脉搏形态；固定显示纵轴为 `[-0.135, 1.212]`。此处是模拟原始输入方向，不在调用适配层再次翻转，也不修改真实采集数据。

### 7. 截图用于实际界面定向对照

实现阶段在一台常规竖屏 Android 模拟器或设备、默认字号和正常显示设置下实际打开相关原生页面，再与 Demo 对照：

- 三秒等待：状态、加载入口、`00:00` 与原面板位置。
- 简要结果：展开层级、顶部收起箭头、四卡、角标、图标比例、声明及滚动到两项操作。
- 详细结果：顶部总览和时间、四卡、处理后波形，以及滚动后的指标解读与完整风险说明。
- 返回与重测：详情返回仍是同一轮；收起能回看真实波形；重测清空并恢复等待覆盖。

截图裁去 Demo 外框、标签、模拟系统栏和原生系统栏，按逻辑内容视口统一比例；长页只补充必要的对应滚动位置，不生成设备／状态矩阵。对比构图、色彩、字体层级、间距、圆角、SVG、卡片及操作可达性，不以相机画面或人体信号逐像素相同为目标。截图可在临时工具产物中并排查看，验收记录和截图基线不写入项目文档。

截图不能证明三秒门槛、旧轮隔离或资源释放，另以实际操作和已有相关测试核对。若模拟器不能完成真实覆盖准入，允许临时、隔离的 UI 验证装配展示相同组件，但必须撤除并报告它不能替代真实完成触发链；不能在正式页面增加模拟成功按钮或伪造采集事实。

## Risks / Trade-offs

- [固定样例不是本轮计算结果] → 本次明确是 UI 阶段，固定数据与采集状态分离，不进入健康记录，保留参考声明并在开发文档说明，不声称算法已接入。
- [详情压栈触发失焦，历史被释放或返回重开设备] → 只对已完成同轮详情交接保留展示内存，资源关闭、停止语音和可见性控制仍独立执行；定向验证详情往返。
- [结果组件适配影响首页 SVG 或血压共用会话] → 新场景能力显式启用，保留原默认尺寸、外观与清理路径，不扩大改造范围。
- [原生字体、阴影和安全区与 Web 不完全一致] → 用等价内容视口截图发现可见偏差，保持层级与交互，不设置逐像素一致门槛。

## Migration Plan

先建立功能内样例及共用结果组件，再接入三秒展示和根栈详情，最后调整同轮内存保留与重测边界。完成原生核心操作和截图对比后，同步 `docs/development/frontend-development.md`、`docs/development/measurement.md` 中与本次结果相关的说明；不顺带修订无关历史内容。本次无后端、持久化或数据迁移；需要撤回时移除结果入口和路由并恢复原完成展示，不触及原生已定稿文件。
