# Spec Delta

## MODIFIED Requirements

### Requirement: 指尖提示居中显示于放大的圆形预览内
指尖 MUST 保留圆形构图、覆盖环、底缘固定宽 88 dp 的百分比标签，以真实原生预览替换模拟红层。提示 MUST 采用镜头内居中的半透明毛玻璃浮层且不拦截操作，约 72% 白色叠层、浅色边框、14 dp 圆角、14／22 dp 正文色文字与 600 字重、水平 16 dp／垂直 12 dp 内边距，总宽度不超过镜头的 80%，随内容收缩、最多两行省略，换行后各行仍水平居中。支持相机背景模糊的设备 MUST 保留真实背景模糊，旧版保留半透明外观；文字保持清晰，不随背景一起模糊。原圆形下方旧说明和占位图标 MUST 不恢复，不推移或压缩既有底部状态及波形面板；状态与倒计时之间 MUST NOT 绘制分隔线。覆盖值和准备／采集提示 MUST 来自真实算法；未知显示占位，不以动画宣称完整覆盖。结果等待和弹层作为采集完成后的独立展示，不改变采集中的布局和事实。

#### Scenario: 等待与正式检测提示
- **WHEN** 指尖等待真实覆盖、当前为部分覆盖，或原生已进入正式采集
- **THEN** 等待覆盖与部分覆盖的中央提示 MUST 统一为“手指未完全覆盖镜头，请调整位置”，正式采集显示“正在检测，请勿移动手指”；仅合并文案，不合并底层覆盖分类、百分比、页面状态或准入规则，不改变语音提示；状态及辅助说明保持现有位置，未评估不宣称完整覆盖，检测中不得早于原生正式开始

#### Scenario: 覆盖分类快速抖动
- **WHEN** 普通覆盖分类在短时间内来回变化
- **THEN** 对应操作提示稳定 300 ms 后才切换，覆盖数字与环最多每 250 ms 消费最新真实值；不重建相机或以动画触发正式采集，原生开始、结束、错误及取消不受普通提示防抖延迟

#### Scenario: 完成后保留产品提示
- **WHEN** 原生达到目标并完整收尾
- **THEN** 镜头显示“检测完成，可以移开手指”，保留 00:00、结束时覆盖快照和本轮真实波形，并进入独立三秒结果等待；冻结覆盖快照不代表相机仍在识别，不添加演示、模拟数据或文件核查文案，随后呈现的固定样例不代表已计算真实健康结果

#### Scenario: 外部模拟控制不迁入原生
- **WHEN** 指尖使用真实采集及独立样例结果展示
- **THEN** 不新增手机外模拟按钮、假摄像头切换或模拟手指识别；检测页的覆盖、准备／采集提示及采集曲线只能来自本轮真实输入，结果页的固定样例不得回填这些位置

#### Scenario: 中央提示换行与背景模糊
- **WHEN** 指尖操作提示换为两行，且相机预览正在显示
- **THEN** 各行文字水平居中、清晰且不拦截操作，浮层保持宽度限制；支持时呈现真实预览背景模糊，旧版保留半透明外观，不改变下方面板布局

### Requirement: 页面还原按等价视口与状态验收
受影响页面 MUST 在常规 Android 设备、默认字号及正常显示设置下检查既有排版、配色、圆角、留白、照片裁剪及层级；对照区域对齐逻辑内容视口，剔除 Demo 外框／标签与系统栏。应用 MUST 固定竖屏，必要操作可达，不新增非预期滚动或横向溢出；不追加横屏、多尺寸、大字号或专项无障碍验收。真实预览与波形不要求逐像素相同，既有边框、布局和适配保持不变，不将指尖改成工程控制台。

面部取景四角 MUST 保持画面内侧 24×2 dp 实色线段，不因裁剪缩为半宽；脉搏波画布 MUST 填满标题与原主操作区域间剩余空间，不固定为最小高度。指尖分页 MUST 保持连续横向滑动、平滑点击及自动切页，不因普通布局变化无动画复位；标识保持 200 ms 伸缩过渡。指尖结果扩展 MUST 保留准备和采集中的既有页面布局，新增结果等待入口、完成后展开面板及独立详情，不借此重绘无关采集区域。

#### Scenario: 面部与指尖主要状态对比
- **WHEN** 检查本次指尖真实预览、覆盖、正式采集、完成及必要中断状态
- **THEN** 原生页面保持现有构图、提示、状态面板、分页与波形交互，面部不因共享组件迁移回退；不以网页截图或编译替代实际运行，不保存截图矩阵或验收流水

#### Scenario: 常规竖屏操作
- **WHEN** 用户在常规设备、默认字号下使用准备及检测页
- **THEN** 图形保持比例、正文不裁切，必要返回、分页及失败反馈操作可达，安全区不重复叠加

#### Scenario: 原生结果迁移截图对比
- **WHEN** 验证原生三秒等待、结果弹层、详细结果及详情返回后的效果
- **THEN** 实际打开 Android 对应界面，并与 Demo 相同状态、等价逻辑内容视口的截图对照；检查布局、配色、文字层级、圆角、图标、角标和操作位置，长内容补充必要的对应滚动区域，不要求相机或波形逐像素一致，不把截图对比代替流程操作验证，验收记录不写入项目文档

### Requirement: 进行中状态使用旋转 spin
面部进行中及指尖真实准备、覆盖观测、正式采集和收尾时 MUST 使用既有 900 ms 匀速旋转 spin，不以覆盖满环冒充加载动画。指尖正常收尾后的独立三秒结果等待 MUST 继续呈现旋转状态圈和等待入口加载圈；结果可用、其他完成、中断和失败静止。减少动态效果保持已有静止行为，不阻止原生计时。动效结束 MUST NOT 推进覆盖就绪、正式开始、采集完成或结果可用。

#### Scenario: 正常动效下正在检测
- **WHEN** 正常动态效果下本轮仍在准备、覆盖观测、正式采集或收尾
- **THEN** 指示器旋转并与真实状态对应，不通过动画制造百分比或阶段

#### Scenario: 独立等待结束
- **WHEN** 指尖进入三秒结果等待并随后结果可用
- **THEN** 等待时显示旋转加载圈，结果可用后停止等待加载并恢复可用结果入口；不以一圈动画结束替代三秒等待

### Requirement: 指尖使用真实本地采集且不发布健康结果
指尖页 MUST 承接用户明确的检测入口执行系统授权、真实后摄及可选补光准备，沿用现有页面而不增加打开／开始的两步控制面板。补光明确支持时请求开启，不支持或能力未知时 MUST 以关闭补光的配置继续，不单独作为检测失败条件；已请求开启但实际应用失败仍按真实错误处理。游客、离线及无云端配置均可使用；必须等待真实覆盖稳定才正式采集。采集链路 MUST NOT 生成模拟输入、调用云端或健康指标推理，页面 MUST NOT 更新首页、最近测量时间或健康记录。正常完成后允许显示独立固定样例结果 UI，但 MUST NOT 将其作为真实采集计算的健康结果发布。后摄或权限不可用时真实反馈，不替换镜头或接管占用者。

#### Scenario: 未登录无网络的本地检测
- **WHEN** 未登录、无网络的用户明确进入指尖页并授予相机权限
- **THEN** 可以准备真实后摄、判断覆盖并完成本地采集与脉搏展示，正常完成后可以进入固定样例结果 UI，不依赖服务器或生成真实健康指标

#### Scenario: 补光不可用仍继续真实检测
- **WHEN** 已授权且真实后摄可用，但补光能力不支持或未知
- **THEN** 不请求开启补光，继续预览与真实覆盖观测，满足原覆盖稳定条件后才自动开始；不因无补光报错，不伪造覆盖或脉搏

#### Scenario: 必需能力不可用
- **WHEN** 用户拒绝权限，或后摄不可用或被其他所有者占用
- **THEN** 使用统一中文反馈及必要重试／返回，不显示假预览、假覆盖或正在正式采集，不停止占用者，不进入样例结果等待或弹层

## ADDED Requirements

### Requirement: 指尖正常收尾后模拟三秒结果等待
指尖 MUST 仅在本轮正式目标正常完成、文件和相机资源收尾成功且无当前失败或离开请求后，进入独立的三秒结果展示等待；中断和失败 MUST NOT 进入。等待 MUST 不改变原生采集状态、覆盖准入、正式计时及既有语音规则。等待按本轮前台可见时间累计，满三秒后结果可用并自动展开一次；重复完成通知不得重置或重复展开。

#### Scenario: 正常完成开始等待
- **WHEN** 本轮正常采满目标并完成文件及相机收尾
- **THEN** 显示“等待检测结果／正在处理，请稍候”，同时显示 loading Toast“等待检测结果，请稍候…”，底部面板顶部显示禁用的“等待检测结果”加载入口，保留真实结束覆盖、00:00 和本轮曲线；三秒前不能查看详情，Toast 不另建推进结果的时钟

#### Scenario: 只有截止或收尾失败
- **WHEN** 倒计时归零或结束语已播放，但资源仍在收尾或随后失败
- **THEN** 不开始三秒等待、不显示样例结果，继续现有收尾或错误反馈；播放完成不推进视觉成功

#### Scenario: 等待期间后台及离开
- **WHEN** 用户在等待中进入后台、返回前台，或真正离开本轮流程
- **THEN** 后台暂停剩余展示等待并关闭等待 Toast，前台继续且仍在等待时恢复 Toast，不重开采集；真正离开、重测或卸载取消本轮等待并关闭本轮 Toast，迟到回调不得在其他页面弹出结果或误关闭后来替换的新提示

#### Scenario: 等待完成只自动展开一次
- **WHEN** 同轮累计可见等待达到三秒，随后继续收到原生完成通知或用户收起结果
- **THEN** 关闭等待 Toast，状态变为“检测完成／本次检测已结束”，入口变为可用的“查看本次结果”，首次自动展开简要结果；收起后不因重复通知再次自动打开

### Requirement: 指尖结果弹层沿底部面板展开并可收起
简要结果 MUST 沿检测页底部面板以约 420 ms 位移动画向上展开，使用主题青绿至白色柔和背景和既有圆角，背景遮罩隔离检测页交互。面板 MUST 按内容自然撑高，仅超出安全可用高度时内部滚动。收起箭头 MUST 位于面板顶部居中边缘且独立于滚动正文；收起入口不推移检测页状态、计时和分页。结果只在当前轮有效。

#### Scenario: 查看完整简要结果
- **WHEN** 简要结果展开
- **THEN** 依次展示 40 dp 绿色实心成功图形与“检测完成”、移开手指提示、完整检测时间、四项指标看板、一次居中的健康声明，以及可滚动到达的“查看详细结果”和白底描边“重新检测”按钮；弹层不附加质量说明，保留各指标质量角标

#### Scenario: 收起并重新打开
- **WHEN** 用户点击顶部收起箭头、遮罩或按 Android 返回键
- **THEN** 仅收起结果，不同时离开检测页；本轮真实波形仍可回看，“查看本次结果”恢复可操作，点击再次展示同轮结果

#### Scenario: 结果展开期间操作背景
- **WHEN** 用户在结果展开期间尝试点击底层预览、返回或分页区域
- **THEN** 背景不响应，结果内操作仍可达，面板顶部箭头不被正文滚动裁切；操作触控目标至少 48 dp

### Requirement: 指尖结果看板复用四项固定展示内容
弹层和详情 MUST 展示同源两行两列看板：心率、呼吸率、血氧饱和度、糖尿病风险，读数保持中性色，不从参考区间推断健康等级。图形 MUST 复用对应 SVG 轮廓、比例和主题色，血氧看板使用完整半圆仪表，风险值按等级／风险两行展示。卡片 MUST 保持 16 dp 内边距；弹层使用纯白底淡灰边框，详情使用白底轻阴影，均为 22 dp 圆角。

#### Scenario: 两处看板展示一致
- **WHEN** 用户查看简要结果或详细结果
- **THEN** 均显示心率 72 次/分、呼吸率 16 次/分、血氧 98% 和较低风险；前三项底部参考区间分别为 60–80 次/分、12–20 次/分、95–100%，风险卡显示“仅供参考”，不加参考区分隔线；心率、呼吸和风险图标均为 56 dp

### Requirement: 各指标独立展示算法信号质量角标
两处四项指标卡 MUST 在顶部靠右显示各自信号质量角标，使用对称、圆角转角的低矮倒梯形，主体高 16 dp、上底 44 dp、下底 24 dp，左侧保留渐隐细边，右侧不额外延长。角标 MUST 不占内容空间或改变读数排布，白色分数水平居中。90–100 分使用主题薄荷绿、80–89 分使用黄色、70–79 分使用淡粉色，90 和 80 归入较高档；本次不定义低于 70 分的业务分支。

#### Scenario: 四算法质量分别显示
- **WHEN** 结果看板展示固定样例
- **THEN** 心率、呼吸、血氧和风险算法分别显示 92、86、96、76 分及对应色阶，并提供完整信号质量文本标签；风险算法质量不表示患病概率或风险分数

#### Scenario: 质量含义说明
- **WHEN** 用户查看弹层或详细结果的指标看板
- **THEN** 弹层仅保留指标质量角标，不显示看板下方的质量说明；详情看板下方仍显示一次“指标右上角信号质量评分，满分100，分数越高，代表本次检测结果相对较准确。”，不增加统一圆形评分区或质量拒绝业务

### Requirement: 指尖详情按总览波形和指标解读组织
详细结果 MUST 不包含摄像预览、倒计时或产品底栏，按结果总览、四项看板、处理后脉搏波和指标解读组织。总览标题右侧 MUST 显示完整时间，不增加报告大标题或检测时长。各指标解读 MUST 使用独立白底、22 dp 圆角、轻阴影、16 dp 内边距的卡片，间距 12 dp；上排为名称及 48 dp 图标与读数、评估、介绍，下方建议或风险说明占整行，不截断。

#### Scenario: 浏览总览与解读
- **WHEN** 用户进入详情并向下滚动
- **THEN** 可查看四项总览、质量说明、处理后波形，以及与 Demo 一致的三项生命体征解读和糖尿病风险说明；解读区血氧使用原有血氧 SVG 图形和主题玫红而非半圆仪表，风险读数保持单行

#### Scenario: 健康参考声明只出现一次
- **WHEN** 用户查看简要结果或详细结果
- **THEN** 弹层在指标卡下方、操作按钮上方居中展示一次“检测结果仅供健康管理参考，不能替代医学诊断。”；详情仍在总览标题与时间行下方、看板之前左对齐展示一次“检测结果仅供健康管理参考，不能替代医学诊断。如有持续不适，请及时就医。”，不在报告末尾重复

#### Scenario: 风险含义不扩张
- **WHEN** 用户阅读糖尿病风险解读
- **THEN** 保留 Demo 的风险参考、必要咨询与检查建议，明确该结果不等于血糖值、患病概率或确诊，不计算风险分数

### Requirement: 处理后波形独立展示三十秒固定样例
详情 MUST 独立显示三十秒处理后波形固定样例，不读取、加工或替换检测页的真实采集曲线。样例生成源 MUST 使用负向原始幅值，经统一绘图层 `displayY = -rawY` 后呈现正向脉搏，固定显示纵轴为 `[-0.135, 1.212]`；不在调用适配层重复翻转。窗口 MUST 初始为 0–6 秒、每屏固定六秒，只能横向平移至全轮范围，不能缩放，不自动连续滚动或提供拖动条。波形 MUST 保持品牌 1.5 dp 细线、圆角及浅绿模糊内边缘，不改写生成后的样例值或影响实时波形的缩放策略。

#### Scenario: 拖动查看全轮处理后波形
- **WHEN** 用户在详细结果的波形内横向拖动
- **THEN** 仅改变六秒视窗及范围文字，可从 0–6 秒查看至 24–30 秒；标题、“处理后”与“左右滑动查看”同行，范围和“共 30 秒”位于波形下方，不增加重复说明或实时回到最新按钮

### Requirement: 指尖本轮结果在详情往返保留且重测清空
指尖 MUST 在本轮检测页与详情往返时保留完成状态、结束覆盖、真实曲线及回看位置和可用样例结果，不重新计时、采集或重复等待；保留展示内存 MUST NOT 保持相机占用。重测 MUST 先安全关闭旧轮，再清空旧结果资格、覆盖、计时、真实曲线及分页，回到等待真实覆盖；真正离开本流程或卸载 MUST 释放本轮展示内存并取消迟到回调，不删除完成文件。

#### Scenario: 详情返回检测
- **WHEN** 用户通过页内返回或 Android 返回从详情回到本轮指尖检测
- **THEN** 恢复该轮完成状态并展示简要结果；收起后可继续查看原分页和真实波形回看位置，不重播三秒等待、不重新打开相机

#### Scenario: 明确重新检测
- **WHEN** 用户点击结果弹层的“重新检测”
- **THEN** 收起结果并清理旧轮，安全关闭后显示等待放置及第一页流程说明，倒计时复位 00:30，覆盖未知、波形为空；新轮仍须真实覆盖稳定才开始，旧轮回调不能显示结果或恢复旧数据
