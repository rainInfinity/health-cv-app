# 指尖检测语音提示

## Why

指尖检测已具备真实覆盖观测、原生三十秒窗口和页面提示，但尚无操作语音。用户已确认播报规则并提供七个本地 MP3，需要将这些资源接入现有指尖流程，使用户不必持续查看屏幕即可听取关键引导。

## What Changes

- 仅为指尖检测加入放置指导、正式开始提示、剩余二十秒与十秒提醒、覆盖纠正、十五秒放置帮助及最后三秒结束语音，使用 `apps/native/assets/audio/fingertip/` 内现有七个 MP3。
- 新增独立指尖语音调度，依据本轮原生快照和指导实际可见性触发；单路播放、关键提示抢占低优先级提示，按轮次及连续覆盖不足去重，不补播过时内容。
- 原生剩余时间跨过三秒时，从头连续播放现有“三、二、一，检测完成”合并音频，不裁剪、不要求数字逐秒对齐、不在结束语前暂停等待文件或资源收尾。“检测完成”仅表示正式检测阶段结束，不代表保存或资源释放成功；后续收尾失败仍由既有界面反馈处理。
- 中断、后台、离页及重测立即停止旧轮语音；语音不控制原生开始、计时、结束或页面成功状态。
- 使用 Expo SDK 57 对应的 `expo-audio` 播放本地资源，仅启用前台播放，不增加录音、后台播放或系统音量控制。
- 实施时同步检测语音文档，替换此前严格逐秒对齐、结束语等待资源收尾的旧规划；不顺带修订其他检测方式或文档中的无关旧内容。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `native-measurement-pages`：增加指尖本地语音的触发、抢占与去重、合并结束音频语义以及轮次和页面生命周期约束；保留现有检测准入、原生计时和视觉成功屏障。

## Impact

- 原生应用新增 `expo-audio` 依赖及仅播放所需配置，更新 `apps/native/package.json`、工作区锁文件和必要应用配置；安装新原生模块后需重新构建 Android 开发包。
- 主要接入 `FingertipMeasurement/useFingertipMeasurement.ts`、现有放置指导及 `ContactMeasurement/useContactMeasurementSession.ts` 的生命周期；血压复用路径不得因此获得指尖语音。
- 本地音频资源通过静态资源映射使用；不修改七个用户音频，不使用此前生成的试听 WAV，不依赖在线合成或网络。
- 不修改采集协议、原生相机或信号处理，不创建 `packages/measurement`，不改变页面布局、现行界面文案、声音提醒或跳过偏好。
- 不接入面部或血压语音，不增加光照、权限、错误或中断播报，也不新增上传和健康结果能力。
