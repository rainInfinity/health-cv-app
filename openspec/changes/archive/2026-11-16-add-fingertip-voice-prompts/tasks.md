## 2. 指尖语音调度

- [x] 2.1 实现按原生轮次、观测、正式开始及剩余时间阈值触发的语音控制器；用定向临时脚本走通观测、开始、二十秒、十秒及三秒节点，确认跨阈值和重复快照下每个节点只播放一次，不建立独立检测时钟，验证后移除临时脚本。
- [x] 2.2 实现连续覆盖不足去重、正式阶段允许轻微缺角、关键提示抢占、低优先级时长空档检查和帮助可见性消费；为这些易出现重复或过时播报的消费者行为增加少量确定性测试，验证持续不足不重播、恢复后可再播、关键提示不被纠正阻挡、帮助收起后不补播。
- [x] 2.3 实现合并结束音频的连续播放语义及取消边界；为正式窗口提前中断、窗口结束后仍在收尾或收尾失败，以及旧异步回调失效增加定向测试，确认提前中断会停止、后续收尾不暂停结束语、语音回调不修改页面成功状态。
- [x] 2.4 同步 `docs/development/measurement.md` 第 10 节的确认规则，删除严格逐秒对齐、迟到跳播及等待资源收尾后播结束语的旧约束；核对文档明确三秒时从头连续播放现有完整录音、完成语义仅指正式检测结束，保留其他检测方式及无关文档内容不变。
