# Proposal

## Why

现有原生指尖页已经具备覆盖环、三十秒倒计时、说明／脉搏波分页和本轮回看，但数据仍全部来自本地模拟。需要补齐后摄采集、覆盖判断及脉搏波展示算法，让现有 UI 由真实输入驱动，而不是另建只检查文件的工程测试页。

## What Changes

- **BREAKING**：将现有指尖页从纯展示切换为真实本地采集，保留页面布局、操作提示、覆盖环与百分比、覆盖就绪后自动开始、三十秒倒计时、分页和六秒波形回看；删除模拟红层、固定覆盖推进、模拟计时和模拟曲线。
- 复用 CameraX、PPG、文件输出和相机互斥，接入真实后摄；补光为可选辅助能力，明确支持时开启，不支持或未知时继续无补光检测，不单独阻断准备或放宽真实覆盖门控。用户从现有入口进入指尖页后完成授权和预览准备；不新增“打开预览／手动开始”的两步控制面板。
- 在原生补齐空间覆盖估计与时间稳定判定，区分未评估、未覆盖、部分覆盖及稳定就绪。覆盖环反映真实图像估计，不将现有经验提示布尔值转换为百分比；完整覆盖连续保持 3 秒且输入新鲜后才触发原生开始准备，必要锁定及 writer 就绪后才开启正式窗口，等待与准备不扣正式三十秒。
- 从同一轮真实 PPG 样本提取供展示的脉搏标量，补齐去直流、因果滤波、启动无效段和时间缺口处理，以有界批次交给现有图表；不跨桥发送像素、原始 PPG 行或相机元数据。
- 原生拥有正式三十秒计时、截止、覆盖丢失中断和完整关闭屏障；覆盖准备不计入正式时长。后台和离页结束本轮，返回前台不续采，重进清空本轮展示。
- 保留单块 `ppg.csv`、配对 `frame.csv` 及真实配置、时间和结束原因，不改变原始 CSV 协议，不在产品首屏增加文件路径或调参控件；本轮波形回看不扩展为跨轮文件回放。
- 本次不接血压、不创建血压路由、不改传感器或增加 PPG＋ACC 联合采集；既有血压入口继续反馈尚未接入。
- 不实现 `packages/measurement`、云端上传、健康指标推理、健康记录、语音或面部／被动 RPPG 算法变更。覆盖与波形可用不等于医学质量通过。
- 根据实际使用反馈，降低覆盖展示刷新频率并对普通提示防抖，分离完整覆盖准入和采集中维持门槛；短暂失效断线但不立即结束，持续丢失才收尾。
- 面部及指尖共享波形改按当前六秒可见窗口计算纵轴，保留原始幅值和历史回看；全帧 POS 仅用已有录制素材离线对照，本次不替换产品红通道算法。
- 将 design-demo 的“未检测到手指”指导弹窗原位迁入原生：真实预览进入本轮覆盖观测起 15 秒仍未进入 `capturing` 时每轮提示一次，包含部分／完整但未就绪及 `starting`；授权和打开预览不计时。保留两幅插画、文案及动效，仅“我已知晓”可主动关闭；不暂停覆盖、不切换相机，正式开始或失败、后台、离页、重试时收起并取消旧计时，不改变三秒完整覆盖准入和三十秒正式窗口。
- 同步已实现的最新 UI：镜头内提示采用半透明毛玻璃并保持多行居中；面部与指尖产品波形使用品牌主色、1.5 dp 线宽、12 dp 圆角及薄荷绿模糊内阴影，取消底部基线，不增加纵向渐变或面积填充；指尖状态与倒计时之间不绘制分隔线。保留既有布局、六秒视窗及左侧渐隐。

## Capabilities

### New Capabilities

无。扩展既有采集及产品页面能力。

### Modified Capabilities

- `native-acquisition`：增加真实覆盖估计、覆盖门控的有限指尖采集、原生窗口与中断、指尖有界脉搏展示例外及本轮完成事实；保留独立手动 PPG 行为。
- `native-measurement-pages`：将指尖模拟数据替换为真实预览、覆盖、计时和波形，保留现有布局、分页、回看及必要失败反馈。
- `native-product-pages`：保持分类和目标映射，指尖入口接入真实本地检测，不发布健康结果；血压行为不变。
- `native-app-shell`：将主动离页屏障覆盖真实指尖会话，保留原返回来源，不新增路由、Tab、导航容器或产品深链。

## Impact

- `restore-native-measurement-pages` 已完成并归档；以当前主规格及已交付组件为基线，不等待旧变更、不回写其归档文件。
- 影响 `packages/acquisition` 的 PPG 像素处理、会话控制、公开 TypeScript／Nitro 合同及核心回归；对“原始采集只提供低频信息”的旧约束显式增加有界指尖脉搏标量例外。
- 影响 `apps/native/src/pages/measurement/FingertipMeasurement`、`app/measurement` 及现有离页守卫接入。复用 `PulseWaveHistory`、`PulseWaveChart` 和主题；窗口纵轴调整同步两端缓存及调用，不移植面部人脸／POS 算法、不改 design-demo 文件、不增加 Dev 页面；不改 Demo 不限制将已确认的指导插画、文案与动效迁入原生。
- 实施时同步 `docs/acquisition/android-ppg.md`、前端开发约定及受影响架构说明，区分覆盖估计、展示波形和健康结果；不保存验收日志或截图流水。
- 真机用于验证未覆盖／部分覆盖／完整覆盖、手指移开及真实脉搏展示；模拟器用于其支持的设备接入、生命周期和文件路径，不代替人体输入验证，不要求医学准确性或设备矩阵。
- `add-local-measurement-orchestration` 仍引用旧提案名称、血压双源方案和手动开始合同。本次不修改该独立提案；它不能直接按旧依赖实施，需在采用本次新合同前单独对齐。
