# Spec Delta

## MODIFIED Requirements

### Requirement: 功能目录按检测部位与指标提供入口
功能页 MUST 保留“按检测部位”和“按指标”分类，默认前者。部位分类保留面部、指尖、指尖＋胸口三张照片卡片；指标分类保留指尖心率与呼吸率、面部心率、血压、血氧、糖尿病风险五项插画。两分类 MUST 共用方式、目标映射及设备级跳过偏好：未跳过进入准备，已跳过直达对应检测且不补声音提醒。游客不得强制登录；面部仍显式开始，指尖使用真实本地采集与展示算法，血压仍反馈尚未接入，不创建或上传云端任务。

#### Scenario: 游客点击测量入口
- **WHEN** 游客点击任一功能或主页测量入口
- **THEN** 不因身份强制登录；功能入口按方式及跳过偏好推进，主页既有入口不在本次改造范围。面部待开始页不启动设备，指尖承接明确入口完成授权及预览准备，覆盖稳定后才正式采集

#### Scenario: 功能最近测量信息
- **WHEN** 游客或已确认账号访问功能页
- **THEN** 游客所有测量时间为空，已确认账号仍仅显示既有固定数据对应时间及真实间隔；无记录和时钟早于记录分别如实表达，不将固定日期改成今天

#### Scenario: 按检测部位进入
- **WHEN** 用户尚未保存该方式跳过偏好，在默认分类点击面部、指尖或指尖＋胸口卡片
- **THEN** 分别进入对应准备页；面部目标仍为面部心率，指尖不预选指标，指尖＋胸口目标仍为血压估计；血压准备确认不新增采集页或设备行为

#### Scenario: 按指标进入
- **WHEN** 用户点击心率与呼吸率、面部心率、血压、血氧或糖尿病风险卡片
- **THEN** 保留原方式及目标映射；指尖目标共用真实指尖页，不按目标执行健康指标推理；面部规则不变，血压继续给出尚未接入反馈，不新建另一套检测

#### Scenario: 已保存跳过偏好的功能入口
- **WHEN** 用户勾选某方式“以后不再提示”后再次点击对应部位或指标卡片
- **THEN** 不显示引导或声音提醒；面部进入待开始页，指尖建立新的真实轮次并准备覆盖观测，血压仍在功能页反馈尚未接入，其他方式偏好不受影响

#### Scenario: 返回保留分类
- **WHEN** 用户选择按指标后进入准备或检测，再返回功能页
- **THEN** 原分类仍选中，不重置为按检测部位，分类选中状态与可见卡片一致

#### Scenario: 新页面不发布健康记录
- **WHEN** 用户结束面部会话或完成真实指尖本地采集后查看首页和功能页
- **THEN** 不改写现有健康摘要、固定测量时间、面部独立记录或风险结果，不将指尖采集完成时间记为最近健康检测，不把覆盖就绪、波形存在或文件完成当作健康结果
